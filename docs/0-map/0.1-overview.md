## 一句话定义

这一节回答：Isaac 体系到底是什么？

Isaac 体系是 NVIDIA 面向机器人研发的 GPU 仿真与学习工具链，核心是两部分：**Isaac Sim**，一个用来开发、仿真和测试机器人的仿真器[^sim]；**Isaac Lab**，构建在 Isaac Sim 之上的机器人学习框架[^lab]。

## 它解决什么问题

这一节回答：为什么要用这套工具，而不是直接在真机上试？

- **大规模并行仿真**：在一块 GPU 上同时跑几千个环境（官方 reach 任务默认 4096 个），为强化学习提供足够多的样本[^reach]。
- **真实感渲染与合成数据**：RTX 渲染与 Replicator 生成带标注的图像数据[^sim]。
- **标准化的任务与训练流程**：用统一的接口定义观测、动作、奖励，再接上现成的 RL 库[^lab]。
- **sim2real**：在仿真里跑通数字孪生与完整流程，再上真机[^sim]。

## 典型工作流

这一节回答：一个机器人项目在这套体系里要经过哪几步？

资产 → 场景 → 任务 → 训练 → 评估 → 部署。本站以 Galbot One Golf 为例把这六步完整走一遍，入口是 [6.1.1 认识 Galbot One Golf 描述仓库](../6-galbot/1-asset/6.1.1-galbot-repo.md)。

## 本站怎么读

这一节回答：从哪里开始，版本怎么选？

- **学习路线**：按目标选路线，见 [0.7 学习路线图](0.7-learning-paths.md)。
- **版本**：主线是 Isaac Sim 5.1.0 + Isaac Lab 2.3.2，所有示例都在这个组合上验证；Isaac Lab 3.0 的内容集中在第 8 部分，基于 3.0.0-EA，可能变动，见 [8.1 3.0 改了什么、为什么改](../8-frontier/8.1-what-changed.md)。
- **与翻译站的分工**：本站讲框架、概念与工程落地；需要查某个 API 或选项的完整说明时，跳到中文翻译站 [isaac.kiloong.com](https://isaac.kiloong.com/zh/index.html)（译自最新版 Isaac Sim 文档，与主线 5.1.0 可能有差异）。
