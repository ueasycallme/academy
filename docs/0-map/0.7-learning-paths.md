## 前置自测

这一节回答：开始之前，我需要会什么？

逐条对照，不会的项目给出了补救办法：

- ☐ **Python**：能读懂类、装饰器、dataclass。本站所有代码都是 Python，这一条是必需的。
- ☐ **Linux 命令行**：会用终端、环境变量、conda 或 venv。主线安装以 Linux 为准，见 [1.4](../1-env/1.4-install-51-232.md)。
- ☐ **刚体与线性代数基础**：知道位姿、四元数、关节角是什么。不熟也可以开始，遇到时回查 [0.8 术语表](0.8-glossary.md)。
- ☐ **ROS 2**（可选）：只有"数字孪生与 ROS 2"路线需要。
- ☐ **强化学习**：**不要求**。需要的概念在 [第 5 部分](../5-rl/5.1-mdp.md) 从零讲起。

## 我已经会 X，可以跳过什么

这一节回答：有基础的读者怎么省时间？

**会 ROS 与 URDF**：URDF 的概念你已经熟悉，[2.1 为什么是 USD](../2-usd-kit/2.1-why-usd.md) 可以快速浏览，重点放在 USD 与 URDF 的差异上。[3.5 资产导入](../3-isaacsim/3.5-urdf-mjcf-import.md) 仍然要读，因为导入选项直接决定碰撞体和关节驱动的质量。ROS 2 相关的 [3.10 ROS 2 Bridge](../3-isaacsim/3.10-ros2-bridge.md) 可以直接跳到与 Isaac ROS 的边界部分。

**会 MuJoCo 或 Isaac Gym**：并行仿真与 RL 的思路你已经有了，第 5 部分可以只看 [5.8 训练不收敛时看什么](../5-rl/5.8-training-debug.md)。要重点读的是 [0.3 产品谱系与改名史](0.3-lineage.md)（旧代码怎么换算）和 [0.6 一个 RL step 里发生了什么](0.6-one-step.md)（Isaac Lab 的调用链与 Isaac Gym 的差别）。

**会 USD**：第 2 部分可以只看 [2.4 Schema：USD 如何描述物理](../2-usd-kit/2.4-physics-schema.md)，其余跳过。物理 schema 是 USD 通用知识之外、仿真最依赖的部分。

## 3.0 前沿专栏怎么并入

这一节回答：想了解 Isaac Lab 3.0，什么时候读第 8 部分？

先走完主线路线中的任意一条，再读 [8.1 3.0 改了什么、为什么改](../8-frontier/8.1-what-changed.md)。第 8 部分基于 3.0.0-EA，内容可能变动；它默认你已经理解 2.3 的概念，重点讲差异。主线示例全部在 Isaac Sim 5.1.0 + Isaac Lab 2.3.2 上验证，不要在 3.0 环境里直接照做主线页面。

## 常见误解

:::{admonition} 误解：必须从第 0 部分按顺序读到第 9 部分
:class: warning

不需要。本站按主题分部分，路线才是阅读顺序。第 9 部分（源码导读）和第 7 部分（工程基础设施）是在需要时查阅的，不在任何一条入门路线里。
:::
