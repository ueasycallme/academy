## 中英使用规则

这一节回答：一个术语什么时候写英文、什么时候写中文？

- **保留英文，不翻译**：USD 的基本对象（Stage、Prim、Layer、Schema）；代码里的类名、配置项和参数（Articulation、configclass、Manager、Term、decimation、num_envs、dt、render_interval）；产品与项目名（Isaac Sim、Isaac Lab、PhysX、Newton、Warp、Kit）；业界通用、翻译后反而难以检索的词（rollout、headless、sim2real、PPO）。首字母大小写按本表写法统一，例如 Prim、Term 首字母大写。
- **用中文，首次出现附英文**：一般概念用中文，全页第一次出现时写成"中文（English）"，之后只用中文。例如刚体（rigid body）、关节（joint）、执行器（actuator）、观测（observation）、域随机化（domain randomization）。
- **两种写法都允许的**：适配层（wrapper）首次出现写"适配层（wrapper）"，之后同一页内二选一，保持一致；"扩展"可以单独使用，不必附英文（D-018）。
- 本表未收录的术语，按上述规则判断；新增术语时先补进本表，再在页面中使用。
