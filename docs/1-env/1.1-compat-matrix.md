## 我的环境能跑哪个

这一节回答：拿到一台机器，怎么快速判断？

按顺序看三件事，每一步都会排除一部分组合：

1. **驱动**：`nvidia-smi` 显示的驱动版本低于 580.65.06 时，按官方推荐不应使用 2.3.x + 5.1 与 3.0 组合，先升级驱动（2.3.x 与 3.0 的推荐值都从 580 起）[^idx232][^lab30-install]。
2. **Python**：Isaac Sim 的 pip 包精确要求 Python 小版本。系统只有 3.10 就只能装 Isaac Sim 4.5；要用主线 5.1 需要 3.11；要用 6.1 与 Isaac Lab 3.0 需要 3.12[^pypi]。用 conda 或 venv 单独建环境即可，不必改系统 Python。
3. **Isaac Sim 版本**：确定 Isaac Sim 版本后，回到表 1 找支持它的 Isaac Lab 版本。例如装的是 5.0，就只能用 2.2.x 或 2.3.x。

不确定选哪个组合时，看 [1.2 版本选择决策树](1.2-version-decision.md)。

## 常见误解

!!! warning "误解：Isaac Lab 版本和 Isaac Sim 版本一一对应"
    2.x 是支持集合，例如 2.3.x 同时支持 Isaac Sim 4.5、5.0、5.1[^readme232]。本站选 5.1.0 + 2.3.2，是因为这是官方推荐组合[^idx232]，不是因为只能这样配。3.0 才收窄为只支持 6.1[^lab30-install]。
