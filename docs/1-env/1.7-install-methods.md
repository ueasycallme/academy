## 三种方式各是什么

这一节回答：同一个 Isaac Sim 5.1.0，官方给了哪几种拿法？

| | 二进制包（Workstation） | pip 包 | 容器 |
|---|---|---|---|
| 获取 | 下载 zip 解压，示例目录 `~/isaacsim`[^ws] | `pip install isaacsim[all,extscache]==5.1.0`[^pip] | `docker pull nvcr.io/nvidia/isaac-sim:5.1.0`[^ct] |
| 落在哪 | 解压目录 | 虚拟环境的 `site-packages/isaacsim/` | 镜像内；缓存挂到宿主的 `~/docker/isaac-sim/`[^ct] |
| 启动 | `./isaac-sim.sh`；脚本用 `./python.sh`[^ws] | `isaacsim` 命令；脚本用环境里的 `python`[^pip] | `./runheadless.sh`（远程串流）或 `./runapp.sh`（X11 界面）[^ct] |
| Python | 自带解释器 | 自己建的 Python 3.11 环境[^pip] | 镜像自带 |
| 本站 | 未验证 | 主线（1.4），本页实测 | 未验证，见 [1.6](1.6-container.md) |

*表 1：三种获取方式。安装步骤见各自的官方页面；pip 方式见 [1.4](1.4-install-51-232.md)。*

- **二进制包**：一个自成一体的目录，带 Python 解释器、全部扩展和启动脚本。适合要用完整图形界面、不想管 Python 环境的人。
- **pip 包**：同样的内容拆成 Python 包装进你自己的环境，Isaac Sim 与 PyTorch 等库共用一个解释器，`import isaacsim` 即可。
- **容器**：把整个运行环境封进镜像，宿主只需驱动与容器工具，适合服务器与集群。

## pip 包里装的是什么

这一节回答：pip 包是不是"精简版"？

不是。在 1.4 装好的环境里实测（2026-10-08，本机）：

- `pip list` 中有 25 个 `isaacsim*` 包：元包 `isaacsim`、内核 `isaacsim-kernel`、按领域拆分的 `isaacsim-core`、`isaacsim-sensor`、`isaacsim-rl` 等，以及三个扩展缓存包 `isaacsim-extscache-kit`、`-kit-sdk`、`-physics`；
- 合起来就是 `site-packages/isaacsim/` 一个目录，共 11 GB：`extscache/` 9.1 GB（Kit 与 Omniverse 扩展）、`exts/` 750 MB（Isaac Sim 扩展）、`kit/` 595 MB（其中 Kit 内核本身约 170 MB，其余是本环境运行产生的 `cache/` 359 MB 与 `logs/` 65 MB，随使用变化）、`extsDeprecated/` 126 MB；整个虚拟环境（含 PyTorch 等）约 20 GB；
- `apps/` 下有 `isaacsim.exp.full.kit` 等 13 个体验文件，`isaacsim isaacsim.exp.full` 能打开完整界面[^pip]。

`import isaacsim` 之后，三个环境变量都指向这个目录（本站实测）：

| 变量 | pip 安装下的值 | 含义 |
|---|---|---|
| `ISAAC_PATH` | `…/site-packages/isaacsim` | Isaac Sim 根目录 |
| `EXP_PATH` | `…/site-packages/isaacsim/apps` | 体验文件目录（[2.6](../2-usd-kit/2.6-what-is-kit.md)） |
| `CARB_APP_PATH` | `…/site-packages/isaacsim/kit` | Kit 内核目录 |

*表 2：pip 安装下的环境变量，由 `isaacsim/__init__.py` 设置[^bootstrap]。*

所以两者的差别在打包和解释器，不在功能：同一套 Kit 扩展，二进制包放在解压目录、用自带的 `python.sh` 运行，pip 包放在 site-packages、用你环境里的解释器运行（推断，依据是两种方式的官方说明[^ws][^pip]，以及 pip 包的目录结构与二进制包的扩展目录同名）。二进制安装时 Isaac Lab 还要求设置 `ISAACSIM_PATH` 与 `ISAACSIM_PYTHON_EXE`，后者指向 `python.sh`[^lab-bin]。

## Isaac Lab 怎么看待三种方式

这一节回答：Isaac Lab 2.3.2 推荐哪种，它怎么找到 Isaac Sim？

Isaac Lab 2.3.2 的安装文档把"pip 装 Isaac Sim + 源码装 Isaac Lab"标为推荐方式，适合初学者和常规使用；另列二进制安装、源码安装、Isaac Lab pip 包与容器部署[^lab-install]。

`isaaclab.sh` 分两步找[^lab-sh]：

1. **Python 解释器**：已激活 conda 环境就用它的 `python`，否则用已激活的 venv，都没有则用 `_isaac_sim/python.sh`；
2. **Isaac Sim 目录**：先看仓库里有没有 `_isaac_sim` 符号链接（二进制安装时手动 `ln -s` 建立[^lab-bin]），没有才检查 pip 是否装了 `isaacsim-rl`，再从 `import isaacsim` 后的 `ISAAC_PATH` 读路径。

## 选哪种

这一节回答：我该用哪种？

| 场景 | 建议 | 理由 |
|---|---|---|
| 个人开发机，跟本站学 | pip | Isaac Lab 推荐方式[^lab-install]；一个环境装下所有依赖 |
| 一台机器上装多个版本 | pip，每个版本一个环境 | 环境之间互不影响，见 [1.2 两套并存](1.2-version-decision.md) |
| 服务器、集群、CI | 容器 | 环境可复现，宿主只需驱动；见 [1.6](1.6-container.md)、[7.1](../7-infra/7.1-headless-remote.md) |
| 主要在图形界面里搭场景、调试 | 二进制或 pip 都可以 | 二者带同样的体验文件；二进制开箱即用 |

*表 3：选择指南（经验性）。*

## 缓存与目录一览

这一节回答：Isaac Sim 在磁盘上还写了哪些东西？哪些可以删？

| 位置 | 内容 | 本机实测 | 清理 |
|---|---|---|---|
| `site-packages/isaacsim/kit/cache/` | 着色器等缓存（每个环境一份） | 359 MB | 可删，下次启动重建，首次启动变慢 |
| `site-packages/isaacsim/kit/logs/` | Kit 日志（每个环境一份） | 65 MB | 可删 |
| `~/.cache/ov/texturecache/`、`shaders/` | 纹理与着色器缓存 | 1.1 GB、177 MB | 可删，同上 |
| `~/.cache/ov/client/` | 资产下载缓存 | 124 MB | 可删，用到的资产会重新下载 |
| `~/.local/share/ov/data/exts/` | 从扩展仓库下载的扩展 | 197 MB | 可删，需要时重新下载（推断） |
| `~/.nvidia-omniverse/logs/` | 其他 Kit 日志 | 63 MB | 可删 |
| `~/.cache/warp/` | Warp 内核编译缓存 | 89 MB | 可删，下次重新编译 |

*表 4：pip 安装下的缓存与日志目录。"本机实测"是这台机器上几个环境多次运行累计的结果，只作量级参考。校验方在较干净的环境中测得 `~/.cache/ov` 为 180–750 MB，用过图形界面后着色器与纹理缓存再增加约 0.86 GB。*

另两种方式的差别（未验证，依据官方文档）：官方 FAQ 给出的着色器缓存在 `~/.cache/ov/Kit`，日志在 `~/.nvidia-omniverse/logs/Kit/Isaac-Sim`，配置在 `~/.local/share/ov/data/Kit/Isaac-Sim`，可用 `clear_caches.sh` 或启动参数 `--clear-cache` 清理[^faq]；这些是二进制安装的位置（推断：FAQ 未写明适用哪种方式，但 pip 安装的日志实测写在 site-packages 内，见 [1.4](1.4-install-51-232.md) 表 1）；容器把这些目录挂到宿主的 `~/docker/isaac-sim/cache/`、`logs/` 等处，删容器不丢缓存[^ct]。

## 常见误解

:::{admonition} 误解一："pip 包是轻量版，功能不全"
:class: warning

pip 包有 11 GB，带同样的扩展和完整界面的体验文件（上文实测）。它省掉的只是一个独立的 Python 解释器。
:::

:::{admonition} 误解二："同一份 Isaac Lab 可以随便接不同的 Isaac Sim"
:class: warning

`isaaclab.sh` 的两步各有优先级（上文）。仓库里留着 `_isaac_sim` 链接、同时又激活了 pip 环境时，解释器用的是 pip 环境，Isaac Sim 目录却是链接指向的二进制包，两者可能不是一个版本（推断，依据 `isaaclab.sh` 源码[^lab-sh]）。换安装方式时，删掉 `_isaac_sim` 链接，一份 Isaac Lab 只对应一种方式。
:::

:::{admonition} 误解三："容器里不能用图形界面"
:class: warning

官方给了两种方式：`runheadless.sh` 通过 WebRTC 远程串流，`runapp.sh` 通过 X11 显示界面[^ct]。不过训练通常 headless 跑，界面只在调试时用。
:::
