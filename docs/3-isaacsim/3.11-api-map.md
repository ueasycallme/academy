# Isaac Sim 的 Python API 地图

:::{admonition} 学习目标
:class: lead-goals

- 按功能找到对应的 `isaacsim.*` 包与常用类
- 把旧教程中的 `omni.isaac.*` 导入换算成新名字
- 知道 Isaac Lab 依赖了哪些 Isaac Sim API，以及怎样自己查
:::

:::{admonition} 前置知识
:class: lead-prereq

- [3.2 SimulationApp 与 Python 启动方式](3.2-simulation-app.md)：这些模块都要在 `SimulationApp` 启动后才能导入
:::

本页是参考页，按需查阅。包名以 Isaac Sim 5.1.0 pip 包中实际存在的扩展为准：本站实测 `site-packages/isaacsim/exts/` 下有 94 个扩展，`extsDeprecated/` 下 70 个，`extscache/` 下 448 个。

## `isaacsim.*` 顶层包速查

这一节回答：想做某件事，该导入哪个包？

| 包 | 用途 | 常用的类 / 函数 |
|---|---|---|
| [`isaacsim.simulation_app`][api-app] | 启动 Kit，standalone 脚本的入口 | `SimulationApp`（通常写 `from isaacsim import SimulationApp`） |
| [`isaacsim.core.api`][api-core] | 仿真世界与时间推进 | `World`、`SimulationContext`、`PhysicsContext`；`objects.DynamicCuboid` 等 |
| [`isaacsim.core.prims`][api-prims] | 按路径批量或单个包装 Prim | `Articulation`、`RigidPrim`、`XFormPrim`，单个对象用 `SingleArticulation` 等 |
| [`isaacsim.core.utils`][api-utils] | Stage、Prim、旋转等工具函数 | `stage.add_reference_to_stage`、`stage.get_current_stage`、`prims.create_prim` |
| [`isaacsim.core.cloner`][api-cloner] | 复制环境、过滤环境间碰撞 | `Cloner`、`GridCloner` |
| [`isaacsim.core.simulation_manager`][api-simmgr] | 管理物理场景、后端与仿真视图 | `SimulationManager` |
| [`isaacsim.sensors.camera`][api-cam] | 相机 | `Camera` |
| [`isaacsim.sensors.physics`][api-sphys] | 基于物理的传感器 | `ContactSensor`、`IMUSensor` |
| [`isaacsim.sensors.physx`][api-sphysx] | PhysX 射线类传感器 | `RotatingLidarPhysX` |
| [`isaacsim.sensors.rtx`][api-srtx] | RTX 渲染的激光雷达等 | `LidarRtx` |
| [`isaacsim.robot.manipulators`][api-manip] | 机械臂与夹爪封装 | `SingleManipulator` |
| [`isaacsim.robot.wheeled_robots`][api-wheel] | 轮式机器人与底盘控制器 | `WheeledRobot`、`DifferentialController` |
| [`isaacsim.robot_motion.motion_generation`][api-motion] | 运动规划与控制（含 Lula） | `ArticulationMotionPolicy`、`lula.LulaKinematicsSolver`、`lula.RmpFlow` |
| [`isaacsim.asset.importer.urdf`][api-urdf] / `.mjcf` | URDF / MJCF 导入 | 命令 `URDFParseFile`、`URDFImportRobot` 等（见 [3.5](3.5-urdf-mjcf-import.md)） |
| [`isaacsim.replicator.writers`][api-writers] / [`.domain_randomization`][api-dr] | 合成数据写出与域随机化 | `PytorchWriter` 等 |
| [`isaacsim.ros2.bridge`][api-ros2] | ROS 2 桥接，以 OmniGraph 节点为主 | 见 [3.10](3.10-ros2-bridge.md) |
| [`isaacsim.storage.native`][api-storage] | 资产服务器路径 | `get_assets_root_path` |

*表 1：常用的 `isaacsim.*` 包。类名均在 5.1.0 pip 包的对应扩展源码中核对过（本站实测）；`isaacsim.core.experimental.*` 等实验性扩展未列入。*

## 底层包：什么时候会直接用到

这一节回答：`omni.*`、`pxr`、`carb` 又是什么？

| 包 | 是什么 | 什么时候直接用 |
|---|---|---|
| `pxr`（`Usd`、`UsdGeom`、`UsdPhysics`、`Sdf`、`Gf`） | OpenUSD 的 Python API | 读写 Prim 与属性（见 [2.2](../2-usd-kit/2.2-usd-concepts.md)、[2.5](../2-usd-kit/2.5-usd-python.md)） |
| `omni.usd` | Kit 中的 USD 上下文 | 取当前 Stage：`omni.usd.get_context().get_stage()` |
| `omni.kit.app` / `omni.kit.commands` | Kit 应用与命令系统 | 启用扩展、执行 Kit 命令（如导入器） |
| `omni.timeline` | 播放控制 | 查询或控制 play / stop（见 [3.1](3.1-sim-loop.md)） |
| `omni.physx` | PhysX 的 Kit 接口 | 直接调用 simulate、查询物理设置 |
| `omni.physics.tensors` | 物理状态的张量视图 | 批量读写 Articulation、刚体状态（见 [3.4](3.4-articulation.md)） |
| `carb` | Kit 底层框架：设置、日志、输入 | 读写设置项，如 `carb.settings.get_settings()` |

*表 2：底层包。Isaac Sim 的 `SimulationContext` 本身就是用 `omni.physx`、`omni.timeline` 等实现的（见 3.1 的源码引用）。*

## 旧名 → 新名

这一节回答：旧教程里的 `omni.isaac.*` 该换成什么？

Isaac Sim 4.5 起，扩展由 `omni.isaac.*` 等旧名改为 `isaacsim.*`[^renaming]。5.x 中大多数旧名仍以弃用扩展的形式保留在 `extsDeprecated/` 里，可以导入但会打印弃用警告；官方计划在 6.0 移除（D-009）[^rn51]。**前提**：pip 安装时，必须先 `import isaacsim` 或启动 `SimulationApp`，旧名才找得到（见 [3.2](3.2-simulation-app.md)）。

| 旧名（4.2 及以前） | 新名（4.5 起） |
|---|---|
| `omni.isaac.kit` | `isaacsim.simulation_app` |
| `omni.isaac.core` | `isaacsim.core.api`、`isaacsim.core.prims`、`isaacsim.core.utils` |
| `omni.isaac.cloner` | `isaacsim.core.cloner` |
| `omni.isaac.core_nodes` | `isaacsim.core.nodes` |
| `omni.isaac.version` | `isaacsim.core.version` |
| `omni.isaac.sensor` | `isaacsim.sensors.camera`、`isaacsim.sensors.physics`、`isaacsim.sensors.physx`、`isaacsim.sensors.rtx` 等 |
| `omni.isaac.range_sensor` | `isaacsim.sensors.physx` |
| `omni.isaac.manipulators` | `isaacsim.robot.manipulators` |
| `omni.isaac.franka` | `isaacsim.robot.manipulators.examples` |
| `omni.isaac.wheeled_robots` | `isaacsim.robot.wheeled_robots` |
| `omni.isaac.surface_gripper` | `isaacsim.robot.surface_gripper` |
| `omni.isaac.motion_generation` | `isaacsim.robot_motion.motion_generation` |
| `omni.isaac.lula` | `isaacsim.robot_motion.lula` |
| `omni.isaac.cortex` | `isaacsim.cortex.framework` |
| `omni.importer.urdf` | `isaacsim.asset.importer.urdf` |
| `omni.importer.mjcf` | `isaacsim.asset.importer.mjcf` |
| `omni.isaac.ros2_bridge` | `isaacsim.ros2.bridge` |
| `omni.isaac.nucleus` | `isaacsim.storage.native` |
| `omni.isaac.debug_draw` | `isaacsim.util.debug_draw` |
| `omni.replicator.isaac` | `isaacsim.replicator.domain_randomization`、`isaacsim.replicator.examples`、`isaacsim.replicator.writers` |
| `omni.isaac.dynamic_control` | 无新名（官方表中新名一栏为空；5.1.0 中仍在 `extsDeprecated/`） |

*表 3：高频扩展的改名对照，摘自官方改名页[^renaming]。一个旧扩展可能拆成多个新扩展；类名大多不变，例如 `omni.isaac.core.World` 对应 `isaacsim.core.api.World`。*

Isaac Sim 6.x 上这些旧名是否已经移除，本站尚未实测，不作断言；进展见 [8.1 3.0 改了什么、为什么改](../8-frontier/8.1-what-changed.md)。

## Isaac Lab 用到了哪些

这一节回答：学 Isaac Sim API 时，哪些最值得先学？

本站统计 Isaac Lab v2.3.2 `source/` 目录中的导入语句（`git grep`，按导入的模块计行数）：

| Isaac Sim 模块 | 导入次数 | 底层模块 | 导入次数 |
|---|---|---|---|
| `isaacsim.core.utils` | 42 | `pxr` | 73 |
| `isaacsim.core.simulation_manager` | 16 | `carb` | 46 |
| `isaacsim.core.prims` | 16 | `omni.usd` | 30 |
| `isaacsim.core.cloner` | 14 | `omni.replicator.core` | 22 |
| `isaacsim.core.api` | 12 | `omni.kit.app` | 15 |
| `isaacsim`（顶层） | 10 | `omni.physics.tensors.impl.api` | 12 |
| `isaacsim.asset.importer.*` | 8 | `omni.kit.commands` | 10 |
| `isaacsim.gui.components` | 4 | `omni.ui` | 9 |
| `isaacsim.robot.surface_gripper` | 2 | `omni.physx` | 8 |
| `isaacsim.robot_motion.motion_generation` | 2 | `omni.timeline` | 5 |

*表 4：Isaac Lab v2.3.2 对 Isaac Sim 与底层模块的依赖（本站实测，共 70 个文件导入了 `isaacsim`）。计数口径：统计以 `from` 或 `import` 开头的导入语句行数，两列归类方式不同。Isaac Sim 列按模块名的前三级合并（如 `isaacsim.core.utils.stage` 计入 `isaacsim.core.utils`）；顶层一行的 10 次为 5 行 `from isaacsim import SimulationApp` 与 5 行 `import isaacsim`。底层列按导入语句中的完整模块名计数，不合并子模块（所以 `omni.physics.tensors.impl.api` 单列，另有 1 行 `omni.replicator.core.functional` 未计入 `omni.replicator.core`）。*

结论：Isaac Lab 主要依赖 `isaacsim.core.*` 这一组，再加上直接操作 USD（`pxr`、`omni.usd`）与物理张量（`omni.physics.tensors`）。机械臂、轮式机器人、传感器等高层封装它基本不用，而是自己实现（见第 4 部分）。

## 如何自己查

这一节回答：本页没有列到的，去哪找？

- **API 文档**：Isaac Sim 5.1.0 的 Python API 按扩展组织，入口为 <https://docs.isaacsim.omniverse.nvidia.com/5.1.0/py/index.html>，每个扩展的页面地址形如 `…/py/source/extensions/<扩展名>/docs/index.html`。
- **看目录**：pip 安装的扩展在环境的 `site-packages/isaacsim/` 下：`exts/` 为 Isaac Sim 自己的扩展，`extsDeprecated/` 为旧名兼容层，`extscache/` 为依赖的 Kit 与 Omniverse 扩展。`import isaacsim` 后，环境变量 `ISAAC_PATH` 指向这个目录，`isaaclab.sh` 就是这样找到它的[^lab-sh]。
- **扩展管理器**：Isaac Sim 界面里的扩展窗口可以搜索扩展、查看版本与依赖、启用或停用。
- **源码**：`isaacsim.*` 扩展的源码在 [isaac-sim/IsaacSim](https://github.com/isaac-sim/IsaacSim) 仓库的 `source/extensions/` 下（tag v5.1.0），与 pip 包内容一致（本站在 3.1、3.2 中抽查过）。
