## 刚体参数

这一节回答：一个刚体有哪些"旋钮"，拧错了会怎样？

| 参数（Schema 属性） | 含义 | 默认 | 调大 / 调小的表现 |
|---|---|---|---|
| 质量 `physics:mass` | 总质量 | 0，表示由碰撞体体积 × 密度计算，密度缺省 1000 kg/m³[^usd-physics] | 与相连物体质量差太大时，关节与接触难以收敛 |
| 质心 `physics:centerOfMass` | 质心在刚体坐标系中的位置 | 由几何计算 | 偏差大时物体"翻倒方向不对" |
| 惯量 `physics:diagonalInertia` + `principalAxes` | 转动惯量的对角形式 | 由几何计算 | 过小时一碰就高速旋转 |
| `physics:kinematicEnabled` | 运动学刚体：位姿由你设定，不受力影响，但能推开其他刚体[^usd-physics] | False | 用于被脚本驱动的平台、传送带等 |
| `physxRigidBody:linearDamping` / `angularDamping` | 线 / 角速度阻尼 | 0 / 0.05 | 大：运动像在黏液里；小：可能转个不停 |
| `physxRigidBody:maxLinearVelocity` / `maxAngularVelocity` | 速度上限 | ∞ / 5729.58 °/s | 设得过小会"限速"掩盖真实运动 |
| `physxRigidBody:sleepThreshold` | 质量归一化动能低于它时可休眠 | 5e-5 | 大：慢速运动会被"冻住"；小：静物也一直参与计算 |
| `physxRigidBody:solverPositionIterationCount` | 求解器位置迭代次数，范围 1–255 | 16 | 大：接触与关节更"硬"、更准，但更慢[^physx-dyn] |
| `physxRigidBody:solverVelocityIterationCount` | 速度迭代次数 | 1 | 影响碰撞后的速度准确性 |
| `physxRigidBody:maxDepenetrationVelocity` | 求解器消除穿透时允许的最大分离速度 | 3（schema 回退值；文档注释写 5 × 长度容差） | 大：初始穿透时被"弹飞"；小：穿透恢复慢 |

*表 1：刚体参数。迭代次数是下限，实际次数由同一求解岛中的最大值决定；PhysX 文档提示，需要超过 30 次时应先检查场景设置[^physx-dyn]。*

## 碰撞近似

这一节回答：一个网格参与碰撞时，PhysX 实际用什么形状算？

网格碰撞体通过 `physics:approximation` 选择近似方式（见 [2.4](../2-usd-kit/2.4-physics-schema.md)）：

| 近似方式 | 形状 | 能用于动态刚体 | 精度 / 开销 | 适合 |
|---|---|---|---|---|
| `none`（三角网格） | 原网格 | 否，只能静态或运动学[^physx-geom] | 最准，静态场景开销可接受 | 地面、墙、桌面等静态环境 |
| `convexHull` | 一个凸包 | 是 | 快；凹处被填平 | 大致凸的连杆、箱体 |
| `convexDecomposition` | 多个凸包 | 是 | 能表示凹形，凸包越多越慢 | 杯子、夹爪等凹形物体 |
| `sdf` | 有符号距离场 | 是，动态三角网格需要它[^physx-geom] | 最接近原形；内存占用大[^physx-geom] | 精细装配、插孔 |
| `boundingSphere` / `boundingCube` | 包围球 / 包围盒 | 是 | 最快、最粗 | 远处或不重要的物体 |
| 基本体（`Cube`、`Sphere`、`Capsule` 等 Prim） | 解析形状 | 是 | 快且准 | 能用基本体拼出的形状 |

*表 2：碰撞近似方式。PhysX 的凸包最多 255 个顶点[^physx-geom]，Isaac Lab 的凸包配置默认限制为 64 个，凸分解默认最多 32 个凸包[^lab-mesh]。Galbot 的 144 个网格碰撞体全部用 `convexHull`，全向轮滚子用球体基本体（见 2.4）。*

## 接触参数与物理材质

这一节回答：两个物体"碰上"是怎么判定的，摩擦怎么算？

- **contact offset**：两个形状的距离小于双方 contact offset 之和时，就开始生成接触点[^physx-coll]。
- **rest offset**：静止时两个形状之间保持的距离是双方 rest offset 之和[^physx-coll]；刚体默认为 0。

两者默认都是 `-inf`，意思是由 PhysX 按形状大小自动选取[^physx-schema]。contact offset 太大，接触点变多、变慢，也可能出现异常；太小，在较大步长下容易抖动[^physx-coll]。

物理材质写在 Material 上（`PhysicsMaterialAPI`），主要是静摩擦、动摩擦与恢复系数（弹性）[^usd-physics]。两个物体材质不同时，按 combine mode 合成，默认取平均值（`average`），也可选 `min`、`multiply`、`max`[^physx-schema]。在 Isaac Lab 中，没有指定材质的刚体使用场景默认材质，建在 `/physicsScene/defaultMaterial`，参数来自 `SimulationCfg.physics_material`[^lab-defmat]。

## 碰撞过滤

这一节回答：怎么让某些物体互相穿过？

- **碰撞组**：UsdPhysics 的 CollisionGroup 把碰撞体分组，并声明哪些组之间不碰撞；也可以用 `FilteredPairsAPI` 逐对排除[^usd-physics]。Isaac Lab 借助 Isaac Sim 的 Cloner，为每个环境副本建一个碰撞组并反转组过滤规则，让副本之间互不碰撞，只与地面等全局物体碰撞[^cloner-filter]（见 [3.7](3.7-cloner.md)）。
- **自碰撞**：Articulation 上的 `physxArticulation:enabledSelfCollisions` 决定同一台机器人的连杆之间是否碰撞，PhysxSchema 默认开启[^physx-schema]。Galbot 的资产把它关掉了（见 2.4）。关节直接相连的两个连杆之间默认不碰撞（`physics:collisionEnabled` 在关节上默认为 False）[^usd-physics]。

## PhysicsScene 全局参数

这一节回答：场景级别有哪些设置会影响所有物体？

| 参数 | 含义 | Schema 默认 | Isaac Lab 默认[^lab-physx] |
|---|---|---|---|
| 重力 | 方向与大小 | 与 upAxis 相反，地球重力（UsdPhysics）[^usd-physics] | (0, 0, −9.81) |
| `solverType` | 求解器：TGS 或 PGS | TGS | TGS（`solver_type=1`） |
| `bounceThreshold` | 相对速度低于它的接触不反弹 | 0 | 0.5 m/s |
| `enableStabilization` | 额外的稳定化步骤 | False | False |
| `enableCCD` | 连续碰撞检测 | False | False（GPU 管线不支持，见 [3.1](3.1-sim-loop.md)） |
| `gpuFoundLostPairsCapacity` 等 GPU 缓冲区 | GPU 管线预分配的缓冲区大小 | 262144 等 | 2²¹ 等，普遍更大 |

*表 3：场景参数。TGS 相比 PGS 收敛更好，更擅长质量比悬殊的情形与关节驱动，每次迭代略慢[^physx-dyn]。*

GPU 缓冲区在仿真开始时一次分配、不会自动增长；环境数或接触数超出时会报 `PhysX error: the application need to increase the PxgDynamicsMemoryConfig::…Capacity`，按报错提示调大 `PhysxCfg` 中对应的 `gpu_*` 参数，见 [1.9 安装排障手册](../1-env/1.9-install-troubleshooting.md)。

## 在 Isaac Lab 里的入口

这一节回答：在 Isaac Lab 配置里改这些参数，写在哪？

| 配置类 | 覆盖的参数 | 源码 |
|---|---|---|
| `RigidBodyPropertiesCfg`（spawner 的 `rigid_props`） | 启用、kinematic、阻尼、最大速度、最大穿透恢复速度、迭代次数、休眠与稳定阈值 | [^lab-rigid] |
| `CollisionPropertiesCfg`（`collision_props`） | 碰撞开关、contact / rest offset、扭转接触半径 | [^lab-coll] |
| `MassPropertiesCfg`（`mass_props`） | 质量或密度 | [^lab-mass] |
| `ConvexHullPropertiesCfg` 等（`mesh_collision_props`） | 网格碰撞近似方式及其参数 | [^lab-mesh] |
| `RigidBodyMaterialCfg` | 摩擦、恢复系数、combine mode；默认静 / 动摩擦 0.5，恢复系数 0 | [^lab-mat] |
| `PhysxCfg`（`SimulationCfg.physx`） | 求解器类型、迭代次数范围、反弹阈值、CCD、稳定化、GPU 缓冲区 | [^lab-physx] |

*表 4：Isaac Lab 配置入口（v2.3.2）。前几个配置类的字段默认为 None，表示不改动资产里已有的值（见 2.4）。*

## 症状 → 参数速查

这一节回答：看到异常，先查什么？

| 症状 | 先查 | 依据 |
|---|---|---|
| 穿透：快速物体穿过薄物体 | 减小 `dt`；加厚碰撞体或增大 contact offset；GPU 管线下没有 CCD | contact offset 的作用[^physx-coll]；GPU 管线关闭 CCD（见 3.1）；其余为推断 |
| 抖动：静止物体一直轻微颤动 | contact offset 与 rest offset 之差是否太小；提高位置迭代次数；尝试 `enable_stabilization` | [^physx-coll][^physx-dyn]；稳定化一项为推断 |
| 爆炸：开始仿真时物体被弹飞 | 初始是否有穿透；降低 `max_depenetration_velocity`；检查质量与惯量是否离谱 | [^physx-dyn]；Isaac Lab 排障页建议参考 Articulation 稳定性指南[^lab-trouble] |
| 滑动：物体在斜面或夹爪中滑走 | 摩擦系数（默认 0.5）与 combine mode；是否绑定了材质 | [^lab-mat]；经验性（推断） |
| 粘连 / 悬浮：物体之间留有缝隙或"吸"在一起 | rest offset 是否被设为正值；恢复系数与反弹阈值 | [^physx-coll]；经验性（推断） |

*表 5：常见症状与优先检查的参数。机器人本体（Articulation）的稳定性问题见 [3.4](3.4-articulation.md)，Galbot 的碰撞与惯量调校见 [6.1.4](../6-galbot/1-asset/6.1.4-collision-mass-inertia.md)。*

## 常见误解

:::{admonition} 误解一：碰撞网格越精细越好
:class: warning

动态刚体不能直接用三角网格碰撞，必须转成凸包、凸分解或 SDF[^physx-geom]；更精细的近似也更慢。机器人连杆通常用凸包即可，只有需要精确接触的部位才值得用凸分解或 SDF。
:::

:::{admonition} 误解二：迭代次数越高越稳
:class: warning

迭代次数只是下限，一个求解岛取其中的最大值[^physx-dyn]。给所有物体都设很高的迭代次数，主要结果是变慢。抖动和爆炸更多来自初始穿透、步长或质量比。
:::

:::{admonition} 误解三：Isaac Lab 的默认值就是 PhysX 的默认值
:class: warning

Isaac Lab 的 `PhysxCfg` 改了一部分：反弹阈值 0.5（PhysxSchema 为 0），GPU 缓冲区也更大[^lab-physx]。同一资产在 Isaac Sim 与 Isaac Lab 中表现不同时，先比较场景参数。
:::
