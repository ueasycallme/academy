## 三条导入途径

这一节回答：URDF 转 USD 有哪几种做法，各适合什么？

三条途径背后是同一个 Isaac Sim 扩展 `isaacsim.asset.importer.urdf`：它解析 URDF，生成遵循 Isaac Sim 资产结构的 USD[^sim-urdf]。

| 途径 | 怎么用 | 适合 | 可重复性 |
|---|---|---|---|
| GUI 的 URDF Importer | Isaac Sim 菜单里打开导入窗口，勾选选项后导入[^sim-urdf] | 第一次看效果、调选项 | 低：选项靠手点 |
| Isaac Sim Python API | 调用 `URDFParseFile`、`URDFImportRobot` 等命令，自己配置 `ImportConfig`[^lab-conv-impl] | 脱离 Isaac Lab 的流水线 | 高 |
| Isaac Lab `UrdfConverter` / `scripts/tools/convert_urdf.py` | 用 `UrdfConverterCfg` 描述选项；命令行工具覆盖常用选项[^lab-conv-cfg][^lab-conv-script] | Isaac Lab 项目 | 高，配置即代码 |

*表 1：三条导入途径。Isaac Lab 的转换器内部就是调用上面的命令[^lab-conv-impl]，本页以它为主线。*

## 导入选项

这一节回答：每个选项改变了生成的 USD 的哪一部分？

| `UrdfConverterCfg` 字段 | 默认 | 含义与对 USD 的影响 |
|---|---|---|
| `fix_base` | 必填 | 为 True 时在根连杆与世界之间加固定关节（固定基座） |
| `root_link_name` | None | 指定根连杆；None 时由 PhysX 决定 |
| `merge_fixed_joints` | True | 合并固定关节两侧的连杆：刚体变少，被合并的连杆降级为父刚体下的 Xform |
| `convert_mimic_joints_to_normal_joints` | False | 与 mimic 关节（mimic joint）有关，**效果与字段名相反**，见"常见坑" |
| `joint_drive.drive_type` | `"force"` | 驱动输出力矩，或 `"acceleration"`（与质量无关） |
| `joint_drive.target_type` | `"position"` | 位置 / 速度 / `none`（none 时增益置 0）；可按关节名正则分组 |
| `joint_drive.gains` | `PDGainsCfg` | stiffness（N·m/rad）与 damping；也可按自然频率与阻尼比计算 |
| `link_density` | 0.0 | URDF 缺少 `<inertial>` 的连杆使用的密度（kg/m³） |
| `collider_type` | `"convex_hull"` | 碰撞网格近似为凸包，或 `"convex_decomposition"`（凸分解） |
| `collision_from_visuals` | False | 用视觉网格生成碰撞体 |
| `self_collision` | False | 是否开启 Articulation 自碰撞 |
| `replace_cylinders_with_capsules` | False | 圆柱碰撞体换成胶囊体 |
| `make_instanceable` | True | 把网格做成可实例化的共享数据，节省内存 |

*表 2：`UrdfConverterCfg` 的主要字段（v2.3.2）[^lab-conv-cfg][^lab-conv-base]。*

命令行工具 `convert_urdf.py` 只暴露了其中一部分，而且默认值与配置类不同：`--merge-joints` 默认**不合并**；驱动增益默认 stiffness 100、damping 1，目标类型为位置[^lab-conv-script]。

## 实操：转换 Galbot

这一节回答：实际转一次，得到什么？

用命令行工具转换 Galbot 仓库中的预置 URDF（commit 2d496b0）[^galbot]：

```bash
# 在 Isaac Lab 仓库根目录执行；<galbot> 为 Galbot 描述仓库的路径
./isaaclab.sh -p scripts/tools/convert_urdf.py \
    <galbot>/urdf/galbot_one_golf.urdf galbot_usd/galbot.usd --merge-joints --headless
```

本站实测（2026-09-30，RTX 5070）约 6 秒完成，返回码 0，输出约 12 MB：

```text
galbot_usd/
├── galbot.usd              入口
├── config.yaml             本次转换用的配置
└── configuration/
    ├── galbot_base.usd     几何与材质
    ├── galbot_physics.usd  物理
    ├── galbot_robot.usd
    ├── galbot_sensor.usd
    └── materials/
```

过程中会有大量 `Unresolved reference … </visuals/…>` 警告，对应的都是 URDF 里没有 `<visual>` 的连杆（Galbot 有 58 个，例如全向轮滚子）；加 `--merge-joints` 时还会有 26 条 `DEPRECATION WARNING: Merging bodies with inertia is deprecated`，每个被合并的固定关节一条。两者都是预期输出，不影响结果（本站实测）。

再用 [2.4](../2-usd-kit/2.4-physics-schema.md) 的脚本统计，与 URDF 对照：

| | 刚体 | 关节 | 带驱动 | mimic |
|---|---|---|---|---|
| URDF | 104 个 link | 103（33 revolute + 44 continuous + 26 fixed） | — | 10 |
| 命令行，不合并 | 104 | 103（含 26 个 FixedJoint） | 77 | 0 |
| 命令行，`--merge-joints` | 78 | 77 | 77 | 0 |
| 本站示例 `convert_galbot.py` | 78 | 77 | 67（其中 40 个被动滚子增益为 0） | 10 |
| 厂商提供的 USD（见 2.4） | 78 | 77 | 27 | 10 |

*表 3：Galbot 转换结果（本站实测）。命令行工具给所有转动关节（包括 40 个被动滚子和 10 个 mimic 关节）都加了驱动，也丢掉了 mimic 关系。*

本站示例 `examples/isaaclab-2.3/3.5-urdf-mjcf-import/convert_galbot.py` 在 Python 里设置了命令行没有的选项：保留 mimic 关系，被动滚子不加驱动（按关节名正则把目标类型设为 `none`，增益随之为 0）。它的驱动增益仍是演示值，真实增益的整定见 [6.1.5](../6-galbot/1-asset/6.1.5-joint-drive-tuning.md)。

## 导入后的检查清单

这一节回答：转完之后要检查什么？

1. **Articulation 根**：恰好一个，位置正确（2.4 的脚本会检查）。
2. **关节数与类型**：与 URDF 对得上；合并后固定关节应当消失。
3. **驱动**：哪些关节有驱动、增益多大；被动关节和 mimic 关节不应被驱动。
4. **限位与单位**：转动关节限位在 USD 中是度（见 [3.4](3.4-articulation.md)）。
5. **质量与惯量**：每个刚体的 `physics:mass` 不为 0，惯量合理。
6. **碰撞体**：数量、近似方式；有无遗漏的连杆。
7. **mimic 关系**：是否保留（`PhysxMimicJointAPI`）。
8. **默认姿态**：初始关节角在限位内。
9. **单位与朝向**：`metersPerUnit = 1`，`upAxis = Z`（见 [2.2](../2-usd-kit/2.2-usd-concepts.md)）。
10. **网格与贴图路径**：在另一台机器或另一个目录下打开，视觉网格与材质仍能找到。
11. **仿真检查**：放进仿真保持若干秒，确认没有 NaN；根固定时，先确认初始姿态下没有连杆（尤其是轮子）与地面穿透。前 10 项只看 USD，发现不了这类问题。

## MJCF

这一节回答：MuJoCo 的 MJCF 能直接导入吗？

Isaac Lab 的 `MjcfConverter` 与 `scripts/tools/convert_mjcf.py` 调用 `isaacsim.asset.importer.mjcf`，选项比 URDF 少[^lab-mjcf]。本站实测转换 Galbot 仓库的 `mjcf/galbot_one_golf.xml`：

- 直接运行时报 `Can't execute command: "MJCFCreateImportConfig"`，因为 v2.3.2 在 Isaac Sim 5.1 上不会自动启用 MJCF 导入扩展（URDF 转换器有启用它的代码，MJCF 转换器没有）[^lab-conv-impl][^lab-mjcf]。加上 `--kit_args "--enable isaacsim.asset.importer.mjcf"` 后可以转换。
- 转换结果**不能直接用于 Isaac Lab**：生成了两个 Articulation 根（`base_link` 与 `worldBody`），MJCF 中表示夹爪联动的 10 个 `equality` 约束没有转成 mimic，所有 77 个转动关节都加了驱动。

Galbot 这类同时提供 URDF 的机器人，优先从 URDF 导入。

## xacro

这一节回答：只有 xacro 文件怎么办？

URDF 导入器只读 URDF，xacro 要先展开成 URDF。Galbot 仓库用 `python3 scripts/create_description.py` 重新生成预置 URDF（交互式选择轮子配置与输出路径），单个部件则直接调用 `xacro`，例如 `xacro xacro/component.xacro type:=left_arm > left_arm.urdf`[^galbot-xacro]。`xacro` 命令来自 ROS 的 xacro 包，展开时会处理宏与参数；展开后再按上文导入。

## 常见坑

:::{admonition} 坑一：mimic 关节被当成普通关节
:class: warning

v2.3.2 的转换器把 `convert_mimic_joints_to_normal_joints` 的值直接传给导入器的 `set_parse_mimic()`[^lab-conv-impl]，于是默认值 False 时导入器**不解析** mimic，联动关节变成各自独立、带驱动的关节；设为 True 时才保留 mimic 关系（本站实测，见表 3）。命令行工具没有这个选项。
:::

:::{admonition} 坑二：按正则分组的配置被后面的键覆盖
:class: warning

`target_type`、`stiffness` 等字段写成字典时，按字典顺序依次应用，后面的键会覆盖前面匹配到的关节[^lab-conv-impl]。把通配的 `".*"` 放在最后，会把前面给被动关节设的 `none` 覆盖掉（本站实测）。通配项要放在最前面。
:::

:::{admonition} 坑三：合并固定关节后，找不到 TCP 等连杆
:class: warning

合并后，被合并的连杆不再是刚体，而是父刚体下的 Xform，路径也变了：Galbot 的 `left_gripper_tcp_link` 从 `/galbot_one_golf/left_gripper_tcp_link` 变成挂在 `left_arm_link7` 下的多级子节点（本站实测）。在 Isaac Lab 里按刚体名查找它会失败（推断：Articulation 的 body 列表只含刚体），需要用这个 Xform 或另行定义坐标系。
:::

:::{admonition} 坑四：保留了 mimic，联动仍然跟不住
:class: warning

URDF 导入器把每个关节驱动的 `naturalFrequency` 与 `dampingRatio` 写进 mimic 约束（`physxMimicJoint:<轴>:naturalFrequency` 等），默认值为 25 与 0.005[^mimic-soft]。这样的约束很软：带 mimic 的夹爪在重力下，跟随关节可能明显偏离主动关节乘以倍数的位置。Isaac Lab 的 `PDGainsCfg` 只设置 stiffness 与 damping，不会改变这两个值。

对策：转换后用 USD API 调高 mimic 约束的固有频率（并给足阻尼比），再在仿真里驱动主动关节、检查跟随误差。具体做法与 Galbot 夹爪的实测数值见 [6.1.2](../6-galbot/1-asset/6.1.2-import-urdf.md)。
:::

:::{admonition} 坑五：连杆没有惯量，质量为 0
:class: warning

URDF 中缺少 `<inertial>` 的连杆，在 `link_density` 为默认 0 时，导入后 `physics:mass` 为 0（本站实测：不合并时 Galbot 的 `base_link` 即如此）[^lab-conv-cfg]。质量为 0 时，PhysX 按碰撞体与密度计算，没有碰撞体时取缺省值[^usd-physics]，结果往往不合理。合并固定关节时，子连杆的惯量会并入父连杆，Galbot 的 `base_link` 因此得到 24.506 kg。
:::

:::{admonition} 坑六：驱动参数不是你以为的值
:class: warning

转换器把 URDF 的 `effort` 写成驱动的 `maxForce`（Galbot 的 `left_arm_joint1` 为 60），增益取自配置（命令行默认 stiffness 100 N·m/rad，写入 USD 为每度 1.745），不是厂商资产中的值（本站实测）[^lab-conv-script]。仿真前按 [3.4](3.4-articulation.md) 核对单位与数值。
:::

:::{admonition} 坑七：网格路径找不到
:class: warning

ROS 包里常见 `package://包名/meshes/…` 形式的网格路径，导入器需要能把它解析到实际目录，否则视觉或碰撞网格缺失（推断：依据 URDF 的包路径约定；Galbot 使用相对路径 `meshes/…`，本站未遇到）。导入前可先把路径改成相对路径。
:::

:::{admonition} 坑八：转换失败但返回码是 0
:class: warning

MJCF 转换抛出异常时，`convert_mjcf.py` 的返回码仍是 0（本站实测）。在脚本或 CI 中批量转换时，要检查输出文件是否生成，而不能只看返回码。
:::


:::{admonition} 坑九：带轮子的机器人固定根放在地面高度
:class: warning

把轮式机器人的根固定（`fix_base=True` 或 `fix_root_link`）并放在 z=0 时，轮子的碰撞体可能一开始就嵌在地面里。Galbot 轮式版就是这样：滚子碰撞球低到 z = −0.032 m，保持零位时出现 NaN；抬高 5 cm 或不放地面即稳定（本站实测，校验方复现，见 [6.1.2](../6-galbot/1-asset/6.1.2-import-urdf.md)）。根不固定时，同样的穿透只会把机器人顶起（本站实测，本页示例的浮动基座版在 z=0 处被顶高 4.5 cm，没有 NaN）。对策是把根放到轮子离地的高度，或不放地面。
:::
