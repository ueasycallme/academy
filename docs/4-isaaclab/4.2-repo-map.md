## `source/` 下的六个包

这一节回答：仓库里的代码分成哪几个包？

| 包 | 版本 | 用途 | 依赖 |
|---|---|---|---|
| `isaaclab` | 0.54.2 | 核心框架：仿真、场景、资产、传感器、Manager、环境基类 | — |
| `isaaclab_assets` | 0.2.4 | 预置的机器人与物体配置（如 `CARTPOLE_CFG`） | isaaclab、isaaclab_contrib |
| `isaaclab_tasks` | 0.11.12 | 官方任务，注册为 Gym 环境 | isaaclab、isaaclab_assets |
| `isaaclab_rl` | 0.4.7 | 对接 rsl_rl、skrl、rl_games、sb3 的适配层 | isaaclab、isaaclab_assets、isaaclab_tasks |

## `isaaclab_tasks` 的组织

这一节回答：一个官方任务由哪些文件组成？

任务按写法分在两个目录下，再按类别细分[^lab-tasks]：

- `manager_based/`：`classic`（Cartpole、Ant、Humanoid 等）、`locomotion`、`manipulation`、`navigation`、`locomanipulation`、`drone_arl`。
- `direct/`：每个任务一个目录，如 `cartpole`、`ant`、`franka_cabinet`、`shadow_hand`、`quadcopter`。

本站实测，`scripts/environments/list_envs.py` 列出 168 个已注册的任务 ID，其中 52 个带 `Direct`。Manager-based 版 Cartpole 的目录：

```text
manager_based/classic/cartpole/
├── __init__.py              用 gym.register 注册 Isaac-Cartpole-v0 等 ID
├── cartpole_env_cfg.py      环境配置：场景、动作、观测、事件、奖励、终止
├── cartpole_camera_env_cfg.py  带相机观测的变体
├── mdp/                     本任务专用的 MDP 函数（如 rewards.py）
└── agents/                  各 RL 库的算法参数
    ├── rsl_rl_ppo_cfg.py
    ├── skrl_ppo_cfg.yaml
    ├── rl_games_ppo_cfg.yaml
    └── sb3_ppo_cfg.yaml
```

*Cartpole（manager-based）任务目录，节选[^lab-cartpole]。Direct 版在 `direct/cartpole/` 下，环境写在 `cartpole_env.py` 一个文件里，注册为 `Isaac-Cartpole-Direct-v0`。*

`__init__.py` 中的注册把几件东西连在一起：环境类（`entry_point`）、环境配置（`env_cfg_entry_point`）、各 RL 库的参数（如 `rsl_rl_cfg_entry_point`）[^lab-cartpole-reg]。训练脚本就是按任务 ID 找到这些条目的，细节见 [4.15 任务注册与 Gym 接口](4.15-task-registration.md)。

## `scripts/` 入口

这一节回答：要跑点什么，从哪个脚本开始？

| 目录 | 作用 | 典型命令 |
|---|---|---|
| `reinforcement_learning/<库>/` | 各 RL 库的 `train.py` 与 `play.py`（rsl_rl、skrl、rl_games、sb3、ray） | `./isaaclab.sh -p scripts/reinforcement_learning/rsl_rl/train.py --task Isaac-Cartpole-v0 --headless` |
| `environments/` | 列出任务、零动作 / 随机动作试跑、遥操作 | `./isaaclab.sh -p scripts/environments/list_envs.py` |
| `tools/` | 资产转换、示教数据录制与回放 | `./isaaclab.sh -p scripts/tools/convert_urdf.py <输入> <输出> --headless` |
| `tutorials/` | 官方教程脚本，`00_sim` 到 `05_controllers` | `./isaaclab.sh -p scripts/tutorials/00_sim/create_empty.py --headless` |
| `demos/` | 演示场景（多种机器人、传感器等） | `./isaaclab.sh -p scripts/demos/<脚本>.py` |
| `benchmarks/` | 性能基准 | 按需使用 |
| `imitation_learning/` | 模仿学习相关流程 | 见 [4.19](4.19-mimic.md) |

*表 3：`scripts/` 的主要目录[^lab-scripts]。本站实测：`list_envs.py` 4 秒完成；`zero_agent.py --task Isaac-Cartpole-v0 --num_envs 16 --headless` 能建好环境并持续运行（它是无限循环，需要手动结束）；rsl_rl 训练 Cartpole 的实测见 [1.4](../1-env/1.4-install-51-232.md)。*

## `isaaclab.sh`

这一节回答：仓库根目录的这个脚本能做什么？

| 选项 | 作用 |
|---|---|
| `-i, --install [LIB]` | 安装 `source/` 下的包，并按参数安装 RL 库（默认 all） |
| `-p, --python` | 用当前环境（或 Isaac Sim 自带）的 Python 运行脚本 |
| `-s, --sim` | 启动 Isaac Sim 应用 |
| `-t, --test` | 运行 pytest 测试 |
| `-f, --format` | 用 pre-commit 格式化与检查代码 |
| `-n, --new` | 从模板创建外部项目或内部任务（见 [4.18](4.18-extension-template.md)） |
| `-c, --conda [NAME]` / `-u, --uv [NAME]` | 创建 conda / uv 环境 |
| `-o, --docker` | 调用 Docker 辅助脚本 |
| `-v, --vscode` | 生成 VS Code 设置 |
| `-d, --docs` | 用 Sphinx 构建文档 |

*表 4：`isaaclab.sh` 的选项，以 v2.3.2 脚本的帮助信息为准[^lab-sh]。*

## `apps/` 下的体验文件

这一节回答：这些 `.kit` 文件是干什么的？

`apps/` 下的 `.kit` 文件决定 Isaac Sim 启动时加载哪些扩展、用什么设置：

- `isaaclab.python.headless.kit` / `isaaclab.python.kit`：无窗口 / 有窗口，不开相机渲染；
- `isaaclab.python.headless.rendering.kit` / `isaaclab.python.rendering.kit`：加上相机等渲染所需的设置；
- `isaaclab.python.xr.openxr*.kit`：XR 模式；
- `rendering_modes/`：`--rendering_mode` 的预设；`isaacsim_4_5/`：兼容 Isaac Sim 4.5 的一套文件。

`AppLauncher` 根据 `--headless`、`--enable_cameras` 等参数自动选择，规则见 [3.2](../3-isaacsim/3.2-simulation-app.md)[^lab-apps]。

## 我想找 X，去哪里

这一节回答：常见需求的位置速查。

| 想找 | 去哪里 |
|---|---|
| 某个任务的环境配置 | `isaaclab_tasks/…/<任务>/<任务>_env_cfg.py`（Direct 任务为 `<任务>_env.py`） |
| 某个任务的 PPO 参数 | 同目录下 `agents/` |
| 某个任务的 ID 与注册信息 | 同目录下 `__init__.py`，或运行 `list_envs.py` |
| 机器人的预置配置（如 Franka、ANYmal） | `isaaclab_assets/robots/` |
| 通用的观测、奖励、事件函数 | `isaaclab/envs/mdp/` |
| 某个 Manager 的实现 | `isaaclab/managers/` |
| 仿真参数（dt、PhysX 设置） | `isaaclab/sim/simulation_cfg.py` |
| 刚体、碰撞等 Schema 配置 | `isaaclab/sim/schemas/`（见 [2.4](../2-usd-kit/2.4-physics-schema.md)） |
| URDF / MJCF 转换 | `isaaclab/sim/converters/` 与 `scripts/tools/convert_*.py`（见 [3.5](../3-isaacsim/3.5-urdf-mjcf-import.md)） |
| 训练与回放脚本 | `scripts/reinforcement_learning/<库>/` |
| RL 库的适配层 | `source/isaaclab_rl/isaaclab_rl/` |
| 教程示例 | `scripts/tutorials/` |
| 启动参数与体验文件 | `isaaclab/app/app_launcher.py` 与 `apps/` |

*表 5：常见需求速查。*
