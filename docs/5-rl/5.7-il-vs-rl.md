## 两条路在学什么

这一节回答：RL 和模仿学习（imitation learning）的区别在哪？

两者的产出一样，都是一个策略：观测进、动作出（[5.2](5.2-policy-value.md)）。区别在于从哪里学：

- **强化学习（RL）**：从**奖励**里学。你写一个奖励函数说明"什么是好"，策略自己反复试，得分高的行为留下来。
- **模仿学习（imitation learning）**：从**示范**里学。你提供一批"在这个观测下，人做了这个动作"的数据，最简单的做法是行为克隆（behavior cloning）：像做监督学习一样，让策略去拟合这些动作。

| | RL | 模仿学习（行为克隆） |
|---|---|---|
| 需要什么 | 奖励函数 + 大量试错（仿真里的并行环境） | 示范数据（遥操作采集） |
| 擅长 | 奖励容易写、人难以示范的动态技能 | 人一看就会、但很难写成奖励的操作 |
| 典型失败 | 奖励被钻空子；探索不到稀疏的奖励 | 走到示范没覆盖的状态就不会了；上限是示范质量 |
| Isaac Lab 入口 | `scripts/reinforcement_learning/` 下的 rsl_rl、skrl、rl_games 等训练脚本 | `scripts/tools/record_demos.py` 采集，`scripts/imitation_learning/` 下的 Mimic 与 robomimic 脚本[^il-doc] |

## RL 适合什么任务

这一节回答：什么时候该让它自己试？

符合下面几条时，RL 通常是首选（经验性）：

- **奖励容易写**：reach 的"末端离目标多远"、行走的"速度跟踪得多准"，一行公式就能说清楚；
- **探索不危险**：在仿真里摔倒、碰撞都没有代价，几千个环境可以同时试；
- **人难以示范**：四足行走、高速平衡这类接触复杂、反应要快的动作，人用遥操作很难做得好。

代价有二：奖励要设计好，否则策略会钻空子（[5.5](5.5-reward-design.md)）；需要大量样本，依赖并行环境（[5.4](5.4-parallel-envs.md)）。Isaac Lab 自带的运动（locomotion）任务，配的都是 RL 训练配置（本站核对：11 个机器人的速度跟踪任务都有 rsl_rl 配置）。

## 模仿学习适合什么任务

这一节回答：什么时候该给它示范？

- **目标难以写成奖励**：把杯子"整齐地"放好、按某种顺序整理桌面，写成奖励函数要处理很多细节；
- **多步骤**：抓取、移动、放下、松手，每一步的奖励都得设计，步骤一多就很难调；
- **人一看就会**：操作员用遥操作做几遍，比写一个能用的奖励快得多。

代价也有三：

- 采集与标注要花人力；
- 策略的上限是示范质量；
- **分布偏移**（covariate shift）：示范只覆盖了"做对时"会经过的状态。策略一旦稍有偏差，进入示范里没见过的状态，就不知道怎么办，误差还会越积越大。DAgger 用"让专家在策略自己走到的状态上补标注"来缓解它[^dagger]。

## 两者如何结合

这一节回答：能不能既有示范又有奖励？

- **示范初始化，RL 微调**：先用行为克隆得到一个"会做个大概"的策略，再用 RL 在仿真里继续优化。DAPG 是这一路的代表工作，结合示范后，样本效率大幅提高[^dapg]。
- **示范进奖励**：把"与参考动作的差距"写成奖励项，让 RL 去跟踪一段动作捕捉或示范轨迹。DeepMimic 用这种方法学出了翻跟头等动作[^deepmimic]。
- **少量示范 → 自动生成大量数据 → 行为克隆**：这是 Isaac Lab Mimic 的路线。以官方 Franka 堆方块为例：
  1. 人遥操作录约 10 条示范，标注每个子任务的起止；
  2. Mimic 把每段子任务相对物体的轨迹变换到新的物体位置，拼接成约 1000 条新示范[^il-doc]；
  3. 用 robomimic 训练行为克隆策略[^robomimic]。

  Isaac Lab 源码注明，这个数据生成器受 MimicGen 启发[^mimic-src][^mimicgen]。详见 [4.19](../4-isaaclab/4.19-mimic.md)。

## 怎么选

这一节回答：拿到一个新任务，先走哪条路？

| 奖励好写吗 | 能方便地示范吗 | 步骤数 | 接触复杂度 | 推荐 |
|---|---|---|---|---|
| 好写 | — | 少 | 任意 | RL |
| 好写 | 难（动作快、接触复杂） | 任意 | 高 | RL，必要时加参考动作奖励 |
| 难写 | 能 | 多 | 低到中 | 遥操作 + 模仿学习（数据少时用 Mimic 扩充） |
| 难写 | 能 | 任意 | 高 | 示范初始化 + RL 微调 |
| 难写 | 难 | — | — | 先把任务拆小，让每段的奖励变好写，再回到第一行 |

## 常见误解

:::{admonition} 误解一："模仿学习不需要仿真"
:class: warning

行为克隆本身可以离线训练，但在本站的设定里，示范要在仿真里遥操作采集；Mimic 生成新数据时要在仿真里回放、确认成功；训练出的策略也要回到仿真里评估。仿真一步都离不开。
:::

:::{admonition} 误解二："有了示范就不用奖励了"
:class: warning

行为克隆训练时不用奖励，但判断一条生成的示范算不算成功、评估策略成功率，仍然需要成功条件，它和终止条件、奖励里的"成功"是同一件事。想在示范之上用 RL 微调，就更需要奖励。
:::

:::{admonition} 误解三："RL 一定比模仿学习强"
:class: warning

RL 能超过示范者，前提是奖励写得对、能探索到。多步骤的操作任务奖励难写，RL 常常学不会，几条示范反而更快见效。两者各有适用的任务（表 3）。
:::
