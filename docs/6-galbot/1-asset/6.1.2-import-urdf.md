# 从 URDF 导入 Isaac Sim

:::{admonition} 学习目标
:class: lead-goals

- 把 Galbot 的 URDF 转成 Isaac Lab 可用的 USD，知道每个选项为什么这样选
- 保住夹爪的 mimic 联动，并在仿真里验证它
- 按检查清单确认转换结果
:::

:::{admonition} 前置知识
:class: lead-prereq

- [3.5 资产导入：URDF 与 MJCF Importer](../../3-isaacsim/3.5-urdf-mjcf-import.md)（通用方法）
- [6.1.1 认识 Galbot One Golf 描述仓库](6.1.1-galbot-repo.md)
:::

3.5 讲转换器的通用用法，本页做 Galbot 的具体决策。**本页在项目中新增两个文件**：

- `scripts/convert_galbot.py`：转换；
- `scripts/check_galbot_usd.py`：在仿真里检查转换结果。

## 选哪个预置 URDF

这一节回答：固定底座用哪个文件？

reach 任务用固定底座（D-003）。有两种做法，本站都实测了（`--variant` 切换）：

| | 固定底座版 URDF + `fix_base` | 轮式 URDF + `fix_base` |
|---|---|---|
| 刚体 | 34 | 78 |
| 转动关节 | 33 | 77 |
| 带驱动的关节 | 23 | 67 |
| mimic 关节 | 10 | 10 |
| 合并固定关节时的弃用警告 | 30 条 | 26 条 |

*表 1：两种做法的转换结果（本站实测，统计工具为 2.4 的 `list_physics_schemas.py`）。两者都只有一个 Articulation 根，碰撞体都是 184 个。*

轮式版多出的 44 个关节是 4 个主动轮和 40 个被动滚子（[6.1.1](6.1.1-galbot-repo.md)）。转换器给滚子也加了驱动 API，只是增益为 0；它们对 reach 毫无用处，却会成为 Articulation 的自由度，让每个环境多算 44 个关节。所以本项目用**固定底座版 URDF**，再设 `fix_base=True` 把根连杆 `base_link` 固定到世界。固定底座版中 4 个轮关节已是固定关节，合并时多出 4 条警告，所以是 30 条，比 3.5 的轮式版多 4 条，属预期。

## 转换脚本的取值

这一节回答：每个选项为什么这样选？

`scripts/convert_galbot.py` 用 `UrdfConverterCfg`（字段见 [3.5 表 2](../../3-isaacsim/3.5-urdf-mjcf-import.md)）：

| 字段 | 本项目取值 | 理由 |
|---|---|---|
| `fix_base` | True | reach 用固定底座 |
| `merge_fixed_joints` | True | 合并固定关节两侧的连杆，减少刚体数 |
| `convert_mimic_joints_to_normal_joints` | **True** | 字段名与效果相反：True 才保留 mimic 关系（见下文） |
| `collider_type` | `convex_hull` | 默认；凸包对手臂足够，夹爪碰撞体的细调见 [6.1.4](6.1.4-collision-mass-inertia.md) |
| `self_collision` | False | 先关闭，需要时在 `ArticulationCfg` 中打开（[6.1.6](6.1.6-articulation-cfg.md)） |
| `joint_drive.drive_type` | `force` | 驱动输出力矩 |
| `joint_drive.target_type` | 全部 `position` | 位置驱动；轮式版额外把被动滚子设为 `none` |
| `joint_drive.gains` | 按正则分组，见下文 | 只求能站住，细调见 [6.1.5](6.1.5-joint-drive-tuning.md) |

*表 2：本项目的转换选项。输出到 `<GALBOT_GENERATED_DIR>/galbot_fixed_base/galbot.usd`（默认 `<项目根>/generated/`，不提交）。*

**驱动增益**写成按关节名正则分组的字典：

```python
STIFFNESS = {".*": 400.0, "leg_joint[1-3]": 4000.0, ".*_gripper_joint": 100.0}   # N·m/rad
DAMPING   = {".*": 40.0,  "leg_joint[1-3]": 400.0,  ".*_gripper_joint": 10.0}    # N·m·s/rad
```

URDF 转换器按字典顺序应用这些键，后面的键覆盖前面匹配到的关节[^conv-gains]，所以要"先通配、后特例"：先给所有关节 400，再给承重大的腿部前三个关节 4000，最后给两个夹爪主动关节 100。这组数只为让机器人在重力下站住；写进 USD 时按度换算（4000 N·m/rad 变为 69.8 N·m/°，见 [3.4](../../3-isaacsim/3.4-articulation.md)），力矩上限 `maxForce` 取自 URDF 的 `effort`。

:::{admonition} 同样是按正则写的字典，两处规则相反
:class: important

- **URDF 转换器**的增益字典：键可以重叠，按顺序应用，后键覆盖前键。
- **Isaac Lab `ArticulationCfg.actuators`**：各执行器组的 `joint_names_expr` 不能重叠，重叠时抛 `ValueError: Multiple matches`（[4.7](../../4-isaaclab/4.7-actuators.md)）。

所以转换阶段可以"先通配、后特例"，到了 [6.1.6](6.1.6-articulation-cfg.md) 写执行器分组时，必须给各部件写互不重叠的正则。
:::

## mimic 关节：保住联动，并调硬它

这一节回答：夹爪的联动怎么保留、怎么验证？

每只夹爪有 6 个关节，只有 `*_gripper_joint` 是主动的，其余 5 个通过 URDF 的 `<mimic>` 跟随它，倍数为 ±1（[6.1.1](6.1.1-galbot-repo.md)）。要保住这层关系，需要做两件事。

**第一，打开"保留 mimic"的开关。** Isaac Lab 2.3.2 的 `convert_mimic_joints_to_normal_joints` 被直接传给导入器的 `set_parse_mimic`，所以设为 True 时才保留 mimic 关系，默认的 False 反而会丢掉它（3.5 常见坑）。保留后，10 个跟随关节带有 `PhysxMimicJointAPI`，`gearing` = −倍数，没有驱动（表 1 中带驱动的关节为 33 − 10 = 23）。

**第二，把 mimic 约束调硬。** 只做第一步还不够。本站在仿真中实测（`check_galbot_usd.py`）：把右夹爪主动关节的目标设为 0.8 rad，5 个跟随关节却停在 −2.04、+0.69、+0.33、−0.06、−1.42，其中一个顶到了限位。关掉重力再测，跟随误差在 2 秒时为 0.016，5 秒时为 0，说明约束本身有效，只是太软，托不住手指的重量。

原因在 Isaac Sim 5.1 的 URDF 导入器：它把关节驱动的 `naturalFrequency` 与 `dampingRatio` 写进 mimic 约束（`physxMimicJoint:rotZ:naturalFrequency` 等），默认值是 25 与 0.005[^mimic-src]。Isaac Lab 的 `PDGainsCfg` 只设置 stiffness 和 damping，不改这两个值，所以 mimic 约束一直是这么软。本站把固有频率提高后重测（阻尼比 1.0，夹爪目标 0.8 rad，有重力）：

| mimic 固有频率 | 5 s 后最大跟随误差 |
|---|---|
| 25（导入器默认，阻尼比 0.005） | 1.242 rad |
| 100 | 0.212 rad |
| 250 | 0.039 rad |
| 1000 | 0.004 rad |

*表 3：mimic 约束刚度与跟随误差（本站实测，GPU；CPU 管线下默认值的结果相同）。误差大致随固有频率的平方下降。*

`convert_galbot.py` 在转换后调用 `stiffen_mimic_joints()`，把所有 mimic 约束改为固有频率 1000、阻尼比 1.0，写入入口 `galbot.usd` 的根层。

## 被动滚子

这一节回答：被动滚子关节怎么处理？

主线用固定底座版 URDF，里面没有被动滚子，这个问题自然消失。如果以后要用轮式版（[6.4.5](../4-task/6.4.5-base-navigation.md)），做法是把滚子的 `target_type` 设为 `none`，让它们自由转动，`convert_galbot.py --variant wheeled` 已按此处理。注意：这个键只能在轮式版中出现，放进固定底座版的配置里会报错（见常见坑三）。

## 转换结果检查

这一节回答：转完之后怎么确认结果对？

```bash
python scripts/convert_galbot.py --headless
python scripts/check_galbot_usd.py --headless
```

本站实测：转换约 6 秒，返回码 0。检查脚本输出：

```text
galbot.usd（fixed_base）：关节 33，刚体 34，根固定 True
保持零位 2 s：驱动关节最大偏离 0.0355 rad（right_arm_joint2），平均 0.0050 rad
right_gripper_joint 目标 0.8 → 实际 +0.8018
  right_gripper_r_inner_knuckle_joint    -0.8045（期望 -0.8018）
  right_gripper_r_finger_joint           +0.7999（期望 +0.8018）
  ...
```

对照 [3.5 的检查清单](../../3-isaacsim/3.5-urdf-mjcf-import.md)：

- [x] Articulation 根恰好一个（表 1 的统计）；
- [x] 关节数与类型与 URDF 一致：固定底座版 URDF 的 33 个 revolute 全部保留，固定关节全部合并；
- [x] 驱动：23 个主动关节有驱动，10 个 mimic 跟随关节没有；
- [x] 限位以度为单位，如 `right_gripper_joint` 为 [0, 97.57]，即 URDF 的 [0, 1.703] rad；
- [x] 质量：34 个刚体都有质量，合计 95.18 kg；
- [x] 碰撞体 184 个，均为凸包；
- [x] mimic 关系保留且联动成立（上面的输出）；
- [x] 默认姿态：全零，在所有关节限位内，保持 2 秒最大偏离 0.036 rad；
- [x] `metersPerUnit = 1`，`upAxis = Z`；
- [x] 网格与材质：输出目录自带 `configuration/materials/textures/`，可以整体移动。转换时的 `Unresolved reference … </visuals/head_link1>` 警告对应 URDF 中没有视觉网格的连杆，属预期（[3.5](../../3-isaacsim/3.5-urdf-mjcf-import.md)）。

## 产物放哪

这一节回答：转换得到的文件在哪里，项目怎么引用？

```text
generated/galbot_fixed_base/        # 约 12 MB，派生物，不提交（已在 .gitignore 中）
├── galbot.usd                       # 入口；mimic 参数的修改写在这一层
├── config.yaml                      # 本次转换用的配置
└── configuration/                   # galbot_base / physics / robot / sensor.usd，materials/
```

项目里用 `galbot_academy.assets.generated_asset_dir() / "galbot_fixed_base" / "galbot.usd"` 引用它。改了转换选项后，重新运行 `convert_galbot.py` 即可（脚本设了 `force_usd_conversion=True`）。在 [6.1.6](6.1.6-articulation-cfg.md) 中，它会成为 `ArticulationCfg` 的 `usd_path`。

## 常见坑

:::{admonition} 坑一：没打开"保留 mimic"的开关
:class: warning

`convert_mimic_joints_to_normal_joints` 默认 False，夹爪的 10 个跟随关节变成独立关节，还被加上驱动（3.5 实测）。设为 True，并在转换后检查 `PhysxMimicJointAPI` 的数量。
:::

:::{admonition} 坑二：保留了 mimic，夹爪仍然跟不住
:class: warning

导入器默认的 mimic 约束（固有频率 25、阻尼比 0.005）在重力下明显偏离（表 3）。只看 USD 里有没有 `PhysxMimicJointAPI` 不够，要在仿真里驱动主动关节，看跟随关节的实际角度。
:::

:::{admonition} 坑三：字典里的正则键没有匹配到任何关节
:class: warning

`target_type`、`stiffness`、`damping` 字典中的每个键都必须至少匹配一个关节，否则转换器抛 `ValueError: The joint name … was not found in the URDF file`[^conv-gains]。本站实测：把轮式版的 `wheel_.*_passive_.*` 键用于固定底座版就会触发，而且**进程返回码仍为 0**，USD 没有生成。无人值守运行时，要检查输出文件是否存在，不能只看返回码。
:::

:::{admonition} 坑四：正则是"包含"匹配，不是"整名"匹配
:class: warning

转换器用 `re.search` 匹配关节名[^conv-gains]，只要关节名中包含该模式就算命中。例如 `arm_joint1` 会同时匹配 `left_arm_joint1` 和 `right_arm_joint1`；只想要一个时，写 `^left_arm_joint1$`（由源码可知）。
:::

本页基于 Isaac Sim 5.1.0 的 URDF 导入器与 Isaac Lab 2.3.2 的 `UrdfConverter`。3.0 中导入流程的变化未核对，见 [8.1 3.0 改了什么、为什么改](../../8-frontier/8.1-what-changed.md)。

[^conv-gains]: Isaac Lab `sim/converters/urdf_converter.py`（tag v2.3.2）：<https://github.com/isaac-sim/IsaacLab/blob/v2.3.2/source/isaaclab/isaaclab/sim/converters/urdf_converter.py#L200-L250>（按字典顺序、以 `re.search` 匹配关节名并逐个设置；无匹配时抛 `ValueError`）
