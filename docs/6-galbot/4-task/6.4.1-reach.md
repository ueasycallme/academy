## 任务定义

这一节回答：用 MDP 的语言，这个任务是什么？

| MDP 要素（[5.1](../../5-rl/5.1-mdp.md)） | `Galbot-Reach-v0` |
|---|---|
| 指令 | 右臂 TCP 的目标位姿：位置在机器人前方一个长方体内随机，姿态固定；每 4 s 重采样 |
| 观测（28 维） | 右臂 7 个关节的位置、速度（相对默认值），目标位姿（7），上一步动作（7） |
| 动作（7 维） | 右臂 7 个关节的位置目标偏移 |
| 奖励 | 位置误差（线性惩罚 + tanh 奖励）、姿态误差惩罚、动作变化率与右臂关节速度惩罚 |
| 终止 | 只有超时（12 s） |

*表 1：任务定义。*

## 逐个 Manager

这一节回答：每个 Manager 填了什么，为什么这样填？

### Command：目标位姿

```python
ee_pose = mdp.TcpPoseCommandCfg(
    asset_name="robot", body_name="right_arm_link7",
    offset_pos=(-0.25572, 0.0, 0.0), offset_rot=(0.0, 0.0, 1.0, 0.0),   # TCP 相对 link7 的偏移（6.2.1）
    resampling_time_range=(4.0, 4.0), debug_vis=True,
    ranges=mdp.TcpPoseCommandCfg.Ranges(
        pos_x=(0.30, 0.60), pos_y=(-0.40, -0.15), pos_z=(1.15, 1.50),     # 相对机器人根，m
        roll=(-1.3754, -1.3754), pitch=(0.0617, 0.0617), yaw=(0.7876, 0.7876)),
)
```

官方 reach 用 `UniformPoseCommandCfg`，它拿一个刚体的原点当"当前末端"来算误差、画标记（[4.13](../../4-isaaclab/4.13-command-manager.md)）。Galbot 的 TCP 在转换时并进了 `right_arm_link7`，离原点 0.256 m（[6.2.1](../2-scene/6.2.1-workbench-scene.md)），所以项目写了一个子类 `TcpPoseCommand`。它只重写两个方法：误差指标与"当前位姿"标记，都改用"刚体 + 偏移"；目标的采样方式不变。这样，训练日志里的 `position_error` 量的就是 TCP（[6.5.1](../5-train/6.5.1-train-reach-rsl-rl.md) 会读这条曲线）。

**姿态**固定为默认姿态下 TCP 的姿态。数值用 URDF 正运动学算出，同一计算得到的位置与仿真读数逐位一致。

**位置范围**比 6.2.1 的建议窄。6.2.1 只看位置能否到达；加上固定姿态后，用 `check_reach_targets.py` 做逆运动学检验：

```bash
python scripts/check_reach_targets.py --headless                         # 任务当前的范围
python scripts/check_reach_targets.py --headless --position_only --box 0.25 0.85 -0.65 -0.15 1.10 1.50
python scripts/check_reach_targets.py --headless --restarts 4 --box 0.25 0.85 -0.65 -0.15 1.10 1.50
```

| 范围（相对根，m） | 只要求位置 | 位置 + 固定姿态 |
|---|---|---|
| 6.2.1 建议：x [0.25, 0.85]，y [−0.65, −0.15]，z [1.10, 1.50] | 100% | 58.9%；随机重启 4 次后 63.6% |
| 本任务：x [0.30, 0.60]，y [−0.40, −0.15]，z [1.15, 1.50] | — | 98.1%；随机重启 2 次后 99.0% |

*表 2：1024 个随机目标中，逆运动学收敛到位置 < 1 cm、姿态 < 0.05 rad 的比例（本站实测，种子 0；不重启时约 11 秒，按进程显存 2945 MiB）。*

原范围里随机重启也救不回来的目标，集中在 y < −0.48（82% 不可达）和 x > 0.63（57%）：手臂伸到外侧、远处时，保持不了这个姿态。收窄后的长方体几乎全部可达。

### Action：右臂关节位置

```python
arm_action = mdp.JointPositionActionCfg(asset_name="robot", joint_names=["right_arm_joint[1-7]"],
                                        scale=0.5, use_default_offset=True)
```

关节目标 = 默认位置 + 0.5 × 动作（[4.10](../../4-isaaclab/4.10-observation-action.md)），与 Franka 相同。策略输出 ±1 时，目标偏离默认值 0.5 rad。其余关节（腿、头、左臂、夹爪）不受策略控制，目标保持为默认位置，靠下面的 reset 事件设定。右臂的驱动刚度、阻尼在任务里覆盖为 1600 / 80，理由与对照数据见 [6.5.1](../5-train/6.5.1-train-reach-rsl-rl.md)。

### Observation：只取右臂

```python
joint_pos = ObsTerm(func=mdp.joint_pos_rel, params={"asset_cfg": SceneEntityCfg("robot", joint_names=["right_arm_joint[1-7]"])})
joint_vel = ObsTerm(func=mdp.joint_vel_rel, params={"asset_cfg": ...同上})
pose_command = ObsTerm(func=mdp.generated_commands, params={"command_name": "ee_pose"})
actions = ObsTerm(func=mdp.last_action)
```

四项与 Franka 相同，差别有两处：

- 关节量只取右臂：其余关节不受控，放进观测只会增加维度；而且夹爪指节的静止速度读数可达 0.2 rad/s（[6.1.5](../1-asset/6.1.5-joint-drive-tuning.md)）；
- 先不加观测噪声（`enable_corruption = False`）。噪声留给 [6.4.2](6.4.2-domain-randomization.md)。

### Reward：权重基本照搬 Franka

| 项 | 函数 | 权重 | 说明 |
|---|---|---|---|
| 位置误差 | `tcp_position_error` | −0.2 | TCP 到目标的距离（m），远处也有梯度 |
| 位置误差（细） | `tcp_position_error_tanh`，std 0.1 | +0.1 | 1 − tanh(d/0.1)，近处精修（[5.5](../../5-rl/5.5-reward-design.md) 的两种核） |
| 姿态误差 | `tcp_orientation_error` | −0.1 | TCP 与目标姿态之间的旋转角（rad） |
| 动作变化率 | `action_rate_l2` | −0.0001 → −0.001 | 课程学习：4500 个控制步后加大；Franka 升到 −0.005，本任务只升到 −0.001（[6.5.1](../5-train/6.5.1-train-reach-rsl-rl.md)） |
| 关节速度 | `joint_vel_l2`，只算右臂 | −0.0001 → −0.001 | 同上 |

*表 3：奖励项。三个 TCP 函数照搬 Isaac Lab reach 的写法，只把刚体原点换成"刚体 + 偏移"[^reach-rew]。*

除课程学习的终值外，权重直接照搬，是因为两个任务的控制周期相同（都是 1/30 s，见下文"时间参数"），而 Isaac Lab 按 权重 × 函数值 × 控制周期 累加奖励（[4.11](../../4-isaaclab/4.11-reward-termination-curriculum.md)），量级可以直接比较。关节速度惩罚限定到右臂：官方写法覆盖全部关节，对 Galbot 会把夹爪指节的读数偏差也算进去，量级约是右臂的 40 倍（6.1.5）。

### Termination：只有超时

reach 没有"失败"：机器人固定在原地，手臂伸到哪里都不会摔倒，也没有需要避免的状态。所以只有 `time_out`，标记为截断（time_out=True），让 PPO 在回合结尾用价值估计做自举（[5.3](../../5-rl/5.3-ppo.md)）。

### Event：先复位整台机器人，再扰动右臂

```python
reset_to_default = EventTerm(func=mdp.reset_scene_to_default, mode="reset", params={"reset_joint_targets": True})
reset_robot_joints = EventTerm(func=mdp.reset_joints_by_offset, mode="reset",
                               params={"position_range": (-0.2, 0.2), "velocity_range": (0.0, 0.0), "asset_cfg": 右臂})
```

同一 mode 的事件按声明顺序执行：先把所有关节的状态与目标恢复到默认姿态，再给右臂加 ±0.2 rad 的随机偏移。第一项是 Franka 没有的，原因见常见坑一。Franka 用 `reset_joints_by_scale` 把全部关节按 0.5–1.5 倍缩放；Galbot 的腿若被缩放会撑不住（[6.1.6](../1-asset/6.1.6-articulation-cfg.md)），所以只扰动右臂。完整的域随机化留给 6.4.2。

## 与官方 Franka reach 对照

这一节回答：哪些照搬，哪些改了？

| 项 | `Isaac-Reach-Franka-v0`[^reach-cfg] | `Galbot-Reach-v0` | 原因 |
|---|---|---|---|
| 末端 | `panda_hand` 刚体原点 | `right_arm_link7` + TCP 偏移 | TCP 并进了 link7 |
| 目标姿态 | pitch = π，yaw 在 ±π 内随机 | 固定为默认 TCP 姿态 | 先做最简单的；固定姿态已使可达范围缩小 |
| 动作 | 全部 7 个臂关节，scale 0.5 | 右臂 7 个关节，scale 0.5 | 照搬 |
| 观测 | 全部关节，带 ±0.01 噪声 | 只取右臂，无噪声 | 非任务关节不受控；噪声留给 6.4.2 |
| 奖励权重 | −0.2 / 0.1 / −0.1 / −0.0001 / −0.0001 | 相同 | 控制周期相同 |
| 课程学习 | 动作变化率升到 −0.005 | 升到 −0.001 | −0.005 时训练后段越来越多回合停在离目标几厘米处（6.5.1） |
| 臂的驱动 | 资产配置的值 | 任务里覆盖为刚度 1600、阻尼 80（资产参数表是 400 / 40） | 减小重力下垂（6.5.1） |
| 关节速度惩罚 | 全部关节 | 只算右臂 | 夹爪指节的读数偏差（6.1.5） |
| reset | 全部关节缩放 0.5–1.5 | 先复位到默认，再扰动右臂 ±0.2 rad | 腿不能动；非任务关节要复位 |
| 时间 | dt 1/60，decimation 2 | dt 1/120，decimation 4 | 控制频率相同，物理步更小 |
| 环境数 | 4096 | 1024 | 主线机器 12 GB（T-6-common） |

*表 4：与官方任务的对照。*

## 时间参数

这一节回答：dt、decimation、回合长度怎么换算？

| 参数 | 取值 | 换算（[0.6](../../0-map/0.6-one-step.md)） |
|---|---|---|
| `sim.dt` | 1/120 s | 物理步 |
| `decimation` | 4 | 控制周期 = 4 × 1/120 = 1/30 s，即 30 Hz |
| `episode_length_s` | 12 s | 每回合 360 个控制步，目标重采样 3 次 |

*表 5：时间参数。*

控制频率与 Franka 相同。物理步取 1/120 而不是 1/60，是为了把静止时的速度读数偏置压小：右臂在 1/120 时约 0.05 rad/s，1/60 时约 0.11 rad/s（[6.1.5](../1-asset/6.1.5-joint-drive-tuning.md)）。代价是物理计算量翻倍；若 [6.5.2](../5-train/6.5.2-hyperparameters.md) 发现吞吐不够，再回头调。

```python
gym.register(id="Galbot-Reach-v0", entry_point="isaaclab.envs:ManagerBasedRLEnv", disable_env_checker=True,
             kwargs={"env_cfg_entry_point": f"{__name__}.reach_env_cfg:GalbotReachEnvCfg"})
# 另有 Galbot-Reach-Play-v0（16 个环境），训练用的 agent 配置在 6.5.1 加入
```

任务 ID 以 `Galbot-` 开头：项目的 `list_envs.py` 只列出这个前缀的任务（6.1.1 由模板改来；Isaac Lab 自带的那份只列含 `Isaac` 的 ID，见 [4.15](../../4-isaaclab/4.15-task-registration.md)）。

```bash
python scripts/list_envs.py                                                # 列出 Galbot-Reach-v0 与 -Play-v0
python scripts/zero_agent.py --task Galbot-Reach-v0 --num_envs 16 --headless
python scripts/random_agent.py --task Galbot-Reach-v0 --num_envs 16 --headless
```

两个 agent 脚本都是无限循环，看到各 Manager 的 Term 表、没有报错后手动结束。启动时打印的要点（本站实测）：

## 训练前自检

这一节回答：按 [5.8](../../5-rl/5.8-training-debug.md) 的清单，这个任务能开始训练了吗？

```bash
python scripts/reach_smoke.py --headless                               # 零动作，跑过一次超时重置
python scripts/check_env.py --headless --task Galbot-Reach-v0 --steps 400   # 随机动作
```

| 5.8 清单 | 结果（本站实测） |
|---|---|
| 1. 零动作与随机动作能跑起来 | 能；零动作下非任务关节离默认值最远 0.035 rad（重力下垂），没有飞走或抖动 |
| 2. 观测量级合理、无 NaN | 400 步随机动作无 NaN / Inf；关节速度最大 ±1.5 rad/s（正是臂的速度上限），关节位置偏离默认值 ≤ 0.41 rad，目标位置都在命令范围内 |
| 3. 动作尺度与关节限位匹配 | scale 0.5，动作 ±1 时目标偏离 0.5 rad，在各关节行程内；右臂执行器有刚度（任务里覆盖为 1600，见 6.5.1） |
| 4. reset 后的状态合理 | 看第二个回合开头（4.6 {ref}`常见坑四 <first-reset-velocity>`）：64 个环境全部在第 360 步超时重置，右臂偏离默认值在 [−0.200, +0.200] rad 内 |
| 5. 关掉噪声与随机化做对照 | 本任务本来就没有噪声与域随机化，作为 6.4.2 的对照组 |

*表 6：环境自检（`reach_smoke.py` 约 24 秒、按进程显存 2317 MiB；`check_env.py` 约 25 秒、2315 MiB）。*

另外两个数：随机动作下每步奖励在 [−0.0071, −0.0007]（已乘控制周期）；零动作第 1 步时 TCP 离目标的中位数是 0.36 m，最远 0.53 m，这是策略要学会走完的距离。

## 常见坑

:::{admonition} 坑一：只扰动一部分关节，其余关节停在 USD 的零位
:class: warning

reset 事件只写右臂的关节状态时，其余关节不会回到 `init_state` 的默认姿态，而是停在 USD 的零位。本站最初就是这样：腿、左臂偏离默认值约 2.4 rad，躯干塌回关节下限。Franka 的 reset 恰好覆盖了全部关节，所以官方任务里看不到这个问题。先用 `reset_scene_to_default(reset_joint_targets=True)` 复位整台机器人，再扰动要扰动的关节。
:::

:::{admonition} 坑二：拿刚体原点当末端
:class: warning

`UniformPoseCommandCfg` 和官方奖励都用 `body_name` 刚体的原点。Galbot 的 link7 原点离 TCP 0.256 m，直接用会让目标与奖励都差出一截，日志里的位置误差也不再是 TCP 的。项目的 `TcpPoseCommand` 与 `tcp_*` 奖励都加上了偏移。
:::

:::{admonition} 坑三：用"位置可达"的范围去采样带姿态的目标
:class: warning

6.2.1 的范围只保证位置能到；加上固定姿态后只剩约六成可达（表 2）。到不了的目标会让策略在一部分回合里永远拿不到奖励，看起来像"学不会"。改目标的姿态或范围后，先用 `check_reach_targets.py` 检查。
:::

:::{admonition} 坑四：关节速度惩罚覆盖全部关节
:class: warning

照抄官方的 `SceneEntityCfg("robot")` 时，惩罚里包括夹爪指节，而它们静止时的速度读数可达 0.2 rad/s，惩罚被这个本底占满（6.1.5）。限定到受控的右臂。
:::

:::{admonition} 坑五：在项目外列不出任务
:class: warning

Isaac Lab 自带的 `list_envs.py` 只列含 `Isaac` 的 ID，也不导入本项目的包（4.15）。用项目自己的 `scripts/list_envs.py`，或在脚本里 `import galbot_academy.tasks` 后查 `gym.registry`。
:::
