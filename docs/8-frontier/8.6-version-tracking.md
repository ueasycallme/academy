# 3.0 版本追踪

:::{admonition} 基于 v3.0.0 正式版
:class: note

本页记录 Isaac Lab 3.0 的各个版本，以及本站内容核对到哪个版本。最新的 tag 是 v3.0.0 正式版（2026-10-19，要求 Isaac Sim 6.2），本站已在 [1.5](../1-env/1.5-install-61-30.md) 装好并实测；第 8 部分与各页"版本说明"里的 3.0 内容已按它核对。最后核对日期 2026-10-24。
:::

本页是参考页，用来回答两个问题：3.0 现在发布到哪一版了；本站哪些页面可能已经过期。

## 版本表

这一节回答：3.0 出过哪些版本，各自改了什么？

| tag | 日期 | Isaac Sim | Python | 主要变化 | 破坏性变更 | 已知问题 |
|---|---|---|---|---|---|---|
| v3.0.0-beta | 2026-03-16 | 6.0.0 | 3.12 | 多物理后端架构；Newton 后端（不需要 Isaac Sim）；可插拔的渲染器与可视化器 | 四元数 WXYZ → XYZW；数据属性返回 Warp 数组；写入方法拆成 index / mask | 只支持 Ubuntu；不是所有任务都有 Newton 预设；部分场景性能下降 |
| v3.0.0-beta2 | 2026-06-16 | 6.0.0 | 3.12 | 多后端稳定化；Newton 扩展（VBD、Kamino、粗糙地形、传感器）；统一的训练与安装命令 | 删除 `fold_preset_tokens`，预设命令行参数的解析方式改变；遥操作回放、Deformable 接口移动 | 仍是 beta，正式版前还可能有破坏性变更；Surface Gripper 只能在 CPU 上用 PhysX；Windows 的 Pink IK 不可用 |
| v3.0.0-beta2.patch1 | 2026-06-30 | 6.0.1 | 3.12 | 支持 Isaac Sim 6.0.1；修依赖与 Docker 镜像 | 无 | 同 beta2 |
| v3.0.0-EA | 2026-09-16 | 6.1.0 | 3.12 | 物理、渲染、可视化各自独立选择；Kit-less 训练；`ProxyArray` 零拷贝数据；统一命令 `isaaclab train / play / benchmark` | 各库自带的 train / play 脚本删除，改用统一命令；执行器限值字段改名 | Surface Gripper 只能在 CPU 上用 PhysX；Pink IK 只支持 Linux；Digit 闭链只支持 PhysX |
| **v3.0.0** | **2026-10-19** | **6.2.0** | **3.12** | 正式版。依赖升级：Warp 1.17、Newton 1.6.1、RSL-RL 5.5.1、PyTorch 2.11 + CUDA 13.0；稳定性修复；新增 `list_envs`、`demo`、`example` 子命令与 TorchRL 集成；官方任务多数默认 Newton | `AppLauncher` 只保留有限兼容，改用 `launch_simulation`；隐藏参数 `--cpu` 删除；`--viz newton` 改为 `newton_gl`；观测噪声回调不再先复制；部分指标改为设备上的张量；`load_torchscript_model` 失败时抛异常；关节目标设置移到 `actuators.target_command` | 发布页没有列出。本站实测到的：`visualizer[a,b]` 选择器仍被静默跳过；文档与代码不一致的三处见下文 |

*表 1：3.0 各版本。日期为各 tag 的提交日期（`git log -1 <tag>`；v3.0.0 的 GitHub 发布页时间为 2026-10-20 UTC）；Isaac Sim 与 Python 版本取自各 tag 内安装页开头的版本徽章[^install]；beta、beta2、beta2.patch1 的其余各列取自 tag 内的发布说明副本[^rn]；EA 的各列取自 EA 发布页[^ea-rel]；v3.0.0 的各列取自正式版发布页的"Changes since Early Access"与"Upgrading from Isaac Lab 3.0 Early Access to 3.0 GA"两节[^ga-rel]，以及迁移文档[^migr]，"官方任务多数默认 Newton"是本站统计（[8.1](8.1-what-changed.md) 图 1）。*

EA 阶段只做 bug 修复、稳定性、兼容性与文档，NVIDIA 当时写的 GA 目标是 2026 年 10 月底[^ea-rel]；正式版于 2026-10-19 发布。之后的版本计划，NVIDIA 没有公开说明，本站不作预测。

### 文档与代码不一致的地方

本站在 v3.0.0 上实测，以下三处官方文档的说法与代码不符。页面以代码与实测为准，并在对应位置注明：

| 文档的说法 | v3.0.0 的实际行为 | 本站页面 |
|---|---|---|
| 迁移文档与发布页：`--headless` 不再关掉可视化器，与 `--viz` 相互独立；Kit 无头录像要加 `--enable_cameras`[^migr-headless] | `isaaclab train` 与 `add_launcher_args` 都没有 `--headless`、`--enable_cameras`，传入即 `unrecognized arguments`，返回码 2（EA 时也是这样） | [8.4](8.4-migration-23-30.md#迁移清单总表)、[8.7 坑三](8.7-isaaclab-cli.md#常见坑) |
| Visualization 页："Most tasks default to a PhysX backend"[^viz-default] | 45 个官方任务里 44 个默认 Newton，没有一个默认 Isaac Sim PhysX | [8.1](8.1-what-changed.md) 图 1 |
| `isaaclab train --help` 的用法行把 `--rl_library` 写成必填 | 省略时用任务注册的 `default_agent`，照常训练 | [8.7](8.7-isaaclab-cli.md#train--play参数分三层) |

*表 2：v3.0.0 中文档与代码不一致的地方（本站实测，2026-10-23）。*

## 要不要升级

这一节回答：现在该不该换到 3.0？

| 场景 | 建议 |
|---|---|
| 研究、尝鲜 | 可以另装一套 3.0（[1.5](../1-env/1.5-install-61-30.md)），与 2.3 的环境并存，用来学新架构 |
| 生产训练 | 本站主线暂仍是 5.1 + 2.3.2；3.0 正式版刚发布，是否切换正在评估。按 [1.2](../1-env/1.2-version-decision.md) 的决策树判断自己的情况 |
| 与真机联调 | 继续用已经验证过的 2.3.2。迁移会改四元数顺序、数据接口与检查点格式，旧的策略要转换后重新评估（[8.4](8.4-migration-23-30.md)、[8.10](8.10-physx-newton-transfer.md)），不宜在联调期间切换 |

*表 4：升级建议（经验性）。决策树见 1.2，这里不重复。*

## 本页如何维护

这一节回答：Isaac Lab 发布新的 3.0 版本时，怎么更新这张表？

1. **列出新 tag 与核对范围**：记下新 tag 的名字、日期与要求的 Isaac Sim 版本，按表 3 圈出要核对的页面。
2. **只读新 tag 的文件，逐页核对**：用 `git show <新 tag>:<路径>` 读文件，不切换已有的检出；在表 1 加一行，按表 3 逐页核对已写的 3.0 内容，有变化的页面一并修改，"最后核对"改为新日期。写了实测数字的页面要在新版本上重测。
3. **在另一个独立环境里复核后发布**：另建一个环境，逐格复核表 1 的新行与改过的页面，复现带数字的结论，确认无误后再发布。
