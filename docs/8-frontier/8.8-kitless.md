# Kit-less 工作流实测

:::{admonition} 基于 v3.0.0 正式版
:class: note

本页基于 Isaac Lab **v3.0.0** 正式版（2026-10-19），数字全部在正式版上重测（RTX 5090 32 GB、主机内存 62 GB、i7-14700KF，驱动 580.178.04，2026-10-23）。图 1–3 是 3.0 EA 时（2026-10-12）的截图，正式版上的同一组命令打印出同样的地址、得到同样形状的输出。最后核对日期 2026-10-23。
:::

:::{admonition} 学习目标
:class: lead-goals

- 知道 Kit 与 Kit-less 两条路线在启动、迭代速度、显存和内存上差多少
:::

## 能做什么，不能做什么

这一节回答：不装 Isaac Sim，哪些事能做？

Kit-less 指进程里不启动 Omniverse Kit，环境里也不必装 `isaacsim`。官方的说法是：可以只装 Isaac Lab，用 Newton 物理后端，完全不装 Isaac Sim[^ecosystem]。判断依据是"进程里有没有东西需要 Kit"，见 [8.7 坑二](8.7-isaaclab-cli.md#常见坑)：PhysX 预设、Isaac RTX 渲染器、Kit 可视化器（visualizer）、Kit 实验文件、livestream，只要用到一个，就得启动 Kit[^kit-sources]。

| 工作流 | Kit-less 下 | 依据 | 本站 |
|---|---|---|---|
| headless 训练（Newton） | 能。`physics=newton_mjwarp` 或任务默认的 Newton 预设 | 官方安装说明[^ecosystem] | 实测：Cartpole、Galbot reach 各 200 次迭代 |
| headless 训练（PhysX） | `physics=isaacsim_physx` 不能；`physics=physx` 会选 OvPhysX，要另装 `ov[ovphysx]` | 自动预设的解析逻辑[^physx-auto]；8.7 坑二 | 实测：没装时报 `ModuleNotFoundError`，装 `ov[ovphysx]` 后 Cartpole 能训 |
| Rerun / Viser 可视化 | 能，浏览器里看 | 可视化文档[^viz] | 实测（图 1、图 2） |
| Newton GL 可视化（OpenGL 窗口） | 能 | Newton GL 在没有显示器时改用 EGL[^newton-gl] | 实测：`--viz newton_gl`（及弃用别名 `newton`）跑通 2 次迭代，没有看窗口 |
| Kit 视口、导入对话框等图形界面 | 不能 | 资产导入文档[^import] | — |
| 相机：Newton Warp 渲染器 | 能 | 渲染器文档[^renderers] | 实测（表 2） |
| 相机：OVRTX（RTX 质量） | 能，要装 `ov[ovrtx]`；不能与 Kit 同进程 | 渲染器与可视化文档[^renderers][^viz-ovrtx] | 实测（图 3、表 2） |
| 相机：Isaac RTX、Replicator | 不能；正式版文档已把 Isaac RTX 标为旧版（legacy），推荐 OVRTX | 相机与渲染器文档[^camera][^renderers] | — |
| 录像 | 能：从相机传感器录，或用 Newton GL 可视化器 | 录像文档[^video] | 未测 |
| URDF / MJCF 转 USD | 能：换成独立的导入器，要装 `isaaclab[importers]` | 资产导入文档[^import] | 未测 |
| ROS 2 桥 | 不能（推断） | 3.10 用的 ROS 2 桥是 Isaac Sim 的扩展；正式版发布页把 ROS 桥列为需要完整 Isaac Sim 的功能[^ga] | — |
| 遥操作 | 部分：不带 `--xr` 时可以不用 Kit XR；带头显渲染的完整 XR 路径要 Kit | 遥操作文档[^teleop] | 未测 |

*表 1：Kit-less（不装 Isaac Sim）下各工作流（v3.0.0）。"本站"一列：实测在本页的路线 C 环境上做，"未测"只依据文档。*

## 本站的 Kit-less 环境

这一节回答：在 1.5 路线 C 的基础上，再装什么？

1.5 路线 C 只装了 Newton 与 rsl_rl。本页另加两个浏览器可视化器与 OVRTX 渲染器。下面在 Isaac Lab 源码目录里执行：

```bash
uv venv --python 3.12 --seed env30_kitless_c && source env30_kitless_c/bin/activate
uv pip install --upgrade pip
./isaaclab.sh -i 'newton,rl[rsl-rl],ov[ovrtx]'
./isaaclab.sh -i 'visualizer[rerun],visualizer[viser]'     # 两个可视化器分开写，见坑一
```

本站在正式版上分几次装（另加了 `ov[ovphysx]`），装好后环境约 12 GB，其中 `ovrtx` 一个包就有 2.6 GB；没有 `isaacsim`。主要版本：isaaclab 28.0.0、newton 1.6.1、rsl-rl-lib 5.5.1、torch 2.11.0+cu130、rerun-sdk 0.40.0、viser 1.1.1、ovrtx 0.5.1、ovphysx 0.6.4（本站实测）。安装时会提示 `isaaclab.sh is deprecated … Use 'uv run isaaclab' instead`，3.1 起要改用 `uv run isaaclab`。

在这个环境里，`isaaclab train --help` 不需要先接受 EULA（[8.7 坑四](8.7-isaaclab-cli.md#常见坑)只出现在装了 `isaacsim` 的环境）。

## 训练、回放与可视化

这一节回答：Kit-less 下训练和看结果是什么样的？

```bash
isaaclab train --rl_library rsl_rl --task Isaac-Cartpole-Direct --max_iterations 200
isaaclab play --rl_library rsl_rl --task Isaac-Cartpole-Direct --checkpoint latest --num_envs 16 --viz viser
isaaclab play --rl_library rsl_rl --task Isaac-Cartpole-Direct --checkpoint latest --num_envs 16 --viz rerun
```

Cartpole 用任务默认的 4096 个环境，200 次迭代后平均回报 4.95。Galbot reach（[8.5](8.5-galbot-reach-30.md) 的 3.0 项目，`physics=newton_mjwarp`，1024 个环境）200 次迭代用时 1 分 21 秒（其中训练 71.9 s），训练日志里末端位置误差 4.20 cm，第一次启动就成功（EA 时用时 1 分 17 秒、误差 2.46 cm，也只跑了一次）。

`play` 会一直跑，直到按 Ctrl+C。带 `--viz viser` 时，启动后打印 `http://localhost:8080`；带 `--viz rerun` 时，打印一个带 `?url=…9876/proxy` 参数的完整地址，要原样打开（坑二）。

## Kit 与 Kit-less 的对照

这一节回答：同一个任务，装不装 Isaac Sim、用不用 Kit，差多少？

同一个任务（Cartpole Direct，4096 个环境，100 次迭代），三种组合各跑 2 次：

| 组合 | 启动到第一次迭代 | 每次迭代 | 显存（按进程） | 主机内存峰值 |
|---|---|---|---|---|
| 路线 A + `physics=isaacsim_physx`（启动 Kit） | 8.7 / 9.2 s | 111.5 / 109.2 ms | 3286 MiB | 4.8 GB |
| 路线 A + `physics=newton_mjwarp`（装了 Isaac Sim，不启动 Kit） | 7.2 / 7.6 s | 77.7 / 76.7 ms | 756 MiB | 2.5 GB |
| 路线 C + `physics=newton_mjwarp`（Kit-less） | 6.9 / 6.7 s | 68.4 / 68.6 ms | 756 MiB | 2.5 GB |

*表 2：Kit 与 Kit-less 的对照（本站实测，RTX 5090 32 GB，2026-10-23，独占 GPU 计时；开跑前与过程中每 30 s 记录 GPU 进程，只有被测进程）。每格是两次的值；每个环境先预热一次，不计入。"启动"是从启动命令到 rsl_rl 打印第一行迭代信息；"每次迭代"是相邻两行迭代信息的时间差，跳过前 10 次后取均值。脚本见 `examples/isaaclab-3.0/8.8-kitless/time_train.py`。显存与内存由外部每秒采样一次（`nvidia-smi` 按进程、`/proc` 的 VmRSS），取峰值。EA 时三行的每次迭代为 96、81、71 ms。*

从表 2 读出：

- **启动 Kit 的代价**：显存多约 2.5 GB，主机内存多约 2.3 GB；启动比路线 C 慢约 2 s。同样是 Cartpole，这两行物理后端也不同（PhysX 与 Newton），所以每次迭代的差别不全是 Kit 造成的。正式版上 PhysX 一行比 EA 时慢了约 14 ms，原因没有查。
- **只装不用，也有代价**：路线 A 跑 Newton 时不启动 Kit，显存与内存和路线 C 相同；但每次迭代慢约 9 ms，启动慢约 0.5 s。EA 时也是这样（慢 7–10 ms），原因仍没有查，推断与两个环境的包与导入路径不同有关。

相机渲染单独比较。用 Cartpole 的相机任务（`Isaac-Cartpole-Camera-Direct`，64 个环境，每个一台 96×96 的 RGB 相机），零动作推进 50 步：

| 渲染器 | 每步（物理 2 步 + 渲染一次） | 显存（按进程） | 主机内存峰值 |
|---|---|---|---|
| `renderer=ovrtx` | 5.01 / 4.96 ms | 3643 / 3589 MiB | 5.4–5.5 GB |
| `renderer=newton_renderer` | 1.08 / 1.08 ms | 690 MiB | 1.8 GB |

*表 3：两种 Kit-less 渲染器（本站实测，同表 2 的计时条件；每格两次，各先预热一次，前 10 步不计时）。脚本 `examples/isaaclab-3.0/8.8-kitless/ovrtx_frame.py`。装好 `ov[ovrtx]` 后第一次运行 OVRTX 用了约 5 分钟，主机内存峰值 13.9 GB，第二次起 10 s 左右；EA 时两行为 6.0、1.4 ms。*

```{figure} ../_static/img/8.8-ovrtx-tiled.png
:alt: 4×4 拼图：16 个环境的相机画面，黑色背景上的滑轨、小车与摆杆
:width: 384px

图 3：OVRTX 渲染的 tiled camera，前 16 个环境的 96×96 RGB 拼成 4×4（本站实测）。这个任务的场景没有地面和天空，所以背景是黑的，像素均值只有 3，不是渲染失败。
```

## 常见坑

:::{admonition} 坑一：`visualizer[rerun,viser]` 什么都没装，安装照样成功
:class: warning

`ov[...]` 的选择器会按逗号拆开，`visualizer[...]` 的不会：`rerun,viser` 被当成一个名字去找同名的依赖组，找不到，打印一行 `Unknown root extra 'rerun,viser' … Skipping.` 就跳过，整个安装仍以返回码 0 结束[^install-viz]（本站实测，EA 与正式版相同，正式版没有修）。要装两个可视化器，写成 `visualizer[rerun],visualizer[viser]`。装完用 `pip list | grep -E "rerun|viser"` 确认。
:::

:::{admonition} 坑二：Rerun 只开 9090 端口，看到的是欢迎页
:class: warning

`--viz rerun` 启动后，打印的地址是 `http://127.0.0.1:9090/?url=rerun%2Bhttp://127.0.0.1:9876/proxy`。只打开 `http://localhost:9090`，看到的是 Rerun 的欢迎页，没有仿真数据（本站实测）。9090 是网页查看器，9876 是数据端口[^rerun-cfg]，远程看时两个端口都要能访问。
:::

:::{admonition} 坑三：Galbot 在可视化器里看不见
:class: warning

用 8.5 的 3.0 资产回放 Galbot reach，Viser 里只有目标坐标轴。读回资产：144 个网格与 40 个球全是 `guide` 用途的碰撞体，没有可见网格（本站实测；正式版重新转换的资产相同，见 8.5）。训练不受影响，因为物理只用碰撞体；可视化器与相机只画可见几何，所以这台机器人什么都画不出来。推断原因是 8.5 用 3.0 转换器重新转换时没有带上 URDF 的可见网格，本页没有查。
:::

:::{admonition} 坑四：无头截图得到一片空白
:class: warning

Viser、Rerun 都在浏览器里用 WebGL 画图。本站用 headless Chrome 自动截图，默认是软件 WebGL，加上默认的虚拟时间截图，3D 视图是空的。改用 GPU（`--use-angle=vulkan`），再经 DevTools 协议真实等待 30 s 后截图，才有画面（本站实测）。在远程服务器上用这两个可视化器，要确认浏览器端有 GPU 加速。
:::
