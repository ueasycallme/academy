# 5.1 用一个任务理解 MDP：Cartpole 的一次 rollout

对应页面：`docs/5-rl/5.1-mdp.md`。

用 [-1, 1] 内的随机动作运行官方 Cartpole（4 个环境，种子 42），逐步打印 env 0 的动作、奖励、失败 / 超时标志和这一步之后的观测，直到 env 0 的第一个回合结束；然后算出这个回合的奖励之和与折扣回报（γ = 0.99，与官方 Cartpole 的 RSL-RL 配置相同）。

## 运行

在主线环境中（已激活 `env_isaaclab`）：

```bash
python examples/isaaclab-2.3/5.1-mdp/cartpole_rollout.py --headless
```

## 资源与耗时

每次约 8 秒，返回码 0（2026-09-30，RTX 5070，headless）。显存（按进程）：峰值 2315 MiB。测量方法：每 0.5 秒执行一次 `nvidia-smi --query-compute-apps=pid,used_memory --format=csv`，只累加本脚本进程树的用量。环境的 `close()` 会释放 SimulationContext，之后 flush，再关闭 app。
