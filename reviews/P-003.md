# P-003 独立复现报告：轮式自导入版 NaN 的原因

- 日期：2026-09-30
- 执行：校验方（isaac-academy-examine），**未使用实现方脚本**
- 探针：`reviews/scripts/P-003-nanprobe.py`，由项目的 `scripts/hold_pose.py` 改出，只加两个环境变量开关：`NO_GROUND=1` 不放地面，`ROOT_Z` 设根的初始高度；其余与 hold_pose 相同（固定根 `fix_root_link` 不适用于自导入版——其根本来就固定到世界；零目标保持 5 s；dt 1/120；GPU）
- 资产：6.1.2 `convert_galbot.py --variant wheeled` 的输出（滚子 `target_type="none"`，stiffness = damping = 0）；阻尼扫描在其副本上用 pxr 只改 40 个 `*_passive_*` 关节的 `drive:angular:physics:damping`（USD 单位为每度）
- 原始结果：`reviews/scripts/P-003-results.txt`

## 结论

**实现方的第 ④、① 项在校验方的独立复现中全部成立。** 根因是"固定根在 z = 0 且有地面、轮子压进地面"，不是"滚子阻尼为 0"。校验方在 T-6.1.3 中"阻尼改 0.1 后稳定"的结果，是恰好落在一个对阻尼非单调敏感的系统的稳定一侧，不能作为因果依据。按 CONVENTIONS 第 3 节新增的证据门槛，校验方原结论不成立，予以撤回。

## ④ 决定性对照（滚子阻尼 = 0，不变）

| 条件 | 3 次结果 |
|---|---|
| 根 z = 0，有地面 | NaN、NaN、NaN |
| 根 z = 0.05 m，有地面 | 有限 ×3，最大偏离 0.0355 rad（与固定底座版相同） |
| 不放地面 | 有限 ×3，0.0355 rad |

只改几何条件、不动阻尼，NaN 就消失——满足门槛中"不动 X、只改别的条件也能消除 Y"的对照，且结果完全可重复。

## ① 阻尼扫描（根 z = 0，有地面）

| 滚子阻尼（每度） | 对应每弧度 | 3 次结果 |
|---|---|---|
| 0.0087266 | 0.5 | 有限 ×3 |
| 0.0174533 | 1.0 | NaN ×3 |
| 0.10000736（转换器按 5.73 N·m·s/rad 写入的值） | 5.73 | NaN ×3 |
| 0.1（恰好） | 5.7296 | 有限 ×3 |

另有单次预跑：0.09 有限、0.11 有限、0.2 NaN、0.5 有限。结果**不单调**，0.1 与 0.10000736 仅差 7×10⁻⁶ 就分属两侧，说明系统处于临界、对微小差异敏感。阻尼扫描不满足门槛中"单调或有清晰阈值"，阻尼不是决定因素。

## 补充对照（校验方加做）

| 条件 | 3 次结果 |
|---|---|
| 阻尼 0.10000736（在 z = 0 时 NaN），根 z = 0.05 m | 有限 ×3 |
| 阻尼 0.2（在 z = 0 时 NaN），根 z = 0.05 m | 有限 ×3 |

在 z = 0 会 NaN 的阻尼值，抬高 5 cm 后都稳定：几何条件主导，阻尼只在临界区里左右运气。

- 同一条件 3 次结果完全一致（同机、同种子），这里的"混沌"指对参数的微小变化敏感，不是同一参数下随机。
