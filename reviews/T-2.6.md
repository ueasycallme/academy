## `.kit` 文件（v2.3.2 `apps/`）

- `isaaclab.python.headless.kit`：
  - 220 行；`[package]` 的 title 为 "Isaac Lab Python Headless"，version 为 "2.3.2"；
  - 两段 `[dependencies]` 共 19 项，含 `"omni.physx"`（L24）、`"isaacsim.core.api"`（L198）、`"isaaclab" = {order = 1000}`（L208）；
  - `[settings.physics] updateToUsd = false`（L155–156）；`app.useFabricSceneDelegate = false`（L80）。

  与页面的节选及"220 行、19 个扩展"一致。
- `isaaclab.python.headless.rendering.kit`：
  - title 为 "Isaac Lab Python Headless Camera"，description 为 "running Isaac Lab headlessly with rendering enabled"；
  - `[dependencies]` 的第一项是 `"isaaclab.python.headless" = {}`，接着是 `omni.replicator.core`；
  - `cameras_enabled = true`、`app.useFabricSceneDelegate = true`。

  与表 2 和误解一一致。

- **AppLauncher**：v2.3.2 `app_launcher.py` 中 `_resolve_experience_file`（L707 起）按 headless / 相机两个开关在四个 `.kit` 中选择，与表 1 一致；L823 把选好的文件传给 `SimulationApp`。
- **Isaac Sim 5.1.0（pip 安装的源码）**：
  - `isaacsim/__init__.py` 的 `bootstrap_kernel`（L70）设置 `EXP_PATH`（L106–107），把 `extsDeprecated/omni.isaac.kit` 加进路径（L119）；
  - `exception_handler` 与 `sys.excepthook` 的替换在 L227–259；
  - `simulation_app.py` 中默认体验文件的查找顺序在 L231–239，`update()` 在 L656 起；
  - pip 安装的 `apps/` 中没有 `omni.isaac.sim.python.kit`，所以落到 `isaacsim.exp.base.python.kit`。

  都与页面一致。
