## 三个主要发现的复核

| 发现 | 核查 | 结果 |
|---|---|---|
| ① `convert_mimic_joints_to_normal_joints` 效果与名字相反 | 源码 `urdf_converter.py` L150 `set_parse_mimic(cfg.convert_mimic_joints_to_normal_joints)`；实测：命令行（默认 False）下 `left_gripper_l_finger_joint` 带 DriveAPI、无 mimic；示例（True）下 10 个联动关节带 `physxMimicJoint:rotZ:*`，referenceJoint 指向 `left/right_gripper_joint`，gearing ±1，无驱动 | ✓ |
| ② 字典后面的键覆盖前面 | 源码 L187–L207 按 `dict.items()` 顺序对 `re.search` 匹配到的关节逐个 `set_target_type`；实测把示例字典顺序颠倒为 `{"wheel_.*_passive_.*": "none", ".*": "position"}` 后，`wheel_1_passive_0_joint` stiffness 1.745、damping 0.01745（被覆盖）；原顺序为 0 / 0 | ✓ |
| ③ MJCF 需 `--enable`，两个根，失败返回 0 | 见上表；`mjcf_converter.py` 无启用扩展代码，`urdf_converter.py` L63–L67 有；MJCF 中 `<equality>` 下 10 个 `<joint>` 约束，转换后 mimic 为 0 | ✓ |
