## 断言核查

- **Isaac Sim `isaacsim.core.cloner` 1.4.10**：
  - 从 GitHub tag v5.1.0 取下 `cloner.py`、`grid_cloner.py`，与 pip 包 cmp **逐字节相同**；
  - `clone()` 的默认值 `replicate_physics=False`、`copy_from_source=False`，docstring 说明继承与改源 prim 会反映到克隆；
  - L361–L372 正是"复制规格 / 在 inheritPathList 里加 source"的分支；
  - L73–L134 是 `replicate_physics()`，包含 `base_env_path`、`enable_env_ids`；
  - L49–L71、grid L82–L104 正确。
- **Isaac Lab v2.3.2**：
  - `interactive_scene.py` L141–L216 包含两条路径：replicate 关时先克隆 Xform（`copy_from_source=True`），开时 `clone_environments(copy_from_source=False)`；`enable_env_ids = filter_collisions if device != "cpu"`；
  - `interactive_scene_cfg.py` L87–L120：`replicate_physics=True`、`filter_collisions=True`、`clone_in_fabric=False`，并写明"必须通过 USDRT 访问"；
  - `simulation_cfg.py` L392–L431：`use_fabric=True`、`create_stage_in_memory=False`；
  - `manager_based_env.py` L141–L143 与 L170–L173：建场景和 `sim.reset()` 都包在 `use_stage(get_initial_stage())` 里，坑三成立。坑三的报错原文在实现方修改前那批日志中出现 6 次；把 reset 也包进去之后不再报错，这本身就构成对照。
- **官方 How-to "Optimize Stage Creation"**（v2.3.2，curl 200）：
  - "Stage in Memory Cannot be currently enabled at the same time as Fabric Cloning"；
  - 挂接到 USD 上下文可能很慢，只有渲染时才需要挂接；
  - 基准为"cloning 4000 ShadowHand robots with rendering enabled"；
  - 页面这三处说法都与原文一致。
- **算式**：1.18 / 0.43 = 2.74，"约 2.7 倍"正确。
- **卡片覆盖**：第 1–6 项都有；坑 4 个（≥ 3）；4.4、4.5、4.12、6.2.1 都有链接，anchors 0 问题。
