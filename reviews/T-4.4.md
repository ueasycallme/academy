## 问题：USD 不更新的原因

校验方用 `--kit_args="--/physics/updateToUsd=true"` 把体验文件的设置改回 true，做了完整的对照（1 秒后 `xformOp:translate` 的 z）：

| updateToUsd | use_fabric | device | USD z |
|---|---|---|---|
| false（默认） | 任意 | 任意 | 10.000 |
| true | True | cuda:0 | 10.000 |
| true | False | cuda:0 | 10.000 |
| true | True | cpu | 10.000 |
| true | False | cpu | **4.889** |

结论：只有 `updateToUsd = true`、`use_fabric = False`、CPU 三个条件同时满足时，USD 属性才会跟随仿真；任何一个保持默认，都停在初值。体验文件的设置只是三者之一，不是"首要原因"。GPU 上即使另外两个条件都满足也不更新，这与 3.1 在纯 Isaac Sim 中的解释（GPU 管线不回读到 USD）一致。
