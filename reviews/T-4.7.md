## 重点：`effort_limit` / `velocity_limit` 及 `_sim` 变体（设计 session 指定重点）

| 字段 | 源码 | 与表 3 |
|---|---|---|
| `effort_limit` | actuator_base_cfg docstring：只用于显式模型内截断，None 时取 USD 值；隐式上与 `_sim` 等价。actuator_base.py：`effort_default = effort_limit(USD) if cfg.effort_limit is None else self.effort_limit_sim`，所以**只设 `_sim` 时模型内仍按 USD 值截断** | ✓（坑一成立） |
| `effort_limit_sim` | 求解器截断；None 时隐式取 USD、显式取 `_DEFAULT_MAX_EFFORT_SIM = 1.0e9`（actuator_base.py `if not self.is_implicit_model and self.cfg.effort_limit_sim is None`） | ✓ |
| `velocity_limit` | 隐式不使用：只设它时警告并置 None；与 `_sim` 都设且不等时 `ValueError`（actuator_pd.py L81–L101）；显式时 None 默认取 `velocity_limit_sim` | ✓（坑四成立） |
| `velocity_limit_sim` | 求解器速度上限，None 时隐式与显式都取 USD 值 | ✓ |
| `stiffness` / `damping` | None 时取 USD 值；隐式直接写入 PhysX，显式用于模型 | ✓ |
| 写回 PhysX | articulation.py `_process_actuators_cfg`（L1708–L1776）：以 USD 读出值作默认创建执行器；隐式写 stiffness/damping，显式写 0；两者都写 effort_limit_sim、velocity_limit_sim | ✓ |
