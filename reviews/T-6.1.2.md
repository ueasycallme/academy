## 重点：mimic 约束太软（新发现）

| 项 | 核查 | 结果 |
|---|---|---|
| 源码 | IsaacSim v5.1.0 `UrdfImporter.cpp` L907–L915：`PhysxMimicJointAPI` 的 gearing = −multiplier，并新建 `physxMimicJoint:rot*:naturalFrequency` / `dampingRatio`，值取自 `joint.drive.naturalFrequency` / `dampingRatio`；`UrdfTypes.h` L288–L295 默认 25.0 与 0.005 | ✓ |
| 反证与剂量关系 | 校验方自建探针（`reviews/scripts/T-6.1.2-mimic-probe.py`：在检查脚本基础上把夹爪阶段延长到 5 s、可关重力、输出最大跟随误差），对复制出的 USD 分别改写 mimic 参数：默认 25 / 0.005 有重力 **1.242**、无重力 **0.000**；100 / 1.0 **0.212**；250 / 1.0 **0.039**；1000 / 1.0 **0.004**（rad）——与表 3 逐项相同 | ✓ |
| 修正措施 | `stiffen_mimic_joints()` 写入入口 `galbot.usd` 根层，check 输出跟随误差 ≤ 0.004 rad | ✓ |
