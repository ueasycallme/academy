**改动前后对比**：同时用 HEAD 的 CSS 构建了一份。

- 6.4.2 的前置知识框高度从 83 px（三行，其中顿号单独占一行）降到 56.5 px（两行）。

**目检**：
- 1440 与 2560 下，6.4.2 两项各占一行、左边对齐，没有顿号；0.3 单项页的外观与原来相同。

**构建**：`tools/check_head_build.sh --worktree`（-W）通过。

## 观察（不影响本卡，交设计决定）

CSS 加的顿号已经去掉，但有 12 页共 13 处，作者在同一项里用"、"把两三个链接写在了一起，这些顿号是正文内容，不归 CSS 管。例如 4.9 的 `[4.3 configclass](…)、[4.5 InteractiveScene](…)`。这些页面会显示成"一行里两个链接、中间一个顿号"，不会有顿号单独成行。

用户的原意是"多项时不用顿号相连，直接换行"，如果按这个意思统一，需要把这些项拆成多项。涉及的页面：

- 4.4、4.9、4.13
- 5.6、5.7
- 6.1.6
- 7.1（两处）、7.3
- 8.1
- 1.4
