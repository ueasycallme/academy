## 目标

读者花 3 分钟读完本页，能回答四个问题：这套体系解决什么问题、主要由哪几块组成、我的代码会写在哪一层、我该从本站哪里读起。本页是 0.2–0.7 的索引，不展开细节。

## 必须覆盖

1. **一句话定义**：Isaac 体系是 NVIDIA 面向机器人研发的 GPU 仿真与学习工具链，核心是 Isaac Sim（仿真器）和 Isaac Lab（机器人学习框架）。
2. **一张总图**：比 0.2 的分层图更简化，只有 4–5 个方块（Isaac Sim / Isaac Lab / 你的任务与项目 / RL-IL 库 / 真机与 ROS 2），一屏内。
3. **它解决什么问题**：大规模并行仿真、真实感渲染与合成数据、标准化的任务定义与训练流程、sim2real。每条一句话，不展开。
4. **典型工作流一句话版**：资产 → 场景 → 任务 → 训练 → 评估 → 部署，链接第 6 部分主线项目入口。
5. **本站怎么读**：链接 0.7 学习路线图；说明主线版本（5.1.0 + 2.3.2）与第 8 部分 3.0 专栏的关系；说明与 isaac.kiloong.com 翻译站的分工。
6. **0.2–0.8 的导航列表**，每项一句话。
