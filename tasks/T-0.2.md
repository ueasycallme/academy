## 目标

这是全站的样板页，也是"全景地图"的核心页。读者读完后能说清：Isaac 体系从驱动到 RL 库有哪些层，每层是什么、由谁维护、版本如何相互绑定，以及 3.0 的 Newton 路径改变了什么。

本页同时用来定型页面形态：结构、语气、图的风格、来源标注方式。校验时对形态的意见与对内容的意见分开列。

## 必须覆盖

1. **分层图**（自底向上），每层一句话说明角色：
   - GPU 驱动 / CUDA
   - Omniverse Kit（SDK 与运行时；Isaac Sim 是一个 Kit 应用）
   - Kit 之上的三大基础：OpenUSD（场景数据）、PhysX（物理）、RTX 渲染
   - Isaac Sim（Kit 应用 + `isaacsim.*` 扩展集；提供 Python API、导入器、传感器、ROS 2 bridge 等）
   - Isaac Lab（纯 Python 框架，`isaaclab.*`；环境抽象、并行张量化、任务库、RL 库适配）
   - RL / IL 库（rsl_rl、skrl、rl_games、SB3、robomimic）
   图中标出**用户代码通常落在哪一层**（Isaac Lab 之上的任务/项目，或直接用 Isaac Sim API）。
2. **每层由谁维护、以什么形式分发**：Kit/Isaac Sim 由 NVIDIA 闭源分发（二进制、pip 包 `isaacsim`、容器）；Isaac Lab 开源（BSD-3，GitHub）；OpenUSD 开源；PhysX 的 SDK 开源但 Isaac Sim 内置版本随 Kit 分发；RL 库各自独立。
3. **版本绑定链**：为什么 Isaac Lab 版本锁定 Isaac Sim 版本、Isaac Sim 锁定 Kit 版本、Kit 锁定 Python 版本；给出主线组合（5.1.0 / 2.3.2）与前沿组合（6.1 / 3.0.0-EA）的具体链条，包括 Python 版本。数字必须来自官方 release notes 或安装文档，并链接 `1.1 版本兼容矩阵`（可先做占位链接）。
4. **3.0 的变化**：Isaac Lab 3.0 引入多物理后端，Newton 后端可以不经过 Kit/PhysX 运行（Kit-less）。在图上以虚线或第二张小图表示这条新路径。标注"3.0.0-EA，可能变动"，链接第 8.1 页（占位）。
5. **一个常见误解澄清**（至少三条，用 `warning` 提示框）：例如"Isaac Lab 是 Isaac Sim 的一个模块"、"装了 Isaac Sim 就有 Isaac Lab"、"Isaac Gym 和 Isaac Sim 是同一个东西的新旧版本"。
6. **延伸阅读**：Isaac Sim 官方架构/概览页、Isaac Lab 官方概览与安装要求页、Isaac Lab 3.0 release notes、Kit 文档入口、isaac.kiloong.com 对应页面。
