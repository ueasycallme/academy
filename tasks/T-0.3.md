# T-0.3 产品谱系与改名史

状态: 已合并
优先级: P1
类型: 概念页

产出: `docs/0-map/0.3-lineage.md`（替换占位页）

## 目标

读者搜到任何一份 Isaac 相关资料，都能判断它属于哪个时代、在主线版本上还能不能用、该怎么换算到现在的名字。

## 必须覆盖

1. **时间线图**（Mermaid timeline 或 gantt，一屏内），两条线并列：
   - 学习框架线：Isaac Gym（独立预览版）→ IsaacGymEnvs → OmniIsaacGymEnvs → Orbit → Isaac Lab 1.x → 2.0 → 2.3 → 3.0-EA
   - 仿真器线：Isaac Sim 2022.x / 2023.x → 4.0 → 4.5 → 5.0 → 5.1 → 6.0 → 6.1
   每个节点标年份/月份，**日期必须来自官方 release notes、GitHub release 或官方公告**，查不到确切月份的只写年份并注明。
2. **每个已废弃项目的状态表**：名称、维护状态、官方给出的替代品、来源。Isaac Gym 与 OmniIsaacGymEnvs 的废弃声明要引用官方原文位置。
3. **三次关键改名**及其在代码里的表现：
   - `omni.isaac.*` → `isaacsim.*`（Isaac Sim 4.5），口径按 D-009
   - `omni.isaac.orbit` → `omni.isaac.lab` → `isaaclab`（Orbit → Isaac Lab 1.x → 2.0），给出每次改名对应的版本与来源
   - Isaac Lab 仓库/文档地址的变化（如有）
4. **"看 import 判年代"速查表**：给出 5–8 行典型 import 语句，对应"属于哪个时代、在 5.1+2.3.2 上的状态（可用 / 弃用可用 / 不可用）、换算后的写法"。
5. **常见误解**（warning，至少 3 条）：如"Isaac Gym 是 Isaac Sim 的旧版本"、"Orbit 是另一个框架"、"OmniIsaacGymEnvs 还在维护"。

## 不在本页范围

分层依赖（0.2）、非仿真类 Isaac 产品（0.4）、迁移操作细节（第 8 部分 8.4 只管 2.3→3.0）。

- 日期无官方来源时标"推断：依据 GitHub tag 日期"。
