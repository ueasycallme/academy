# T-0.5 Isaac Sim 与 Isaac Lab 的边界

状态: 待实现
优先级: P1
类型: 概念页
依赖: T-0.2 通过
产出: `docs/0-map/0.5-sim-lab-boundary.md`（替换占位页）

## 目标

读者面对一个需求时能判断"这件事该在 Isaac Sim 层做还是 Isaac Lab 层做"，并理解 Isaac Lab 对 Isaac Sim 做了哪些封装、隐藏了什么、又暴露了什么。

## 必须覆盖

1. **职责划分表**：场景与资产加载、物理步进、传感器、渲染、并行环境克隆、观测/奖励/终止、RL 库对接、GUI 交互、ROS 2 —— 每项标"Isaac Sim 提供 / Isaac Lab 封装 / Isaac Lab 新增"，并给源码或文档来源。
2. **对应关系表**（v2.3.2 源码为准）：`isaaclab.sim.SimulationContext` 与 `isaacsim.core.api.SimulationContext` 的关系；`isaaclab.sim.spawners` 与 `isaacsim.core.utils.prims`/USD API；`isaaclab.assets.Articulation` 与 PhysX tensor API（`omni.physics.tensors`）；`isaaclab.scene.InteractiveScene` 与 Cloner。每行给源码 permalink（tag v2.3.2）。
3. **什么时候直接用 Isaac Sim API**：给出 3 个典型场景（如：单机器人交互式调试、非 RL 的数字孪生、自定义传感器），以及从 Isaac Lab 代码里"下探"到 Isaac Sim API 的方式（`sim.stage`、`prim_utils` 等），并提醒张量视图与 USD 写入的一致性问题（来源或标推断）。
4. **两个入口的对比**：Isaac Sim GUI + 脚本编辑器 vs standalone Python（Isaac Lab 只走后者），以及 `AppLauncher` 做了什么。
5. **命名空间速查**：`isaacsim.*` 与 `isaaclab.*` 顶层包各一行说明，链接 3.11 与 4.2 页（占位）。
6. **常见误解**（至少 3 条）：如"Isaac Lab 是 Isaac Sim 的模块"（本页展开）、"Isaac Lab 里不能用 Isaac Sim API"、"改 USD 就能改并行环境里的物理参数"。

## 来源要求

对应关系表以 v2.3.2 源码为准，permalink 带 tag；Isaac Sim 侧以 5.1.0 文档为准。

## 验收标准

- 篇幅 1500–2500 字。
