**来源获取方式**：Isaac Lab 2.0–2.3 各版本的安装页、README 与 setup.py 均用本地仓库 `git show <tag>:<path>` 读取，脚注给出对应 tag 的 GitHub permalink（含行号）。Isaac Sim 的 Kit 版本读自 IsaacSim 仓库各 tag 的 `deps/kit-sdk.packman.xml`，或 Release Notes。Python 与 pip 包版本取自 PyPI JSON。

**需要校验方留意的几点**
1. **2.0.x / 2.1.x / 2.2.x 的 Windows 驱动，以及 2.0 / 2.1 的 Linux 驱动写"—"**：这些版本的安装页只链接 Omniverse Technical Requirements（滚动更新的页面），没有写版本号，无法对应到当时的值。脚注 `[^drv-old]` 已说明。
2. **2.0 / 2.1 的操作系统**：徽章写 Ubuntu 20.04，正文又建议 Ubuntu 22.04 使用 pip 安装，所以写成"Ubuntu 20.04 / 22.04"。
3. **3.0 的 PyTorch 有两个值**：v3.0.0-EA tag 的 `pyproject.toml` 锁定 2.11.0，与 Release Notes 一致；而当前 3.0 安装文档（release/3.0.0 分支，EA 之后更新）的安装命令是 `torch==2.12.0`（cu130）。两者都列出并给来源，没有取舍。
4. **Isaac Sim 4.5 与 5.0**：官方文档站 `/4.5.0/`、`/5.0.0/` 已返回 404。5.0 的 Kit（107.3.1）从源码仓库 packman 文件取得；4.5 的 Kit 以及 4.5、5.0 的二进制、容器分发无法从官方页面核实，写"—"并说明。4.5 没有公开源码仓库。
5. **6.0 的 Kit**：6.0.0 为 110.1.1，6.0.1 为 110.1.2（packman），6.1 Release Notes 的"110.1.2 → 110.3.0"与之一致。
6. **"三步判断"第 1 步的 580.65.06 阈值**：依据 2.3.2 与 3.0 两个安装页的推荐值。措辞写的是"按官方推荐不应使用"，没有写"不能运行"。
