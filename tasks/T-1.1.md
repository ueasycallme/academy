## 必须覆盖

1. **主表**：行 = Isaac Lab 版本（2.0.x、2.1.x、2.2.x、2.3.x、3.0.0-EA），列 = 支持的 Isaac Sim 版本、Python、PyTorch（含 CUDA 后缀）、最低/推荐驱动（Linux 与 Windows 分列）、支持的 OS、发布日期。每格来源：Isaac Lab 各版 README 版本表、installation 页、release notes；Isaac Sim requirements 页；PyPI `requires_python`。查不到的格写"—"并注明。
2. **Isaac Sim 侧子表**：4.5 / 5.0 / 5.1 / 6.0 / 6.1 各自的 Kit 版本、Python、pip 包版本号（如 5.1.0.0）、二进制/pip/容器三种分发是否提供。
3. **RL 库版本**：v2.3.2 `isaaclab_rl/setup.py` 声明的 rsl_rl、skrl、rl_games、SB3 版本约束；`isaaclab_mimic` 的 robomimic 版本。给 permalink。
4. **本站主线与前沿组合**两行高亮。
5. **"我的环境能跑哪个"三步判断**：先看驱动，再看 Python，再看 Isaac Sim 版本；配一句到 1.2。
6. 表下方"更新记录"小节：本表随版本发布追加，写明最后核对日期。
