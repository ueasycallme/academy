# T-1.2 版本选择决策树

状态: 待实现
优先级: P1
类型: 概念页
依赖: T-1.1
产出: `docs/1-env/1.2-version-decision.md`

## 目标

读者回答 4–5 个问题后，得到"你应该装哪套组合"的明确建议，以及理由。

## 必须覆盖

1. **决策树图**（Mermaid flowchart，D-017：流程图左→右或上→下均可，一屏内）：分支依据 = 目标（学习/复现论文/新项目/3.0 新特性）、硬件（显卡与驱动）、是否已有 2.x 代码、风险承受度（EA 可接受与否）。叶子为：5.1.0 + 2.3.2（主线）、6.1 + 3.0-EA（前沿）、4.5 + 2.x（仅为复现旧论文时）。
2. **每个叶子一段理由**，引用 D-001 的依据（3.0 EA 状态、破坏性变更）与 1.1 表。
3. **两套并存**：一台机器同时装主线与前沿的建议（独立 conda/venv，Python 3.11 vs 3.12），链接 1.4、1.5。
4. **常见误解**（≥ 3）：如"新版本一定更好"、"Isaac Lab 3.0 可以配 Isaac Sim 5.1"、"装了 6.1 就能跑 2.3.2 的例子"。
5. **切换时机**：3.0 GA 后本站主线会切换的说明，链接 8.6。

## 验收标准

- 决策树每条分支的判断依据可在 1.1 或 D-001 找到。
- 篇幅 1000–1800 字。
