## 前提（设计方核对后在附记写明）

- `docker --version`、`docker compose version`、`nvidia-ctk --version` 都能输出；`docker run --rm --gpus all ubuntu nvidia-smi` 能在容器里看到 RTX 5090。
- 当前用户在 `docker` 组。session 的 shell 是在加组之前启动的，`id -nG` 里可能还没有 `docker`；这时用 `sg docker -c '<命令>'` 执行 docker 命令，不要 `sudo`，也不要改任何系统设置。
- 磁盘：镜像约 10–20 GB，现有空闲 386 GB，够用；仍按 `implementer-disk-guard` 规则给构建与运行加 `timeout`。
