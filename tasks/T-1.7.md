## 目标

读者看完能回答："同一个 Isaac Sim 5.1.0，官方给了三种拿到它的方式，它们装的是不是同一个东西？我该选哪种？"本站主线用 pip（1.4），本页解释为什么，以及什么情况下该换。

## 必须覆盖

1. **三种方式各是什么**：Workstation 二进制包（zip）、pip 包（`isaacsim[all,extscache]`）、容器镜像（NGC）。每种：怎么拿到、落在哪个目录、启动入口是什么（`isaac-sim.sh` / `isaacsim` 命令 / `docker run`）。只给一张对照表 + 每种一段，不写安装步骤（二进制与容器各链接官方安装页，pip 链接 1.4）。
2. **`isaacsim` pip 包的本质**：它与二进制包是同一套 Kit 扩展的另一种打包，差异在于 Python 解释器（pip 用你自己的 venv 解释器，二进制自带 `python.sh`）与扩展缓存位置（`extscache`）。用 1.4 装好的环境实测：`isaacsim` 包的 site-packages 目录结构、`EXP_PATH` / `ISAAC_PATH` 等环境变量在三种方式下分别指向哪里（pip 方式实测，另两种引官方文档）。
3. **Isaac Lab 对三种方式的态度**：Isaac Lab 2.3.2 的 `isaaclab.sh` 如何找 Isaac Sim（`_isaac_sim` 符号链接 vs pip 检测），文档里官方推荐哪种、各自支持到什么程度（来源：Isaac Lab v2.3.2 安装文档与 `isaaclab.sh` 源码 permalink）。
4. **选择指南**：按场景给结论——个人开发机、多版本并存（回链 1.2"两套并存"）、服务器 / 集群 / CI（指向 1.6、7.1）、需要 GUI 调试。一张决策表或短流程图（D-017 左→右）。
5. **缓存与目录一览**（并入 `tasks/T-1.7-notes.md` 的两条）：`~/.cache/ov`（Kit 缓存、shaders / texturecache，校验方实测 180–750 MB + 0.86 GB）、`~/.local/share/ov`、`~/.nvidia-omniverse`、日志目录；三种方式下这些目录是否相同；清理哪些安全。pip 方式实测，另两种引官方文档并标"未验证"。
6. 常见误解 ≥ 3（候选：pip 包是"轻量版"；三种方式可以混用同一份 Isaac Lab；容器里不能用 GUI）。

## 验收标准

第 2、5 项的 pip 方式数字与路径为本站实测（写明机器与日期）；二进制 / 容器的断言逐条有官方文档来源；1.2、1.4、1.6、7.1 链接可达。校验不需要安装二进制或容器，只核来源与 pip 实测。
