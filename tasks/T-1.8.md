2. **运行与调试配置**：`launch.json` 两种：直接 `python` 启动 headless 脚本（环境变量、`--headless` 参数）；attach 到已启动进程（`debugpy`，回链 7.3 的最小配置）。各实测一次（2026-10-09 裁断：用 debugpy 的 DAP 适配器按 launch.json 字段发 launch / attach + setBreakpoints 验证，记调用栈文本；VS Code 界面操作不做）；界面截图改为可选——用户若自行装 Python 扩展截一张则补上，否则标"未验证"。
3. **远程开发**：Remote-SSH 到 GPU 机器的要点（端口转发回链 7.1、不要在远程开 GUI、扩展装在远程端）；本站只有一台机器，用 SSH 到本机模拟不可行（7.1 已说明），所以这一节以官方 Remote-SSH 文档为据，标"未验证"。

5. **其他工具一句话各**：Jupyter（Kit 进程里能不能用）、pre-commit / ruff（Isaac Lab 仓库自带的配置）、`isaaclab.sh -p` / `-s` 这类入口（pip 方式下的替代）。
6. 常见坑 ≥ 3（候选：选错解释器导致 import 失败；Pylance 对 Kit 懒加载的模块报错；在 GUI 模式打断点卡死——回链 7.3）。
