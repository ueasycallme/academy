## 必须覆盖

1. **格式**：每条为一个三级标题 = 错误信息关键句（原文，便于搜索），下面固定三行：现象 / 原因 / 解法，末尾来源或"本站实测"。
2. **首批条目（≥ 12）**，来源优先级：本站实测（reviews/ENV.md、各校验报告）> Isaac Lab 官方 FAQ/troubleshooting 页 > GitHub issues（标注 issue 号）> 论坛。至少包含：
   - `ModuleNotFoundError: No module named 'omni.isaac.kit'`（D-009 补充口径：pip 下须先 `import isaacsim`）
   - `import isaaclab` 得到空包 / `__file__ is None`（editable 路径失效）
   - EULA 交互卡住（`OMNI_KIT_ACCEPT_EULA`）
   - ROS 2 的 PYTHONPATH 污染
   - 驱动版本不满足
   - Python 版本不匹配（`requires_python ==3.11.*`）
   - 首次启动长时间无输出（着色器缓存）
   - GLIBC / libstdc++ 相关（有来源才写）
   - Vulkan / 显示相关（headless 与 GUI）
   - 显存不足（CUDA OOM）与 num_envs
   - `isaaclab.sh` 找不到 Isaac Sim
   - 扩展加载失败 / extscache 缺失
3. **通用排障顺序**一节：先看什么日志、日志在哪、如何最小化复现。
4. **如何提问**：向官方论坛/GitHub 提 issue 时需要附的信息清单。

- **本站实测条目**（2026-09-30，clean14 干净环境 `scratch/clean14/env_isaaclab` 与校验环境 `isaac_sim_h1/.venv`）：
  1. 系统 Python 3.10.12 执行 `pip download "isaacsim==5.1.0" --extra-index-url https://pypi.nvidia.com`，报 `No matching distribution found`，可用版本 4.0.0.0–4.5.0.0。
  2. 未激活环境（`env -u CONDA_PREFIX -u VIRTUAL_ENV`）运行 `./isaaclab.sh -p -c "print(1)"`，报 `Unable to find any Python executable at path: '.../_isaac_sim/python.sh'`。
  3. 不先 `import isaacsim` 时，`from omni.isaac.kit import SimulationApp` 报 `No module named 'omni'`；先导入后成功，并打印弃用警告。符合 D-009 的补充口径。
  4. 校验环境 editable 失效：一般目录下报 `No module named 'isaaclab'`；cwd 为 `IsaacLab/source` 或 `/tmp`（有 `/tmp/isaaclab` 日志目录）时 `__file__` 为 None，`from isaaclab.app import AppLauncher` 报 `No module named 'isaaclab.app'`。注意 ENV.md 写的是"得到空的 namespace 包"，实测只在 cwd 为 `source/` 时如此，页面两种情况都写了。
  5. EULA：取已安装包 `kit_app.py` 中的 `check_eula` 单独运行，stdin 为 /dev/null 时报 `EOFError: EOF when reading a line`。确认结果写入 `isaacsim/kit/EULA_ACCEPTED`。
  6. `env -u DISPLAY` 下以 `headless=False` 启动 SimulationApp：打印 `DISPLAY environment variable is not set...` 与多条 `GLFW initialization failed`，程序正常运行并完成 20 次 update（81 秒）。源码为 `simulation_app.py` L447–L457。
  7. Kit 日志含 `Driver Version` / GPU 表；pip 安装时着色器缓存位于 `isaacsim/kit/cache/nv_shadercache`；Isaac Lab 日志位于 `/tmp/isaaclab/logs/`。
  8. SIGTERM：clean14 运行中 `timeout 600 python create_empty.py` 记录 `STEP_TIME 1707s rc=124`。
  9. wheel 标签：`isaacsim-5.1.0.0.dist-info/WHEEL` 为 `cp311-none-manylinux_2_35_x86_64`。
- **标为推断的两处**：GLIBC < 2.35 时的 pip 表现（依据 wheel 标签，未在 20.04 实测）；离线且未装 extscache 时的失败（依据官方说明，没有报错原文，标题写现象）。另外 Kit 忽略 SIGTERM 的机制没有找到官方说明，已标推断。
