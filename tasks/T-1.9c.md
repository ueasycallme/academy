# T-1.9c 安装排障：flatdict / setuptools 构建失败

状态: 已合并

类型: 微任务（D-014，源自校验方 T-1.4 冷缓存复现）

## 背景（校验方实测，详见 reviews/T-1.4.md）

干净环境中 `./isaaclab.sh --install` 失败：isaaclab 2.3.2 依赖的 `flatdict==4.0.1` 在 PyPI 上只有 sdist，隔离构建时拉取最新 setuptools；setuptools 自 82.0.0 起移除了 `pkg_resources`，于是报 `ModuleNotFoundError: No module named 'pkg_resources'`。非 uv 特有：新建 venv + pip 26.2.1 + `--no-cache-dir` 同样失败；`PIP_CONSTRAINT` 对隔离构建不起作用。本机此前能装上是因为 pip 缓存里已有构建好的 flatdict wheel。

已实测可用的绕行：

```bash
pip install "setuptools<82"
pip install --no-build-isolation flatdict==4.0.1
./isaaclab.sh --install
```
