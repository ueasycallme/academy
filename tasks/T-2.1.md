# T-2.1 为什么是 USD

状态: 已合并
优先级: P1
类型: 概念页
依赖: 第 0 部分已合并
产出: `docs/2-usd-kit/2.1-why-usd.md`（替换占位页）

## 目标

读者理解 USD 解决什么问题、它和 URDF/MJCF/SDF 的根本区别，以及为什么 Isaac Sim 把一切都建立在它之上。读完应当不再把 USD 当成"又一种机器人描述格式"。

## 必须覆盖

1. **USD 是什么**：场景描述 + 合成引擎 + API，不只是文件格式；`.usd/.usda/.usdc/.usdz` 的区别一句话。来源：OpenUSD 官方文档。
2. **对比表**：URDF / MJCF / SDF / USD 在"描述范围（单机器人 vs 整个场景）、层级与引用、物理、外观与渲染、非破坏性编辑、多人协作、工具链"上的差异。每格有来源或标推断。
3. **对机器人仿真意味着什么**：同一份资产同时服务物理、渲染、合成数据；场景由引用组装；参数覆盖不改原文件（为 2.3 铺垫）。用 Galbot 仓库里同时提供 URDF/MJCF/USD 这一事实举例。
4. **代价**：学习曲线、概念多、调试工具不同；诚实写。
5. **Isaac Sim 与 USD 的关系**：Stage 即仿真世界；链接 0.2（USD 是 Kit 的组成部分）、2.2、2.4、3.5。
6. 常见误解 ≥ 3：如"USD 是 NVIDIA 的格式"、"导入 URDF 后 URDF 还在起作用"、"USD 文件就是一个 3D 模型"。

## 来源要求

OpenUSD 官方文档（openusd.org）、Isaac Sim 5.1.0 文档 USD 相关页、URDF/MJCF/SDF 各自官方规范页。
