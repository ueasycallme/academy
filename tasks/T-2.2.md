# T-2.2 USD 核心概念

状态: 待实现
优先级: P1
类型: 概念页（黄金路径第 3 站）
依赖: T-2.1
产出: `docs/2-usd-kit/2.2-usd-concepts.md`；示例 `examples/isaaclab-2.3/2.2-usd-concepts/`

## 目标

读者打开任意一个机器人 USD 文件，能看懂它的结构：Stage、Prim、Attribute、Relationship、Path、类型（Xform/Mesh/Scope…）、defaultPrim、单位与坐标轴。

## 必须覆盖

1. **五个核心概念**各一小节：Stage、Prim（含类型与 specifier）、Property（Attribute / Relationship）、Path（SdfPath 语法）、Metadata（defaultPrim、upAxis、metersPerUnit）。每节先一句话定义，再用 Galbot USD 的真实片段举例。
2. **Galbot 实例**：获取 `galbot_one_golf_description` 仓库（克隆到 `third_party/`，该目录加入 .gitignore；页面写明仓库地址、commit 与 Apache-2.0 许可）。打开 `usd/galbot_one_golf.usda`，展示：prim 树的前三层（用文本树或表格，不贴大段原文）、一个关节 prim 的属性、一个 mesh prim 的属性。片段 ≤ 15 行/处。
3. **两种查看方式**：纯 Python（`pxr`，无需启动 Isaac Sim 的写法若可行则给出，来源或实测）与 Isaac Sim GUI 的 Stage 面板（文字描述，截图可选）。示例脚本打印 prim 树与统计。
4. **单位与坐标系**：Isaac Sim 默认米、Z 轴向上；USD 默认值与之不同时会发生什么（来源：Isaac Sim conventions 页）。
5. **与 Isaac Lab 的连接**：prim 路径如何出现在 Isaac Lab 配置里（`prim_path="/World/envs/env_.*/Robot"`、`{ENV_REGEX_NS}`），链接 4.5 占位。
6. 常见坑 ≥ 3：路径大小写、defaultPrim 缺失、单位不一致。

## 来源要求

OpenUSD 术语表与 API 文档；Isaac Sim 5.1.0 conventions 页；Galbot 仓库（带 commit）。

## 验收标准

示例脚本在主线环境运行通过（校验方复跑）；Galbot 片段与仓库指定 commit 一致；篇幅 1500–2500 字。
