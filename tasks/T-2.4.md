# T-2.4 Schema：USD 如何描述物理

状态: 已合并
优先级: P1
类型: 概念页
依赖: T-2.2
产出: `docs/2-usd-kit/2.4-physics-schema.md`；示例 `examples/isaaclab-2.3/2.4-physics-schema/`

## 目标

读者理解"物理属性是通过 Schema 贴到 prim 上的"，能在 USD 里认出刚体、碰撞体、关节、关节驱动、Articulation 根，并知道 UsdPhysics 与 PhysxSchema 的分工。

## 必须覆盖

1. **Schema 是什么**：IsA schema 与 API schema 的区别；"apply API" 的含义。来源：OpenUSD 文档。
2. **UsdPhysics vs PhysxSchema**：前者是 USD 标准物理 schema，后者是 PhysX 专有扩展；各自覆盖什么。来源：OpenUSD UsdPhysics 文档、Omniverse PhysX schema 文档。
3. **对照表**：物理概念 → schema → 关键属性 → 在 Galbot USD 中的实例路径。至少：RigidBodyAPI、MassAPI、CollisionAPI（及 MeshCollisionAPI 的近似方式）、各类 Joint（Revolute/Prismatic/Fixed）、DriveAPI（stiffness/damping/maxForce）、ArticulationRootAPI、PhysicsScene、物理材质。
4. **示例脚本**：遍历 Galbot USD，列出每个 prim 应用了哪些物理 schema，统计刚体数、关节数、驱动数，找出 Articulation 根。
5. **和 URDF 的对应**：URDF 的 link/joint/inertial/collision/limit/dynamics 分别落到哪些 schema（对照表），为 3.5 铺垫。
6. **和 Isaac Lab 的对应**：`isaaclab.sim.schemas` 与 spawner cfg 中的 `rigid_props`、`articulation_props`、`collision_props` 写的就是这些 schema 属性；给 v2.3.2 源码 permalink。
7. 常见坑 ≥ 3：ArticulationRoot 放错位置、刚体嵌套、碰撞体未启用。

## 验收标准

对照表每行可在 Galbot USD 或官方 schema 文档中定位；示例脚本校验方复跑；篇幅 1500–2500 字。
