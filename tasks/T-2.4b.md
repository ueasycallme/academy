## 背景（校验方实测）

在 Isaac Sim pip 环境中，脚本输出重定向到文件或管道时几乎全部丢失（管道下只剩 2 行，终端下 7–8 行）。原因：`simulation_app.close()` 退出时没有刷新 stdout。2.2 与 2.4 的示例都受影响。

## 必须完成

1. 两个示例脚本在 `simulation_app.close()` 之前加 `sys.stdout.flush()`（按 CONVENTIONS 第 5 节新规则）。改后分别在终端、管道（`| cat`）、重定向到文件三种方式下运行，输出行数一致，结果写入附记。
2. 两个 README 的"预期输出"如有行数或片段，与修正后的实际输出核对。
3. 2.4 页表 3：`joint_drive_props` 一行补上它还会写 `PhysxJointAPI`（`max_velocity`），给 v2.3.2 源码 permalink。
4. 两页的"常见坑"各加一句指向 3.2（占位页即可）：重定向输出时要先刷新 stdout。

## 验收标准

三种运行方式输出一致（校验方复跑）；表 3 来源成立；`sphinx-build -W` 零警告。
