## 目标

读者会用 `pxr` API 读、遍历、修改、保存 USD，并知道这些操作在 Isaac Sim 进程内和进程外的差别。按 D-021，把 2.2 里"GUI 查看方式"一段与常见坑第 4 条迁到本页。

## 必须覆盖

1. **两种运行环境**：纯 `usd-core`（pip，不需 Isaac Sim，快）vs Isaac Sim 进程内（能看到 PhysX 相关 schema 与运行时属性）；各自怎么装、什么时候用。
2. **读与遍历**：打开 Stage、`Traverse`、按类型 / 路径筛选、读属性值与元数据；Galbot USD 上的实例（复用 2.2 示例并扩展）。
3. **修改与保存**：设属性、加 prim、应用 API schema、`Export` 与 `Save` 的区别、写到哪一层（回链 2.3）。
4. **常用小工具**：`usdcat`、`usdview`、`usdzip`（有则列）；Isaac Sim GUI 的 Stage / Property 面板（从 2.2 迁来）。
5. **脚本化资产检查**：把 2.4、6.1.3 的检查脚本抽象成"一个资产检查脚本应该查什么"的清单。
6. 常见坑 ≥ 3（含从 2.2 迁来的那条）。
