## 目标

读者理解 Kit 是什么、Isaac Sim 作为 Kit 应用意味着什么、`.kit` 文件在干什么。

## 必须覆盖

1. Kit = SDK + 运行时 + 扩展系统：三件事各一句话，来源 Kit 官方文档。
2. **应用即一组扩展**：`.kit` 文件是依赖清单 + 设置；用 Isaac Lab `apps/` 下两个 `.kit`（headless 与 headless.rendering，即 `--headless` 加不加 `--enable_cameras` 的差别；原卡片写 rendering，按实现方核对 app_launcher.py L727 改正）做对照，逐节解释（`[dependencies]`、`[settings]`、`[package]`）。
3. Isaac Sim 的启动过程：`SimulationApp` / `AppLauncher` 如何选择 `.kit`、加载扩展、Python 解释器嵌入（回链 3.2，D-009 的"先 import isaacsim"在此解释原因）。
4. Kit 的事件循环与 `app.update()`（回链 3.1）。
5. 设置系统：`carb.settings` 怎么读写，常见的几个设置（如 `physics.updateToUsd`，回链 4.4）。
6. 常见误解 ≥ 3。
