## 目标

读者理解 Isaac Sim 里"一步"由什么组成：物理步、渲染步、应用（Kit）更新之间的关系，以及时间是怎么推进的。0.6 讲的是 Isaac Lab 视角的 RL step，本页下探到 Isaac Sim 层。

## 必须覆盖

1. **三种"步"**：物理步（PhysX simulate/fetch）、渲染步、Kit 应用更新（app.update）；各自由谁触发。图：时序图上→下（D-017）。
2. **时间参数**：物理 `dt`、substeps、`rendering_dt`、time codes per second；Isaac Sim `SimulationContext`/`World` 的 `step(render=...)` 语义。来源：Isaac Sim 5.1.0 文档与 `isaacsim.core.api` 源码/文档。
3. **实时与非实时**：仿真时间 vs 墙上时间；headless 下为何可以快于实时；GUI 下帧率对物理的影响（有来源才写）。
4. **GPU 物理管线**：CPU 与 GPU 管线的区别、张量 API 为什么需要 GPU 管线、`device` 的含义。来源：Isaac Sim / PhysX 文档。
5. **与 0.6 的对接**：Isaac Lab 的 `sim.step()` 对应本页哪一步，decimation 循环里每次发生了什么；链接 0.6、4.4 占位。
6. **Timeline**：play/pause/stop 与 `sim.reset()` 的关系，为什么"没 play 物理不动"。
7. 常见误解 ≥ 3。
