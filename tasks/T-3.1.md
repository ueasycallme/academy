## 目标

读者理解 Isaac Sim 里"一步"由什么组成：物理步、渲染步、应用（Kit）更新之间的关系，以及时间是怎么推进的。0.6 讲的是 Isaac Lab 视角的 RL step，本页下探到 Isaac Sim 层。

## 必须覆盖

1. **三种"步"**：物理步（PhysX simulate/fetch）、渲染步、Kit 应用更新（app.update）；各自由谁触发。图：时序图上→下（D-017）。
2. **时间参数**：物理 `dt`、substeps、`rendering_dt`、time codes per second；Isaac Sim `SimulationContext`/`World` 的 `step(render=...)` 语义。来源：Isaac Sim 5.1.0 文档与 `isaacsim.core.api` 源码/文档。
3. **实时与非实时**：仿真时间 vs 墙上时间；headless 下为何可以快于实时；GUI 下帧率对物理的影响（有来源才写）。
4. **GPU 物理管线**：CPU 与 GPU 管线的区别、张量 API 为什么需要 GPU 管线、`device` 的含义。来源：Isaac Sim / PhysX 文档。
5. **与 0.6 的对接**：Isaac Lab 的 `sim.step()` 对应本页哪一步，decimation 循环里每次发生了什么；链接 0.6、4.4 占位。
6. **Timeline**：play/pause/stop 与 `sim.reset()` 的关系，为什么"没 play 物理不动"。
7. 常见误解 ≥ 3。

时序与 API 语义与 5.1.0 文档/源码一致；篇幅 1500–2500 字。

**本站实测**（2026-09-30，Isaac Sim 5.1.0 pip，RTX 5070，headless，`World(physics_dt=1/120, rendering_dt=1/60, backend="torch", device="cuda:0")`，一个 DynamicSphere 从 z=10 自由下落）：

- 未 play 时调用 10 次 `step(render=False)`，`current_time` 仍为 0。
- `reset()` 后调用 1200 次 `step(render=False)`：仿真时间 10.000 s，墙上时间约 0.70 s。位姿接口读到 z ≈ −482.5，vz ≈ −98.3（理论值 −480.5 与 −98.1）。
- 同一时刻 USD 属性 `xformOp:translate` 仍为 (0, 0, 10)，调用 `render()` 后仍然不变。这支撑了"GPU 管线下结果不写回 USD"。
- 调用 120 次 `step(render=True)`：仿真时间 2.000 s（= 120 × 1/60，substeps=2），墙上时间约 1.03 s。
- 附带发现：只用 `SimulationContext` 而不用 `World` 时，`DynamicSphere` 没有被初始化（位姿与速度都不变）。页面没有写这一点，可在 3.2 讲 World 与 SimulationContext 时使用。
