## 必须覆盖

1. **顶层包速查表**：`isaacsim.core.api`、`isaacsim.core.prims`、`isaacsim.core.utils`、`isaacsim.core.cloner`、`isaacsim.core.simulation_manager`、`isaacsim.sensors.*`、`isaacsim.robot.*`、`isaacsim.asset.importer.*`、`isaacsim.replicator.*`、`isaacsim.ros2.bridge`、`isaacsim.storage.native` 等。每行：一句话用途、最常用的 2–3 个类/函数、官方 API 文档链接。以 5.1.0 pip 包中实际存在的扩展为准（实测列目录）。
2. **底层包**：`omni.usd`、`omni.kit.*`、`omni.physx`、`omni.physics.tensors`、`omni.timeline`、`pxr.*`、`carb` 各一行，说明何时会直接用到。
3. **旧名 → 新名对照**：`omni.isaac.core` → `isaacsim.core.api` 等高频 15–20 项，来源为官方 extensions renaming 页；口径严格按 D-009（含"pip 下须先 import isaacsim"的前提）。
4. **Isaac Lab 用到了哪些**：v2.3.2 源码中 `import isaacsim` / `from isaacsim` 的统计（grep 实测，列出前 10 个模块及出现次数），帮助读者知道哪些 Isaac Sim API 值得学。
5. **如何自己查**：扩展管理器、`extscache` 目录、API 文档入口。
6. 6.x 上旧名状态：不下断言，链接 8.x（D-009）。
