# T-3.3 PhysX 物理：刚体与碰撞

状态: 待实现
优先级: P1
类型: 概念页
依赖: T-2.4
产出: `docs/3-isaacsim/3.3-rigid-collision.md`（替换占位页）

## 目标

读者知道刚体与碰撞的关键参数各管什么、调错了会表现成什么现象，为 6.1.4（Galbot 碰撞与惯量调校）做准备。

## 必须覆盖

1. **刚体**：质量、质心、惯量张量；kinematic vs dynamic；线/角阻尼、最大速度、休眠阈值、solver 迭代次数（position/velocity）。每项：含义、默认值（来源）、调大调小的现象。
2. **碰撞近似**：triangle mesh（仅静态）、convex hull、convex decomposition、SDF、基本体；各自的精度/性能/适用对象对比表。来源：Omniverse PhysX 文档。
3. **接触参数**：contact offset、rest offset；物理材质（静/动摩擦、恢复系数、combine mode）；穿透与抖动分别与哪些参数有关。
4. **碰撞过滤**：collision groups、自碰撞开关（Articulation 级）。
5. **PhysicsScene 全局参数**：重力、solver 类型（TGS/PGS）、GPU 缓冲区容量（报错信息与该调哪个参数，链接 1.9）。
6. **在 Isaac Lab 里的入口**：`RigidBodyPropertiesCfg`、`CollisionPropertiesCfg`、`PhysxCfg` 对应上述哪些参数，给源码 permalink。
7. **症状 → 参数速查表**：穿透、抖动、爆炸、滑动、粘连。标注"经验性"的条目写社区来源或标推断。

## 验收标准

默认值与 5.1.0 / v2.3.2 源码一致；篇幅 1500–2500 字（D-016）。
