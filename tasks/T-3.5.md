# T-3.5 资产导入：URDF 与 MJCF Importer

产出: `docs/3-isaacsim/3.5-urdf-mjcf-import.md`；示例 `examples/isaaclab-2.3/3.5-urdf-mjcf-import/`

## 目标

读者能把一个 URDF 转成可用的 USD，并理解每个导入选项改变了什么。本页讲通用方法，用 Galbot 作例子；Galbot 的完整资产流程在 6.1.x。

## 必须覆盖

1. **三条导入途径**：Isaac Sim GUI 的 URDF Importer、Isaac Sim Python API、Isaac Lab 的 `UrdfConverter` / `scripts/tools/convert_urdf.py`。对比表：适用场景、可重复性。来源：5.1.0 文档与 v2.3.2 源码。
2. **导入选项逐项说明**（以 Isaac Lab `UrdfConverterCfg` 字段为主线，给 permalink）：fix_base、merge_fixed_joints、joint_drive（类型、增益）、collider_type / convex decomposition、self_collision、make_instanceable、link_density 等。每项：含义、默认值、对生成 USD 的影响。
3. **实操**：用 `convert_urdf.py` 转 Galbot URDF（仓库指定 commit 的预置 URDF），给出命令、输出文件结构、耗时；用 2.4 的脚本统计刚体/关节/驱动数并与 URDF 对照。
4. **检查清单**：导入后必须检查的 8–10 项（Articulation 根、关节数、质量惯量、碰撞体、驱动增益、默认姿态、单位、网格路径）。
5. **MJCF**：`MjcfConverter` 的差异点与限制，一节即可；Galbot MJCF 是否能直接导入写实测结果（失败也如实写）。
6. **xacro**：如何先展开为 URDF。
7. 常见坑 ≥ 5，来源或本站实测（网格路径 `package://`、merge fixed joints 丢 link、惯量缺失等）。

转换命令校验方复跑成功；统计数字与 URDF 一致；代码头注明验证版本、日期、GPU；篇幅上限 3500 字（D-021：以"必须覆盖"为准，不因篇幅退回，也不必就篇幅再请示）。

- **URDF 解析**（commit 2d496b0）：104 个 link，103 个关节（33 revolute + 44 continuous + 26 fixed），10 个 mimic。58 个 link 没有 `<visual>`，13 个没有 `<inertial>`（含 `base_link`）。
- **Unresolved reference 警告**：`--merge-joints` 时出现 984 条，不合并时 1392 条。涉及的都是没有 `<visual>` 的连杆，不影响结果。
- **mimic 实测**：默认配置下 `left_gripper_l_finger_joint` 带有 DriveAPI，没有 mimic；设 `convert_mimic_joints_to_normal_joints=True` 后变为 `PhysxMimicJointAPI:rotZ`，没有驱动。依据为 urdf_converter.py L150。
- **字典顺序实测**：
  - `{"wheel_.*_passive_.*": "none", ".*": "position"}`：被动关节的增益仍为 1.745。
  - `{".*": "position", "wheel_.*_passive_.*": "none"}`：增益为 0。
  - 另外单独验证了顺序正确时，统一增益（不按正则分组）也会因 `none` 被置 0，所以示例里不需要给增益单独写字典。
- **其他**：
  - 合并后 TCP 的路径为 `/galbot_one_golf/left_arm_link7/left_arm_end_effector_mount_link/left_gripper_flange_link/left_gripper_base_link/left_gripper_tcp_link`。
  - 不合并时 `base_link` 的 `physics:mass` 为 0.0。
  - `left_arm_joint1` 的 maxForce = 60（即 URDF effort），stiffness 1.7453/deg（即 100 N·m/rad）。
  - MJCF 转换失败时返回码仍为 0；转换出两个 Articulation 根（`base_link` 与 `worldBody`），MJCF 的 10 个 equality 约束没有转成 mimic。
- 示例 `convert_galbot.py` 已按 CONVENTIONS 第 5 节在退出前 flush；它没有创建 SimulationContext，所以不需要释放。经管道运行时输出完整。
