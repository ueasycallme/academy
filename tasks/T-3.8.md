## 目标

读者分清"仿真"和"渲染"是两件事：什么时候需要渲染（相机观测、录像、截图、Replicator），什么时候该关掉（纯状态 RL），各种模式的代价差多少；以及材质 / 光照在 Isaac 里是怎么来的，为什么场景会"粉色"。

## 必须覆盖

1. **两种渲染模式**：RTX Real-Time 与 Path Tracing 的差别、各自适合什么（一张表）；怎么切（`--/rtx/rendermode` 等设置、GUI 位置）；与 `render_interval`（4.4 / 术语表）和 `--enable_cameras`、`--headless` 的关系：哪种组合下根本不渲染。
2. **代价实测**：Galbot 6.2 场景同一视角，① 不渲染（headless、无相机）② RTX RT ③ Path Tracing 低采样，各记每步墙上时间与按进程显存，一张表；结论按证据门槛写。
3. **材质与光照**：MDL / OmniPBR 是什么，USD 里材质绑定在哪（回链 2.2 / 2.4 的 schema 视角），缺 MDL 时的表现；主线资产从 URDF 来的材质是什么样（实测看一眼）；光源类型（dome / distant / sphere）各一句，默认场景的光从哪来（`sim_utils.DomeLightCfg`，6.2.1）。
4. **常见坑 ≥ 3**（实测优先；候选：训练时误开相机 / 渲染；headless 下截图是黑的（没等渲染）；DLSS / 去噪设置在 headless 的影响；材质路径是绝对路径）。
5. **版本说明**：3.0 的 OVRTX（术语表已有，链 8.1）一句话。

## 验收标准

设置名与 5.1.0 文档一致；实测表可复跑（校验方复跑①②各一次）；2.2、2.4、3.6、3.9、4.4、6.2.1、7.1、8.1 链接可达；不写"更真实"类评价，只写代价与用途。
