状态: 已合并
优先级: P3（第四批第 2 张；GPU 中：渲染若干百帧）
类型: 实操页
依赖: T-3.6（相机 / 渲染产品 / 标注器）、T-6.2.2（腕部相机场景）、T-6.4.2（物理侧域随机化，本页是图像侧）
产出: `docs/3-isaacsim/3.9-replicator.md`（替换占位页）；`examples/isaaclab-2.3/3.9-replicator/`（独立脚本 `synth_data.py` + README）；若复用 6-galbot 场景，文件头标 `（3.9）`
公共要求: 来源 Isaac Sim 5.1.0 Replicator 文档与 `omni.replicator.core` API 文档；篇幅 ≤ 3500；图按 D-017 / D-025

## 目标

读者知道 Replicator 是什么、与 Isaac Lab 的域随机化（6.4.2，物理侧）分工在哪，并能在 Galbot 腕部相机场景里生成一小批带标注的合成图像（RGB + 分割 + 2D 框），看清"随机化 → 渲染 → 标注 → 写盘"四步各在哪行代码。

## 必须覆盖

1. **定位**：Replicator（`omni.replicator.core`）= 场景随机化 + 标注输出 + 写入器；与 3.6 的"渲染产品 + 标注器"是同一套底层；与 6.4.2 的 Isaac Lab 事件项分工（一张表：随机什么 / 谁管 / 作用在哪一步）。**术语**：本页用 "Replicator" 原名，不译"复制器"；页首一句话与 3.7 的复制器（cloner）区分。
2. **四步**：`rep.randomizer`（光照、材质 / 颜色、物体位姿）、`rep.create.render_product`、标注器（`rgb`、`semantic_segmentation`、`bounding_box_2d_tight`）、写入器（`BasicWriter`，输出目录结构与文件格式一张表）；`rep.orchestrator.step()` 与仿真步的关系（回链 3.1）。
3. **语义标签**：没有 semantics 的 prim 分割 / 框为空——给 Galbot 方块打标签的两种方式（USD 属性 / `rep.modify.semantics`），实测缺标签时的输出。
4. **实测**：生成 ≥ 200 帧（640×480，3 种标注），记每帧耗时、总时间、输出体积、按进程显存；一张 2×2 拼图（RGB / 分割 / 框 / 随机化后另一帧，D-025 不适用于照片但图说明要有）。
5. **与 Isaac Lab 环境共用**：在 `ManagerBasedRLEnv` 里能否同时跑 Replicator（渲染产品共享、`--enable_cameras`）：实测一次最小组合或明确写"本页只做独立脚本"，不猜。
6. **常见坑 ≥ 3**（实测优先；候选：headless 下没开渲染什么都写不出；`rep.orchestrator.run()` 异步与脚本退出时序；标注器名字写错静默为空；分割 id 与颜色映射文件在哪）。

## 验收标准

脚本本机实测可复跑（校验方复跑 ≥ 50 帧，核对输出目录结构与标注文件格式）；API 名称与 5.1.0 文档一致；3.6、3.7、6.2.2、6.4.2 链接可达；图目检。
