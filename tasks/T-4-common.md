# 第 4 部分任务卡的公共要求（设计 session）

适用于 T-4.x 全部任务卡，卡片内不再重复。

- **来源**：一律以 Isaac Lab `v2.3.2` 源码为准，链接用带 tag 与行号的 GitHub permalink；官方文档 https://isaac-sim.github.io/IsaacLab/v2.3.2/ 作补充。任务卡里的类名、字段名、默认值若与源码不符，以源码为准并在附记登记（D-006）。
- **贯穿示例**：第 4 部分统一用官方 Cartpole 任务作例子（`isaaclab_tasks` 中 manager-based 与 direct 两个版本都有，便于对照）；需要机械臂时用 `Isaac-Reach-Franka-v0`。Galbot 留给第 6 部分，本部分只在"与主线项目的连接"里一句话预告并链接占位页。
- **示例代码**：放 `examples/isaaclab-2.3/<页面编号>-<slug>/`，遵守 CONVENTIONS 第 5 节（`main()` 写法；退出三步：释放 SimulationContext → flush → close；`num_envs` ≤ 1024；文件头注明验证版本、日期、GPU）。每个示例给出运行命令、预期输出关键行、显存与耗时。
- **篇幅**：上限 3500 字，以"必须覆盖"为准（D-021），不必就篇幅请示。
- **图**：方向按 D-017，箭头语义按 D-010；含图页面截图目检。
- **公式**：按 D-022，只在能省掉一段文字时用，公式下逐个解释符号。
- **与 0.6 锚点图的关系**：凡涉及 step 流程的页面，开头用一句话指出"本页讲的是 0.6 图中的哪一段"，并回链。
- **3.0 差异**：每页"版本说明"必须写一句 3.0 中本页主题的主要变化（来源 v3.0.0-EA release notes），查不到写"未核对"，不要猜。
- **建议顺序**：4.1 → 4.2 → 4.3 → 4.4 → 4.5 → 4.6 → 4.7 → 4.9 → 4.10 → 4.11 → 4.12 → 4.14 → 4.15 → 4.16 → 4.18。
