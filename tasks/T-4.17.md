# T-4.17 多智能体环境

状态: 待实现
优先级: P3（第四批第 4 张；GPU 轻：官方任务几十迭代）
类型: 概念页（带一个短实测）
依赖: T-4.14（Direct 环境）、T-4.16（RL 封装）、T-5.x（只回链）
产出: `docs/4-isaaclab/4.17-multi-agent.md`（替换占位页）；`examples/isaaclab-2.3/4.17-multi-agent/`（最小脚本或只给命令）
公共要求: 见 `tasks/T-4-common.md`（v2.3.2 permalink；贯穿示例用官方 Cart-Double-Pendulum）

## 目标

读者知道 `DirectMARLEnv` 与 `DirectRLEnv` 差在哪几行、哪些算法库支持它、什么时候该用（以及更常见的：什么时候不该用，直接把多个体拼成一个大动作就够了）。

## 必须覆盖

1. **接口差异**：`DirectMARLEnv`（v2.3.2 `direct_marl_env.py`）与 `DirectRLEnv` 的对照表：`possible_agents`、按智能体的观测 / 动作空间字典、`_get_observations` / `_get_rewards` 返回字典、终止与截断按智能体；配置类 `DirectMARLEnvCfg` 字段；与 4.14 对照表同格式。
2. **官方例子**：`Isaac-Cart-Double-Pendulum-Direct-v0`（两个智能体各控一根）与 `Isaac-Shadow-Hand-Over-Direct-v0` 各一句；跑前者 ≤ 100 迭代（skrl IPPO / MAPPO 的 `--algorithm` 开关）记耗时与显存，一行表。
3. **算法支持**：哪些库支持 MARL（skrl 的 IPPO / MAPPO；rsl_rl 不支持）；`multi_agent_to_single_agent` 封装（v2.3.2 源码 permalink）把 MARL 环境拼成单智能体：实测同一环境两种方式的观测 / 动作形状各一行。
4. **怎么选**：三种情形（共享策略 / 独立策略 / 拼成一个大动作）各适合什么；主线 Galbot 的双臂属于哪种（只一句、不实现）。
5. **常见坑 ≥ 3**（实测优先；候选：rsl_rl 直接喂 MARL 环境的报错原文；智能体间终止同步导致一方提前重置；观测字典顺序与 `possible_agents` 不一致；奖励日志只记合计）。

## 验收标准

类名 / 字段与 v2.3.2 源码一致（permalink）；实测可复跑（校验方复跑第 2 项一次）；4.14、4.16、5.1 链接可达；版本说明写 3.0 变化或"未核对"。
