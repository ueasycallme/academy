# T-4.18 扩展模板：在 Isaac Lab 之外组织你的项目

状态: 待实现
优先级: P1
类型: 实操页
依赖: T-4.15、T-4.16
产出: `docs/4-isaaclab/4.18-extension-template.md`（替换占位页）
公共要求: 见 `tasks/T-4-common.md`

## 目标

读者用官方模板生成一个独立于 Isaac Lab 仓库的项目，在其中注册任务、训练，不修改 Isaac Lab 源码。第 6 部分的 Galbot 项目将采用这个结构。

## 必须覆盖

1. **为什么不直接改 Isaac Lab 仓库**：升级、协作、版本管理。
2. **生成项目**：`./isaaclab.sh --new`（以 v2.3.2 的模板生成器为准）：external 与 internal 两种、Manager-based / Direct 选项、RL 库选择；逐个提问说明；非交互方式若支持也写明。实测一次并记录生成的目录树。
3. **项目结构讲解**：`source/<pkg>/`（`tasks/`、`__init__.py` 注册）、`scripts/`（train/play 包装）、`pyproject.toml` / `setup.py`、VS Code 配置；与 4.2 讲的 Isaac Lab 仓库结构对照。
4. **安装与运行**：`python -m pip install -e source/<pkg>`；列出任务；训练生成的模板任务若干次迭代。
5. **在项目里加资产与任务**：放机器人配置的位置、放 USD 的位置、任务命名；一句话链接 6.1.6、6.4.1 占位。
6. **与 Isaac Lab 版本绑定**：项目依赖哪个 Isaac Lab 版本如何声明；升级 Isaac Lab 时的检查项；3.0 迁移的提醒（链接 8.4 占位）。
7. **示例**：把生成并精简后的最小项目放进 `examples/isaaclab-2.3/4.18-extension-template/`（只保留必要文件，注明由模板生成及其版本）。
8. 常见坑 ≥ 3：editable 安装路径（呼应 1.9）、任务没被发现、VS Code 找不到 isaaclab。

## 验收标准

校验方从零按页面步骤生成项目并跑通训练；目录树与实测一致。
