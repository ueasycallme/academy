## 裁断前提（设计 session）

键盘遥操作（`Se3Keyboard`）依赖 Kit 窗口的输入事件，需要在用户桌面开 GUI 并由人操作。实现 session 不能操作 GUI，所以：① 设备抽象、retargeter、`teleop_se3_agent.py` 的流程按源码讲；② 实测用两条路：a) 把 `Se3Keyboard` 的回调用脚本直接触发（不经键盘硬件）验证 device → 动作 → 环境这条链；b) 请用户在桌面亲手跑一次 `teleop_se3_agent.py --teleop_device keyboard`（官方 Franka 任务即可）并截一张图——用户愿意就补，否则标"未验证"。

## 必须覆盖

1. **设备抽象**：`isaaclab.devices` 的 `DeviceBase`、键盘 / 手柄 / SpaceMouse / OpenXR / Haply 各自的类与依赖（v2.3.2 源码 permalink）、`teleop_device_factory.py` 的配置方式；输出是什么（SE(3) 增量 + 夹爪命令）。
2. **retargeter**：`retargeter_base.py` 与 OpenXR 的 retargeter 做什么（手部姿态 → 末端目标），一段。
3. **从设备到动作**：`teleop_se3_agent.py` 的主循环（permalink）：设备输出 → `DifferentialInverseKinematicsAction`（IK 动作项，回链 4.10）→ 环境；为什么遥操作任务用 IK 动作而不是关节动作。
4. **实测**（按裁断前提）：脚本触发 `Se3Keyboard` 回调跑官方 `Isaac-Lift-Cube-Franka-IK-Rel-v0`（或同类）若干步，打印末端位姿变化；用户若提供真实键盘操作截图则附上。
5. **录制示范**：`scripts/tools/record_demos.py` 的用法与 HDF5 结构一览（为 4.19 / 6.4.6 铺路，不展开 Mimic）。
6. 常见坑 ≥ 3（候选：headless 下键盘设备无事件；IK 动作的坐标系；录制时 env 数必须为 1）。

## 验收标准

设备类与脚本流程以 v2.3.2 源码为准（permalink）；实测 a) 可复跑；4.10、4.15、4.19、6.4.6 链接可达。
