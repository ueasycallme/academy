## 目标

读者知道 Isaac Lab 里仿真的全局参数在哪里配、各参数与 3.1/3.3 讲的物理概念如何对应。

## 必须覆盖

1. **`SimulationCfg` 字段表**：`dt`、`render_interval`、`gravity`、`device`、`use_fabric`、`physx`（`PhysxCfg`）、`physics_material`、`render`（`RenderCfg`）等，以 v2.3.2 源码为准列出：含义、默认值、对应的 3.1/3.3 概念。
2. **`PhysxCfg` 常调字段**：solver 类型、迭代次数上下限、GPU 缓冲区容量各项、`bounce_threshold_velocity` 等；哪些报错对应调哪一项（回链 1.9）。
3. **`isaaclab.sim.SimulationContext` 与 Isaac Sim 的关系**：继承关系、单例、`reset()` / `step()` / `render()` 的语义（回链 3.1、0.5），释放方式（回链 3.2 的退出三步）。
4. **`device` 与管线**：`cuda:0` / `cpu` 各自启用什么；张量在哪个设备上。
5. **`use_fabric`**：开与关的差别（按 T-3.7-notes 的要求，补上 Omniverse 官方来源后说明 Fabric 是什么），与"GPU 管线下 USD 位姿停在初值"（3.1 实测）的关系。
6. **在环境配置里的位置**：`ManagerBasedRLEnvCfg.sim` / `DirectRLEnvCfg.sim`；`decimation` 与 `sim.dt` 的关系（回链 0.6）。
7. **最小示例**：只用 `SimulationContext` + 一个 spawner 跑 N 步的脚本（可复用 3.2 的 Isaac Lab 版并扩展参数）。
8. 常见坑 ≥ 3。

## 验收标准

字段与默认值与 v2.3.2 源码逐项一致（校验方核对）；示例可运行并正常退出。
