# T-4.6 Assets：Articulation / RigidObject / DeformableObject

状态: 已合并

类型: 概念页

公共要求: 见 `tasks/T-4-common.md`

## 目标

读者会用 Isaac Lab 的资产对象读写机器人状态：知道 `data.*` 里有什么、写入接口有哪些、默认状态怎么定义、什么时候数据是新的。

## 必须覆盖

1. **三类资产**与各自的 Cfg：`ArticulationCfg`、`RigidObjectCfg`、`DeformableObjectCfg`（另提 `RigidObjectCollection`、`AssetBaseCfg`）；`spawn`（spawner cfg，含 `UsdFileCfg` / `UrdfFileCfg`）、`init_state`、`actuators` 三块的含义。
2. **`ArticulationData` 常用字段表**：根状态、关节位置/速度/加速度、刚体状态、默认值（`default_joint_pos` 等）、限位、增益；每个字段的形状与坐标系（世界系 / 环境系 / 基座系）。以源码属性为准，标明哪些是惰性计算、带时间戳缓存。
3. **写入接口**：`write_root_*_to_sim`、`write_joint_state_to_sim`、`set_joint_position_target` / `velocity_target` / `effort_target`、`write_data_to_sim()`；"设目标"与"直接写状态"的区别，各用在 reset 还是 step。
4. **数据何时更新**：`update(dt)` 的作用；step 内读到的是哪一时刻的数据（回链 0.6；T-0.6 校验中"joint_vel 每步读取"的例外一并说明）。
5. **名字到索引**：`find_joints` / `find_bodies`、正则、`joint_names` 顺序与 USD/URDF 顺序的关系。
6. **`isaaclab_assets`**：官方预置的机器人配置在哪、怎么用（以 Cartpole 与 Franka 为例）；自己的机器人怎么写一份（一句话链接 6.1.6 占位）。
7. **示例**：加载 Cartpole，打印关键 `data` 字段的形状，给关节设目标并步进，观察状态变化。
8. 常见坑 ≥ 3：默认关节位置越限抛 `ValueError`（T-3.4 已核实）、环境系与世界系混用、读了没 `update` 的旧数据。

字段表与 v2.3.2 源码一致（校验方抽查 ≥ 10 项）；示例复跑。
