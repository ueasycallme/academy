## 目标

读者面对一个新任务时，能判断"该教它（示教）还是让它自己试（RL）还是两者结合"，并知道 Isaac Lab 里每条路对应哪套工具。本站主线的分工（reach / lift 走 RL，pick-place 走遥操作 + Mimic，D-004 / 大纲评审结论）在本页给出理由。

## 必须覆盖

1. **两条路在学什么**：RL 从奖励里学，模仿学习（imitation learning）从示范里学；各自需要什么输入（奖励函数 vs 示范数据）、输出都是策略。一张对照表：需要什么、擅长什么、典型失败、Isaac Lab 里的入口（rsl_rl / skrl / rl_games 训练脚本 vs Isaac Lab Mimic + robomimic）。
2. **RL 适合的任务特征**：奖励容易写、探索不危险、接触动力学复杂到人难以示范（locomotion、reach）；成本是奖励设计（回链 5.5）与大量样本（回链 5.4）。
3. **示教适合的任务特征**：目标难用奖励描述、多步骤、有"人一看就会"的操作序列（pick-place、整理）；成本是采集与标注、分布偏移（covariate shift，直觉解释，一段）、示范质量上限。
4. **组合方式**（各一段，直觉 + 出处）：示范做初始化再 RL 微调；示范进奖励（参考动作项）；Mimic 式"少量示范 → 自动生成大量数据 → 行为克隆"（Isaac Lab Mimic 的流程，一句话 + 链接 4.19 占位与官方 Mimic 文档，不展开）。
5. **主线项目的分工及理由**：reach/lift 走 RL、pick-place 走遥操作 + Mimic，各一句理由；无真机数据的前提（D-004）；链接 6.4.1、6.4.3、6.4.6、6.4.7。
6. **决策表**：按"奖励好不好写 / 有没有示范手段 / 任务步骤数 / 接触复杂度"给出推荐路线，表格或左→右流程图（D-017）。
7. 常见误解 ≥ 3（候选：模仿学习不需要仿真；有了示范就不用奖励；RL 一定比模仿学习强）。
