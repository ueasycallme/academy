# T-6.1.1 认识 Galbot One Golf 描述仓库

状态: 待实现

类型: 实操页
依赖: T-4.18 已合并
产出: `docs/6-galbot/1-asset/6.1.1-galbot-repo.md`（替换占位页）；项目 `examples/isaaclab-2.3/6-galbot-project/`
公共要求: 见 `tasks/T-6-common.md`

## 目标

读者认识这台机器人和它的描述仓库：有哪些部件和关节、仓库里每种格式是干什么的，并把主线项目的骨架搭起来。

## 必须覆盖

1. **机器人概览**：全向轮底盘、躯干、双臂、夹爪、头部与传感器；各部件的自由度。数字全部从固定 commit 的 URDF 统计得出（给统计脚本），与 3.4 的关节清单表一致并回链。
2. **仓库结构**：`xacro/`、`urdf/`（两个预置：移动底盘版与固定底座版）、`mjcf/`、`usd/`、`meshes/`、`scripts/`、`config/`、`launch/`；每个目录一句话。
3. **三种格式各自的角色**：哪个是"源"、哪些是生成物；仓库自带的生成脚本怎么用（以仓库 README 与 docs 为准）。
4. **一处出入要查清**：仓库 README 说预置 URDF 省略了被动滚子关节，而 URDF 里有 44 个 continuous 关节、共 103 个关节；T-3.5 转换结果里有 40 个零增益的被动滚子。核对固定 commit 的实际情况，写明哪个说法对、对后续导入有什么影响。
5. **许可与署名**：Apache-2.0；本站如何使用（不分发其文件，读者自行克隆）。
6. **搭项目骨架**：按 4.18 用模板生成 `galbot_academy` 项目并精简，提交到 `examples/isaaclab-2.3/6-galbot-project/`；约定资产目录的配置方式（环境变量及默认值）；验证命令（安装、列出任务——此时可以只有模板自带的占位任务或为空）。
7. **第 6 部分路线图**：一张流程图（左→右）标出 ①资产 → ②场景 → ④任务 → ⑤训练 → ⑥评估 各页在做什么，本页是起点。
8. 常见坑 ≥ 3。

## 验收标准

统计数字可由脚本复现；项目骨架校验方从零安装并跑通验证命令；README 与 URDF 的出入有明确结论。
