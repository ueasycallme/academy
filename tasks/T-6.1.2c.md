## 背景

6.1.2 的 `--variant wheeled` 和 3.5 的示例都用 `target_type="none"` 处理被动滚子，结果滚子的刚度与阻尼都为 0。两处当时只做了转换、没有在仿真里跑。校验方在 T-6.1.3 中证实：零阻尼滚子导致仿真出现 NaN；阻尼改为 0.1 即消失（T-6-common 第 9 条）。

## 必须完成

1. `convert_galbot.py`：轮式变体不再对滚子用 `none`，改为零刚度 + 小阻尼（取值以实测为准，0.1 为起点），说明为什么零阻尼会出问题（有来源则引，没有则标推断）。转换后用 `hold_pose.py` 在仿真里跑轮式版，确认数值有限、与固定底座版一致；结果写进 README 与页面。
2. 6.1.2 页：更新"被动滚子的处理"一节与常见坑，写明"只转换不仿真"发现不了这个问题，转换后必须在仿真里跑一次。
3. 3.5 页与其示例：同样补上"被动关节需要小阻尼"的说明；示例加一步仿真检查（或在 README 明确说明示例产物不能直接用于仿真，并给出修正方法）。与 T-3.5c 的改动不要冲突，两者可合并提交但在附记分别列出。
4. 检查清单：6.1.2 与 3.5 的"转换后检查清单"各加一项"在仿真里保持若干秒，确认没有 NaN"。

## 验收标准

轮式变体转换后在仿真里无 NaN（校验方复跑）；两页表述一致；3.5 示例按 README 可复现；`sphinx-build -W` 零警告。
