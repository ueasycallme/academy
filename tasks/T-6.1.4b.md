## 背景

已上线的 6.1.4 写"1.45 rad 推测是驱动力矩饱和（推断）"。实现方的新证据：全身 64 组随机姿态下 joint3 需要的重力力矩最大 8.5 N·m，低于上限 30；卡住时位置不变而速度读数非零并持续数秒；怀疑是 articulation 进入休眠（sleep）。

## 必须完成

1. 按 CONVENTIONS 第 3 节"因果结论的证据门槛"查明原因：至少做一组排除性对照（如把休眠阈值设为 0 / 禁用休眠后是否仍卡住；给关节一个微小扰动是否立即恢复；力矩上限调高是否有变化），每种条件 ≥ 3 次。结论分清"已证实"与"推断"。
2. 改写 6.1.4 那句，给出原因、对策（如休眠阈值的设置，回链 3.3 的休眠参数）与探针结果。若查不清，保留"推断"并写明已排除了什么。
3. 探针脚本进项目目录，文件头标明页面归属；附记列出新增 / 修改的文件。
4. 若结论是休眠导致，顺带检查 3.3 讲休眠阈值的段落是否需要加一句回链，列在附记由设计 session 决定。
