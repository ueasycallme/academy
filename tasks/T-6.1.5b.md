## 背景（实现方实测，待查明）

机器人静止保持零位时，PhysX 读回的关节速度不为 0，显式执行器下约 0.1 rad/s。策略观测里通常有 `joint_vel`，这个本底值会进入观测。

## 必须完成

1. **划定范围**（按 CONVENTIONS 第 3 节证据门槛，每种条件 ≥ 3 次）：隐式 vs 显式执行器；CPU vs GPU 管线；`sim.dt` 两档；是否随时间衰减还是稳态存在；是哪些关节（全部还是接近限位的那几个）；官方 Cartpole / Franka 上是否也有（若无，说明与本机器人资产相关）。
2. **量级与来源的推断**：是接触/限位造成的微小振动（位置是否也在抖）、求解器的数值残差，还是读回时机问题（回链 4.6 的数据更新时序）。分清"已证实"与"推断"。
3. **对训练的影响**：与 reach 任务动作/观测的量级对比，给出结论（可忽略 / 需要在观测里加死区或滤波 / 需要改物理参数）；若需要处理，在 T-6.4.1 的观测项里落实并回链本页。

**结论（按证据门槛分开写）**
- 已证实（每种条件 3 次，逐位相同；数据见 scratch `jv_matrix.log`）：
  - 有重力时出现，关掉重力两台机器人读数都为 0；
  - GPU 与 CPU 都有（Galbot 0.196 / 0.203，Franka 0.0667 / 0.0667）；
  - dt 越大越大（Franka 0.034 / 0.067 / 0.133，对应 dt 1/240 / 1/120 / 1/60，成正比；Galbot 0.047 / 0.196 / 0.577）；
  - 不随时间衰减（t = 0.5–6 s 恒定），位置不动（fd = 0，漂移 < 0.01 rad）；
  - raw（直接从 PhysX 读）= data.joint_vel，排除读回时机；
  - 涉及的是受重力的关节：Franka 是 joint4/2/6，Galbot 是腿、臂与夹爪指节，21/33 个关节 > 0.01。
- 推断：读数近似"一步内重力造成的关节速度增量"。Franka 上读数 / (|M⁻¹τg|·dt) 约为 0.38–0.44（joint 1–4），joint6 为 0.26；排序一致、与 dt 成正比，但比例不是 1，所以只写作推断。Galbot 夹爪指节不符合，可能与 mimic 约束有关（推断）。
- 6.1.5 的 IdealPD 稳态误差随 D 变化：与此一致（D × 读数 ≈ 重力力矩），仍写作"现象与计算关系"。
- 全部 IdealPD 的对照（Galbot 各组都换成显式、Franka 显式）都不稳定（关节在动），不能用于静止读数，已排除，没有写进页面。
- 上游：检索 IsaacLab issues（"joint velocity not zero"、"joint_vel stationary"）与 PhysX issues（"articulation joint velocity nonzero"），未找到相关 issue（#1405 是另一个问题）。
- **对训练的影响**：可以忽略（推断，6.5.1 会检验）。右臂在 dt 1/120 时 ≤ 0.053、dt 1/60 时 ≤ 0.109 rad/s，是恒定偏置；对 joint_vel_l2 惩罚的贡献约 10⁻⁵/步。给 6.4.1 的建议：观测只取 reach 臂的关节（夹爪指节读数达 0.2）；不加死区或滤波；dt 的选择会改变偏置大小。sim2real 的差异请设计 session 记入 6.7.3。
