状态: 已合并
优先级: P2（用户批准的 P2 顺序第三项）
类型: 实操页（主线项目）
依赖: T-4.8 已合并（概念在 4.8，本页只讲 Galbot 上怎么装、装了付出什么代价）、T-6.2.1、T-6.4.3（lift 的 FrameTransformer 已在项目里）

公共要求: 见 `tasks/T-6-common.md`；GPU 与主机内存按 WORKFLOW；相机实测需 `--enable_cameras`，计时类每组在 GPU 空闲时连跑 3 次

## 目标

读者会把 Galbot 的右腕相机（URDF 已有 `right_wrist_camera_link`）、末端 FrameTransformer、夹爪接触传感器装进 Isaac Lab 场景，读出数据、验证坐标系，并知道每种传感器对 `num_envs` 与吞吐的代价——为以后的视觉策略 / 接触奖励铺路，本页不训练。

## 必须覆盖

1. **URDF 里已有什么**：`right_wrist_camera_link` / `*_wrist_camera_stand`（描述仓库固定关节、相对末端的位姿，数值写明来源）；转换成 USD 后这些 link 在 6.1.2 的导入里是否保留（固定关节合并规则，回链 6.1.2 / 6.2.1 的 TCP 合并问题——相机 link 可能也被合并进 link7，要实测确认并说明怎么办：用 offset 挂在 link7 上）。
2. **腕部相机**：`TiledCameraCfg` 挂在相机 link（或 link7 + offset），分辨率、`data_types`（rgb、depth）、`update_period`；朝向约定（Isaac Sim 相机 −Z 朝前的坐标系 vs URDF 的 optical frame，回链 4.8）；验证：渲染一帧看到方块 / 桌面（保存 PNG，页面放一张），相机内参与 URDF 的对应（若 URDF 没给内参，写明用默认值）。
3. **FrameTransformer**：TCP 与方块的相对位姿（6.4.3 已用），本页补"验证 offset"的脚本输出（TCP 在世界系的位置与 6.2.1 的工作台数值对照）。
4. **ContactSensor**：夹爪指尖（指垫 link）与方块的接触；需要 `activate_contact_sensors=True`（当前 galbot.py 为 False，说明改动与影响，回链 4.6 / 6.1.6）；`filter_prim_paths_expr` 指向方块；验证：脚本化抓取（复用 check_grasp）时打印接触力随时间变化，夹住时非零、张开时为零。
5. **代价实测**（一张表）：无传感器 / + FrameTransformer / + ContactSensor / + TiledCamera（64×64、128×128）在 `num_envs` = 64、256、1024 下的每步耗时、按进程显存、主机 RSS；相机那列写明 1024 环境能不能跑；给出"主线 reach/lift 训练不开相机"的理由。
6. **坐标系检查清单**：相机朝向、FrameTransformer 的 source/target、接触传感器的 body 名——三处最容易写反的地方各一条自查方法。
7. 常见坑 ≥ 3（候选：忘了 --enable_cameras；相机 link 被合并后路径不存在；activate_contact_sensors 没开读到全零；相机坐标系朝后）。

## 验收标准

第 1、2、4、5 项全部本站实测（版本、GPU、按进程显存、主机 RSS）；渲染图一张；校验方复跑 check_sensors 与代价表（计时类 ±20% 内、显存 ±5%）；4.8、6.1.2、6.1.6、6.2.1、6.4.3 链接可达。

实测要点（全部本站实测）：

2. **相机朝向**：link 的 +Z 指向夹爪前方（D405 碰撞网格 z ∈ [−0.023, 0]），按 ROS 光学约定解释（推断，页面已标）。投影检查：方块钉在相机系 (0.05, 0.05, 0.30) m，投影 (74.7, 73.7)，红色像素重心 (74.7, 73.0)。默认姿态下图像上方指向世界 −z（画面倒置，非约定错误）。内参 128×128：fx = fy = 67.44，cx = cy = 64；视场 87° 取自 realsenseai.com 产品页。
3. **FrameTransformer**：TCP 相对根 (0.684, −0.071, 1.409) m，与 6.2.1 一致；`tcp_to_cube` 与手算一致，源与 ee_frame 的 TCP 相差 0.000 mm。
4. **ContactSensor**：表 1 各阶段接触力；张开钉住阶段为 0.00 N，夹持阶段约 11.55/9.34 N。张开后左指尖仍有 0.62 N：方块落在下方的左指上（指尖高度 1.358/1.461 m）。
5. **代价表**：6 种配置 × {64, 256, 1024} × 3 次，共 54 次，rc 全 0，3 次之间相差 ≤ 1.6%。旁路日志每 10 s 记一次，期间 GPU 计算进程数 ≤ 1，loadavg 3–6（Isaac 自身多线程）。cam128 × 1024 先单独探了一次（10329 MiB / 8.5 GB），然后才进系列。
6. **常见坑**（均实测）：
