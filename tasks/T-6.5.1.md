# T-6.5.1 用 rsl_rl 训练 reach

状态: 已合并
优先级: P1
类型: 实操页（黄金路径第 10 站）
依赖: T-6.4.2、T-5.3、T-4.16
产出: `docs/6-galbot/5-train/6.5.1-train-reach-rsl-rl.md`（替换占位页）；项目 `examples/isaaclab-2.3/6-galbot-project/`
公共要求: 见 `tasks/T-6-common.md`

## 目标

读者训练出第一个 Galbot reach 策略：知道命令怎么写、日志怎么看、什么时候算训练好了。

## 必须覆盖

1. **agent 配置**：项目里的 `RslRlOnPolicyRunnerCfg`（网络结构、PPO 超参、`num_steps_per_env`、`max_iterations`、`save_interval`、实验名）；与官方 Franka reach 的配置对照，逐项说明取值（回链 5.2、5.3）。
2. **训练命令**：项目的 train 脚本或 Isaac Lab 的 `train.py`（按 4.18 的结构），headless，`num_envs` 取值；命令行覆盖的注意点（4.3 的坑：`__post_init__` 推导值不跟着变）。
3. **实测一次完整训练**（本站实测，RTX 5070 12 GB）：总迭代数、墙上时间、每秒步数、按进程显存；贴出开头、中段、结尾各一小段日志并解读（回链 5.3）。
4. **怎么判断训练好了**：mean reward 与分项奖励的走势；末端位置误差这一项的数值；给出本项目的"合格线"（如位置误差低于某阈值），说明这是仿真内的指标。
5. **TensorBoard**：启动方法、看哪几条曲线；附一张曲线截图。
6. **日志目录**：`logs/rsl_rl/<实验名>/<时间戳>/` 下有什么（checkpoint、`params/env.yaml`、`agent.yaml`），怎么从某个 checkpoint 续训。
7. **可复现性**：种子；同一配置跑两次的差异范围（实测）。
8. **没收敛怎么办**：指向 5.8，并列出 reach 任务最常见的三个原因。
9. 常见坑 ≥ 3。

## 验收标准

校验方按页面命令从零训练，到达页面所述合格线（或在波动范围内）；墙上时间与吞吐误差 ≤ 20%；日志目录结构一致。

### 诊断留档（isaac-academy-accomplish，2026-10-08；供 T-6.5.2 开篇案例使用）

评估口径：`scripts/eval_reach.py`，256 个环境，一个完整回合（12 s，目标每 4 s 重采样一次），在每段目标的最后一步取 TCP 误差，共 768 个样本。这与 Isaac Lab 记录的 `Metrics/ee_pose/position_error` 口径一致：后者是回合结束时的当前值在重置环境上的平均（command_manager.py L139–L143），不是回合内的平均。"停住但没到"指误差 > 5 cm，且最后 0.5 s 内右臂关节位置变化 < 0.01 rad。这里用位置变化判断，不用速度读数，因为静止读数有偏置（6.1.5）。

**1. 基线（6.4.1 原配置：刚度 400 / 40，课程学习升到 −0.005；官方 Franka 的 PPO 配置）**
- 两个运行 runA、runB 用同一种子 42，逐位相同；每个 1542 s，按进程显存 3041 MiB。
- 训练曲线（runA）：位置误差在第 400 次迭代前后最低（0.057），之后回升到 0.089；学习率从约 400 次起降到接近 1e-5；动作噪声标准差 1.0 → 0.029；mean reward 在 400 次时 0.23，999 次时 0.01。
- 评估结果：

| 检查点 | 中位数 | 90% 分位 | <2 cm | <5 cm | 停住但没到 |
|---|---|---|---|---|---|
| runA model_300 | 4.71 cm | 9.52 | 11.8% | 54.0% | 353/768 |
| runA model_400 | 5.05 cm | 9.80 | 9.5% | 49.1% | 391/768 |
| runA model_999 | 8.61 cm | 13.34 | 2.6% | 16.5% | — |

- model_400 加 `--vel_limit 3`（评估时把臂的速度上限提到 3 rad/s）：结果与上表逐位相同。但没有核实这次写入是否生效，所以不能据此排除 6.1.4 的卡住机制。

**2. 单因素对照（各 600 次迭代，单种子 42，三个并行，所以不计时；结论只能写作推断）**

| 变体 | model_300 中位数 / <5 cm / 停住 | model_599 中位数 / <5 cm / 停住 |
|---|---|---|
| 去掉课程学习 | 5.66 / 36.3% / 158 | 5.91 / 41.3% / 127 |
| 去掉姿态项 | 3.04 / 78.0% / — | 5.29 / 46.2% / — |
| 学习率 fixed 3e-4 | 10.00 / 18.4% / — | 9.82 / 18.2% / — |
| 刚度 1600 / 80（保留官方课程） | 2.41 / 94.7% / 2 | 3.38 / 71.6% / 190 |

**3. 官方 Isaac-Reach-Franka-v0 标定**（1024 个环境，600 次迭代，同一评估脚本）：model_300 为 3.31 cm、<5 cm 85.9%、停住 106；model_599 为 7.31 cm、34.9%、停住 500。可见"训练后段变差、停住的样本越来越多"是官方配方本身的现象。时间上与课程学习把动作变化率惩罚升到 −0.005 对得上（推断）。

**4. 候选最终配置（1000 次迭代，种子 42 / 43 并行）**

| 配置 | 种子 | model_300 | model_600 | model_999（中位数 / <2 cm / <5 cm / 停住） |
|---|---|---|---|---|
| 刚度 1600 + 去掉课程学习 | 42 | 2.54 | 2.95 | 2.14 / 45.1% / 95.8% / 0 |
| 同上 | 43 | 5.14 | 4.36 | 4.75 / 9.9% / 52.7% / 0（误差大时手臂仍在动） |
| **刚度 1600 + 温和课程（−0.001）** | 42 | 2.38 | 2.95 | **2.73 / 32.2% / 80.9% / 7** |
| 同上 | 43 | 4.98 | 2.61 | **2.91 / 25.5% / 83.7% / 0** |

- 合格线（设计裁定）：中位数 ≤ 3 cm，且 <5 cm ≥ 80%；两个种子都要满足。温和课程版两个种子都过线，其中种子 42 刚好过线（80.9%），采用它。
- 数据目录：scratch `proj6/logs/rsl_rl/galbot_reach/*diag*` 与 `franka_reach/*diagFranka`；诊断用的任务注册与配置只在 scratch 副本里（`diag_cfg.py`），没有进仓库。
