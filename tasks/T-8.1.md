# T-8.1 3.0 改了什么、为什么改

状态: 已合并
优先级: P1
类型: 概念页
依赖: T-0.2（分层图）、T-0.5（Sim/Lab 边界）、T-4.4、T-4.6

公共要求: 见 `tasks/T-8-common.md`

## 目标

读者看完能用一段话说清 3.0 的四个大变化（多物理后端、Newton、Kit-less、Warp 原生数据路径）各解决 2.3 的什么问题、彼此什么关系，并能判断"我现在该不该碰 3.0"（回链 1.2 决策树，不重复）。这是第 8 部分的总图页。

## 必须覆盖

1. **一张总图**：0.2 分层图的 3.0 版本——Isaac Lab 3.0 下面可以是 Isaac Sim 6.1（PhysX + Kit）也可以是 Newton（Kit-less），竖排、底层在下（D-017），与 0.2 并排对照（两张图或一张双栏图），箭头语义同 D-010。
2. **四个变化各一节**，每节结构固定：2.3.2 的做法与痛点（引 v2.3.2 源码/文档）→ 3.0 的做法（引 EA 源码/文档）→ 对用户代码的影响一句话（细节留 8.4）：
   - 多物理后端（backend 抽象、`physics=` 预设的存在，细节留 8.2）；
   - Newton（是什么、不等于 MJWarp、Kamino 等求解器名字只点到为止，细节留 8.3）；
   - Kit-less（不启动 Omniverse Kit 也能仿真：意味着什么能做、什么不能做——渲染、USD 场景、传感器——以 EA 文档为准）；
   - Warp 原生数据路径（`wp.array` 替代 `torch.Tensor`、四元数 XYZW、SceneDataProvider 的角色——只讲"为什么"，清单留 8.4）。
3. **哪些没变**：Manager-based / Direct 的任务写法、configclass、RL 库适配层——以 EA 的 `isaaclab_tasks` 目录和迁移文档为据，给读者"学 2.3 不白学"的依据。
4. **版本与状态**：beta → beta2 → EA 的时间线（左→右），每个节点一句话主要内容（来自 Releases）；GA 未定，按 T-8-common 不预测；主线切换条件回链 D-019 / 1.2。
5. 常见误解 ≥ 3（候选：3.0 = 换成 MuJoCo；3.0 不再需要 Isaac Sim；2.3 的任务代码在 3.0 上原样能跑）。

## 验收标准
