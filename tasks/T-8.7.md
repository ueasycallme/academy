# T-8.7 `isaaclab` 命令行与入口点

状态: 实现中

类型: 参考页
产出: `docs/8-frontier/8.7-isaaclab-cli.md`；示例 `examples/isaaclab-3.0/8.7-cli/`（README + 一个最小的外部任务注册示例，可复用 8.5 的 `register_tasks`）

## 目标

读者装好 3.0 后，知道 `isaaclab` 这一个命令能做什么、参数怎么流到 Hydra 与后端，以及自己的任务怎么挂进去。2.3 读者能对照着找到原来 `scripts/rsl_rl/train.py` 的每个用法。

## 必须覆盖

1. **安装选择器一张表**：`isaaclab -i` 的核心子模块、可选子模块（mimic、teleop）、特性集 `contrib / newton / ov[ovrtx|ovphysx|all] / rl[...] / visualizer[kit|rerun|viser] / tetrahedralization`、特殊值 `all / core`；每项一句"装了什么、要不要 Isaac Sim"。来源：`isaaclab --help` 原文（本站 3.0 环境实测）与 `isaaclab.sh` / CLI 源码 permalink。
2. **三个子命令**：`train / play / benchmark` 的参数分三层（CLI 自己的、Hydra 覆盖、后端专有），分流在哪段代码（8.5 脚注的 `entrypoints/backends/train_rsl_rl.py` L84–L104 `list_intersection`，核对后引用）；`--physics / --renderer / --visualizer` 预设怎么组合（回链 8.2）；常见组合给 4 条命令。
3. **注册自己的任务**：`--external_callback`（8.5 的做法：回调返回 None）、`PYTHONPATH` 方式、与 2.3 的 `gym.register` 对照；模板生成器（`developer-tools/template_generator.rst`）一段，只讲它生成什么、不跑完整模板。
4. **对照表**：2.3 的 `scripts/rsl_rl/train.py --task --num_envs --headless --seed --run_name` 等 ↔ 3.0 的 `isaaclab train` 写法，逐项。
5. **常见坑 ≥ 3**（实测优先）：回调返回空列表的问题（8.5 附记已有）；选择器的引号；`-i` 重复安装 / 特性集覆盖；Hydra 覆盖与 CLI 参数同名时谁赢。

## 验收标准

每条命令在本站 3.0 环境跑过（`--help` 与一次 `train` 2 次迭代即可，不计时）；源码 permalink 带行号（本地镜像核对）；8.2、8.4、8.5、1.5 链接可达；版本说明写明 EA。
