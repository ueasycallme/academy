# T-8.8 Kit-less 工作流实测

状态: 已合并
优先级: P3（D-033 第二张）
类型: 实操页
产出: `docs/8-frontier/8.8-kitless.md`；示例 `examples/isaaclab-3.0/8.8-kitless/`（README、测量脚本、结果表）

## 目标

回答"不装 Isaac Sim 到底能做什么"。读者按 1.5 路线 C 装最小环境，照本页跑通训练、回放与可视化，并知道哪些事必须回到 Kit。

## 必须覆盖

1. **能 / 不能一张表**：按工作流列（headless 训练、Rerun / Viser 可视化、OVRTX 相机 / tiled camera、录像、USD 资产转换、Replicator、ROS 2 桥、遥操作），每行写 Kit-less 下能否、依据（源码 / 文档 permalink）、本站实测与否。
2. **实测路线**：路线 C 环境（不装 isaacsim；装 `newton`、`visualizer[rerun,viser]`、`ov[ovrtx]`）：Cartpole 与 Galbot reach（8.5 的 3.0 项目）各训练 ≤ 200 次迭代、`play` 回放；Rerun 与 Viser 各截一张图（D-025）。
3. **对照测量（计时，独占 GPU，D-032 标 RTX 5090）**：Kit 路线（1.5 路线 A）与 Kit-less 路线在同一任务、同 num_envs 下：启动到第一次迭代的时间、每次迭代时间、按进程显存、RSS 峰值；各 2 次取平均并给范围。
4. **OVRTX**：装 `ov[ovrtx]` 后用 tiled camera 出一帧（`features/visualizer_tiled_camera.rst`、`concepts/renderers.rst`），记分辨率、每帧时间、显存；装不上或跑不通按 6.4.3 先例如实记录并给来源。
5. **常见坑 ≥ 3**（实测优先）：候选：可视化器与 headless 的互斥、Rerun 端口、OVRTX 依赖的驱动 / CUDA 版本、路线 C 里误装 isaacsim。

## 附带修订（源自 T-8.7 的发现）

- 8.2"三种物理后端"或"预设"一节加一两句：在没有 Kit 的进程里 `physics=physx` 解析为 OvPhysX（没装 `ov[ovphysx]` 会报错），要用 Isaac Sim 自带的 PhysX 得写 `isaacsim_physx`；Cartpole（Direct）的默认预设是 `newton_mjwarp`。回链 8.7 对应小节，给源码 permalink。本页（8.8）的能 / 不能表第一行也要体现这一点。

- 8.5 常见坑三（PhysX 能用的 USD，Newton 不一定能用）末尾加一句：3.0 资产副本在 Rerun / Viser 可视化器里没有可见网格，看不见机器人，细节见 8.8 对应的坑。回链 8.8 锚点。（设计裁断 2026-10-12，源自本卡实测；8.10 还要用这份资产，先把现象记下来，不在本卡查根因。）
