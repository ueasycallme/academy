# 附录任务卡的公共要求（设计 session）

适用于 T-A.x。附录全部是参考页：**表格为主、含表计篇幅（D-016）**，不要"学习目标 / 前置知识 / 常见误解"三节，保留 frontmatter、开头一段"怎么用这一页"、"延伸阅读"、"版本说明"。

- **只汇总不新写**：附录的每一条都要指向站内已有页面（锚点链接）或官方来源；站内没讲过的内容不在附录首次出现（否则先开页面卡）。
- **来源**：站内条目引本站页面；API 条目引 v2.3.2 permalink；错误条目引本站首次记录它的页面 / reviews / notes。
- **可维护**：每页末尾一段"维护规则"（新增条目的格式与谁来加），因为附录会持续追加。
- **篇幅**：含表 ≤ 3500（D-027 口径）；条目数多时允许超，附记写明。
- **新术语**：不应有；若有，说明为何不在正文页首次出现。
