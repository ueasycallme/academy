# T-SITE-09 宽表格横向滚动

状态: 待实现
优先级: P2（不阻塞内容任务；在 T-3.x 之间找空档做）
类型: 基础设施
来源: T-2.1b 附记（实现方发现 0.5、1.4、1.9 三页的表格在改动前就已横向滚动）

## 目标

正文表格在 1440 与 2560 宽下尽量不出现横向滚动条；确实放不下的，滚动行为清晰可用。

## 必须完成

1. 盘点：全站已合并页面的表格，在 1440 / 1920 / 2560 三档下哪些出现横向滚动，列表写入附记（页面、表、列数、最宽列内容类型）。
2. 处理原则（按顺序尝试）：① CSS 层面让长代码/路径单元格可断行（`overflow-wrap: anywhere` 仅作用于表格内的行内代码）；② 单元格内容过长的，改内容：把长路径或长命令移到表下脚注或代码块；③ 仍放不下的保留滚动，但确认 pydata 的滚动容器有可见提示。
3. 不得为此缩小全站表格字号；T-2.1b 的首列 keep-all 规则保持。
4. 改内容的地方只做排版性调整，不改事实；每处在附记列出，校验方逐处复核。

## 验收标准

1440 宽下已合并页面无横向滚动，或在附记中逐表说明保留理由；`sphinx-build -W` 零警告；三档截图各一组。
