产出: `docs/_static/js/lightbox.js`、`docs/_static/css/academy.css` 追加、`docs/conf.py`（`html_js_files`）

## 必须完成

1. **全站生效**：`.bd-article` 内所有 `<img>`（`{image}` / `{figure}` / Markdown 图片，不含 Mermaid SVG、不含徽章/图标类小图——按尺寸或 class 排除，附记写规则）点击后在当前页打开悬浮层：半透明遮罩 + 居中图片（最大 90vw × 90vh，保持比例）+ 右上角关闭按钮（×，≥ 40px 可点区域）；ESC、点击遮罩也可关闭；打开时禁止页面滚动；关闭后焦点回到原图。
2. **不跳转**：若图片被包在 `<a>` 里（主题或扩展加的），拦截点击不跳转；页面源码不再给图片加 `:target:` 或外链。
3. **实现方式二选一**（附记写明理由）：自写 ≤ 80 行无依赖 JS；或 cdnjs 上的 GLightbox / basicLightbox（D-015 允许），版本固定、`integrity` 可免。深浅色主题下遮罩与按钮都清晰（用 `--pst-color-*` 变量）。
4. 鼠标悬停时光标为 `zoom-in`，提示可点击。
5. 自检：6.1.1、① 资产 index、6.5.1（PNG 曲线图）、2.2（若有 SVG 图）各点开一次并关闭，1440 与 2560 各截一张打开态；移动端宽度（390）一张。`sphinx-build -W` 通过。

### 实现附记（isaac-academy-accomplish，2026-10-09）

**本页新增/修改的项目文件**：
- 新增 `docs/_static/js/lightbox.js`（60 行）
- `docs/_static/css/academy.css`：追加 lightbox 一节
- `docs/conf.py`：`html_js_files` 加入 `js/lightbox.js`

**实现方式**：自己写的无依赖 JS。理由：需求只有打开、三种关闭方式、焦点还原和滚动锁定，60 行就够了；不引入第三方 CSS / JS，也就不必为外部资源固定版本、核对许可证，深浅色主题直接沿用本站变量。

**作用规则**：
- **范围**：`.bd-article` 内的 `<img>`。Mermaid 图是内联 SVG，不是 `<img>`，天然不受影响。
- **排除**：显示宽、高都小于 48px 的图（徽章、图标），以及位于 `.sd-badge` / `.badge` 里的图。
- **点击**：在 document 的捕获阶段委托处理，`preventDefault` 加 `stopPropagation`，所以即使图片外面包着 Sphinx 加的 `<a class="image-reference">`，点击也不会跳转。用委托而不是逐个绑定，是因为第一版在 `load` 事件里绑定，偶尔赶不上执行时机（第一轮测试 8 次页面加载中有 3 次没生效）。
- **悬浮层**：半透明遮罩 `rgba(0,0,0,.78)`；图片最大 90vw × 90vh，保持比例；右上角 × 按钮为 44 × 44 px。
- **关闭**：ESC、点击遮罩或 × 都会关闭；点图片本身不会关闭。
- **打开期间**：给 `<html>` 加类，禁止页面滚动；关闭后焦点回到原图。
- **键盘与光标**：图片有 `tabindex=0`，回车或空格也能打开；悬停时光标为 `zoom-in`。

**自检**：用 headless Chrome 经本地 http 服务测试，脚本依次执行：点击打开 → ESC 关闭 → 打开后点遮罩关闭 → 打开后点 × 关闭 → 再次打开并截图。
